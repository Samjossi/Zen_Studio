## 1. 项目真实身份与技术栈

目录名为 "VS_Code_Python"，实际内容是 **PyGPT 2.7.12**（py-gpt 的中文化改造版），一个基于 PySide6 的桌面 AI 助手，并非 VS Code。

| 项目 | 内容 |
|:---|:---|
| 语言 | Python `>=3.10,<3.14`（实际运行 3.12） |
| GUI 框架 | PySide6 6.9.1（含 QtWebEngine / QWebChannel） |
| 关键依赖 | `openai`、`anthropic`、`llama-index`、`qt-material`（主题）、`Pygments`、`qasync`、`SQLAlchemy` |
| 入口 | `run.py` → `pygpt_net.app:run()` |
| 规模 | 1057 个 Python 文件，约 40.3 万行 |
| 主布局 | 三栏水平 QSplitter：会话列表 \| 聊天区 \| 工具箱 |

## 2. 三个核心问题的结论

| 需求 | 是否存在 | 结论 |
|:---|:---:|:---|
| 文件树（文件浏览器） | ✅ 有 | 完整实现，可直接借用（详见 3.1） |
| 对话栏（AI 聊天面板） | ✅ 有 | 项目核心功能，方案可借鉴（详见 3.2） |
| 代码浏览高亮 | 🟡 部分 | **只有"只读高亮展示"，没有真正的代码编辑器**（无行号、无语言级高亮编辑），需另行自建（详见 3.3） |

### 3.3 代码浏览与高亮（仅部分可用）

| 方案 | 文件 | 说明 |
|:---|:---|:---|
| highlight.js 只读高亮 | `data/js/highlight/`（全套约 190 种语言）+ `core/render/web/syntax_highlight.py`（58 行） | 在 `QWebEngineView` 中前端高亮，**只读展示代码的可直接照搬此方案** |
| 查找标记高亮 | `ui/widget/textarea/highlight.py` — `MarkerHighlighter(QSyntaxHighlighter)`，66 行 | 查找命中底色标记，★★★★★ 复制即用 |
| Markdown 高亮 | `ui/layout/chat/markdown.py` — `MarkdownHighlighter`，384 行 | ⚠️ GPL 许可衍生，商用慎搬 |
| 只读代码查看器 | `ui/widget/textarea/editor.py` — `CodeEditor(QTextEdit)`，165 行 | 仅查找/缩放，无行号无语言高亮 |

🔴 **结论**：该项目**没有真正的代码编辑器**。IDE 所需的"可编辑 + 行号 + 语言级语法高亮"需自建，路线二选一：`QPlainTextEdit + QSyntaxHighlighter` 或引入 QScintilla。

## 4. 借用注意事项

1. 🔴 **上帝对象耦合**：所有控件强依赖 `window`（`window.core.config`、`window.controller.*` 贯穿全代码），**不能复制即用**，必须写适配层或逐处替换服务引用。
2. 🟡 **图标资源**：走 Qt 资源系统（`:/icons/*.svg`，由 `icons.qrc` 编译），移植需带上 qrc 文件。
3. 🟡 **国际化**：`trans()` 函数需替换。
4. 🔴 **许可证**：`markdown.py` 高亮器为 GPL 衍生文件，注意许可证隔离。

## 5. 对 Zen Studio 的行动建议

| 优先级 | 行动 |
|:---|:---|
| 高 | 借用 `explorer.py` 文件树 → 放入左栏 |
| 高 | 自建代码编辑器（`QPlainTextEdit` + `QSyntaxHighlighter`）→ 中栏；只读展示场景可用 highlight.js 方案 |
| 中 | 借鉴聊天面板上下分栏结构与 LLM 注册表模式 → 中栏下或右栏（可对接本项目的 DeepSeek API key） |
| 中 | 借用标签页系统支撑多文件编辑 |
| 低 | 菜单/状态栏/主题按需借鉴装配模式 |
