# assets/icons/ — 通用矢量图标素材库

通用 SVG 图标素材的存放目录（如 `arrow_up.svg` / `arrow_down.svg`），**非本应用运行时资产**——当前无任何代码消费本目录，留作手动迁移至其他项目时取用。

## 纪律

- **不打包**：本目录**禁止**加入 `building/zen-studio.spec` 的 `datas`。
- 若某图标将来被运行时消费，必须先将其移入合适的运行时资产目录（或新建专目录）并在 `datas` 中补收编记录，再从此目录删除原件，避免"一份素材两处维护"。
- 新增素材保持 SVG 母版形态，命名用 `snake_case`。
