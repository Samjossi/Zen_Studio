# assets/ — 打包资产总目录

> **状态**：已确认
> **范围**：`assets/` — 运行时资产目录治理与打包收编纪律
> **时间**：2026-07-31 01:30（UTC+8，修订补头部元信息）

Zen Studio 全部**运行时资产**的集中存放地，**会被 PyInstaller 收编进产物**。

## 目录约定

| 子目录 | 用途 | 是否打包 |
|:---|:---|:---:|
| `fonts/更纱黑体/` | 终端与代码查看器等宽字体 | ✅ 打包 |
| `fonts/思源黑体/` | UI 正文/标题字体 | ✅ 打包 |
| `fonts/思源宋体/` | 备用衬线字体（完全未注册，87M） | ❌ **不打包**（2026-0725-1053 计划修订二决策，文件留库不删） |
| `themes/` | QSS 主题模板（`base.qss`，gui/theme.py 消费的只读资源） | ✅ 打包 |
| `logo/` | 正式 Logo 全套资产（母版 SVG + 八尺寸 PNG） | ✅ 打包 |
| `logo候选池/` | Logo 设计草稿（历史候选方案存档） | ❌ **不打包** |
| `readme/` | 根目录 `README.md` 引用的文档素材（界面截图、演示 GIF），非运行时资产 | ❌ **不打包** |

## 纪律

- **一族一目录**：同类资产必须放入专属子目录，**禁止向 `assets/` 根直接散落文件**。
- 打包收编按**子目录**进行（`fonts/更纱黑体`、`fonts/思源黑体`、`themes`、`logo` 四条 `datas`），
  因此新增「需要打包」的资产时必须**同时**：
  1. 放入合适的既有子目录（或新建专目录）；
  2. 在 `building/zen-studio.spec` 的 `datas` 中补一条收编记录。
- `fonts/思源宋体/`、`logo候选池/` 与 `readme/` **禁止**加入 `datas`，也禁止恢复整目录收编。
- 运行时通过 `core/paths.py` 的路径常量访问本目录，禁止散落的手写路径推导。
