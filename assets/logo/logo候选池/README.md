# assets/logo/logo候选池/ — Logo 设计草稿存档

本目录存放历史 Logo 候选方案，仅供设计回溯，属于非运行时素材，**不打包、不被代码引用**。

## 内容 / 组织方式

- `形状候选/`：不同构图的 SVG 候选方案。
- `配色候选/`：配色方案 SVG 与预览图。

## 纪律

- 严禁把本目录加入 `building/zen-studio.spec` 的 `datas`，也禁止整目录收编 `assets/logo/`。
- 候选方案定版后复制到 `assets/logo/正式logo/` 并改用通用文件名，本目录原件保留。
- 本目录文件只存档、不改动；新增候选按形状或配色放入对应子目录。
