# assets/sounds/正在使用/ — 提示音启用目录

> **状态**：已确认
> **范围**：`assets/sounds/正在使用/` — 运行时实际消费的提示音目录

本目录是**运行时实际消费**的提示音目录，会被打包进产物。文件均**从 `assets/sounds/备选池/` 复制而来**；用户在设置中心「通知」页从本目录的 wav 文件中为各事件（任务成功 / 任务失败 / 交互提问）挑选提示音。

## 当前文件

| 文件 | 语义 | 备注 |
|:---|:---|:---|
| `done.wav` | 任务成功默认音 | 复制自备选池 `bip-bop-01.wav` |
| `error.wav` | 任务失败默认音 | 复制自备选池 `nope-03.wav` |
| `question.wav` | 交互提问默认音 | 复制自备选池 `alert-01.wav` |
| `bip-bop-02.wav`、`bip-bop-03.wav` | 完成族备选 | 供挑选 |
| `yup-01.wav` | 确认族备选 | 供挑选 |
| `staplebops-06.wav` | 轻快族备选 | 供挑选 |
| `nope-01.wav` | 失败族备选 | 供挑选 |

## 纪律

- 新增可选声音 = 从 `备选池/` **复制**进本目录（禁止移动，备选池留档）；
- 语义化默认值用 `done.wav`/`error.wav`/`question.wav` 命名，备选文件保留原族名便于辨认；
- 设置中心持久化的是**文件名**（如 `"done.wav"`），运行时在 `正在使用/` 下按名取文件；
- 本目录随 `building/zen-studio.spec` 整目录收编，本 README 一并打包（说明书随产物走）。
