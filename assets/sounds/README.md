# assets/sounds/ — 提示音资产总目录

Zen Studio 全部提示音资产的集中存放地，音频源自 kilocode（MIT 许可）。运行时消费链路见 `src/gui/sound_player.py`，设置中心「通知」页负责挑选与持久化。

## 子目录

| 子目录 | 用途 | 是否打包 |
|:---|:---|:---:|
| `正在使用/` | 运行时实际消费的提示音目录（语义默认音 `done.wav`/`error.wav`/`question.wav` + 备选池全量副本，供用户挑选） | ✅ 打包 |
| `备选池/` | 提示音备用库存（45 个 wav，按 `alert`/`bip-bop`/`staplebops`/`nope`/`yup` 五族组织） | ❌ 不打包 |

各子目录的库存明细与命名语义见其各自的 README。

## 纪律

- **启用 = 复制**：声音须从 `备选池/` **复制**进 `正在使用/` 才可被运行时消费（禁止移动，备选池留档）。
- `正在使用/` 随 spec 整目录收编；`备选池/` **禁止**加入 `datas`。
- 运行时只按**文件名**在 `正在使用/` 下取文件，禁止散落的手写路径推导。
