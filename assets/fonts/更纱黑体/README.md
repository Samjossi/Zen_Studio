# assets/fonts/更纱黑体/ — Sarasa Term SC（等宽字体）

更纱黑体终端版简体中文子集（v1.0.40），Zen Studio 的**终端与代码查看器等宽字体**。

## 内容

- `SarasaTermSC-Regular.ttf` / `SarasaTermSC-Bold.ttf` 两档字重。
- 文件名采用官方 `SarasaTermSC-*` 命名，**禁止改名**（加载常量按此名引用）。

## 运行时加载

- 注册入口：`gui/theme.py` 的 `MONO_FONT_FILES`，Regular / Bold 两档**全部注册**。
- 注册字体族名：`Sarasa Term SC`。
