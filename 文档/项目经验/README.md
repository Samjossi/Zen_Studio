# 项目经验

本目录存放项目实践中用真实事故换来的经验教训文档，记录踩坑现象、根因分析、防再犯规则与修复方式——目标是**同类错误不犯第二次**。

## 收录标准

- ✅ 实际发生过的故障/潜伏 bug/返工，有明确根因和可执行的防再犯规则
- ✅ 排查过程本身有方法论价值的案例（如「单独跑过 ≠ 全量过」）
- ❌ 未发生的假想风险、泛泛的最佳实践摘抄（属理论依据或协议指南）
- ❌ 日常功能变更记录（属 `文档/修改记录/`）

## 文档结构建议

每篇按四节组织：**事故现象 → 根因 → 教训（防再犯规则）→ 修复**。教训必须落到可执行规则（🔴 红线优先），不停留在"以后注意"。

## 命名规范

遵循 `文档/文档编写规范.md`：`YYYY-MMDD-HHMM_经验主题.md`，标题点明坑本身（如「多组件conftest同名autouse夹具跨目录遮蔽」），不写成流水账日期。
