# 模型栏「接口」按钮单接口自动隐藏落地计划

## 1. 需求背景

ModelBar 现为四按钮：后台 → 接口 → 模型 → 推理强度。用户提出：「接口」按钮没有存在感——查注册表证实，当前六家后台（kimi / reasonix / opencode / kilocode / dream / local）**每家仅挂一个接口**（`*-acp` 六枚），接口按钮点开永远是单选菜单，纯多一层无效点击。

用户决策（2026-10-04）：

1. **接口级架构保留**——未来可能出现一家厂商多个接入实现（如某 CLI 同时有 ACP 与 HTTP 接法），该级是既定扩展点（2026-0730-0150 计划正是从两级扩成三级以承载它），不删；
2. **代码里备注 why**——在当时代码处注明接口级存在理由，防后来者误判为赘肉删返工；
3. **按钮隐藏掉**——但做成**条件隐藏**：单接口时自动隐藏，出现第二接法时自动恢复显示，架构零改动、无需再改代码。

追加需求（2026-10-05，GUI 截图拍板）：ModelBar 一级按钮的「本地模型」四字偏长，与其余短厂商名不齐——改为「Local」（见 D6）。

## 2. 现状诊断

- `model_bar.py` `ModelBar.__init__`：四按钮依次加入 QHBoxLayout；接口菜单由 `_refresh_interfaces(vendor)` 按后台重建（先清后建，默认勾选首个可用接口）。
- 选择逻辑与按钮显示解耦良好：勾选/信号/持久化全部走 `QActionGroup` 与注册表，按钮只是菜单的承载体——**隐藏按钮不影响任何选择逻辑**（`_refresh_interfaces` 照常重建菜单、勾选首可用接口，信号链 `selection_changed` 不变）。
- 隐藏只需 `setVisible(False)`：QHBoxLayout 对不可见子部件自动收拢，宽度贴合策略（`_refresh_button_texts` 的 setFixedWidth）对隐藏按钮照常计算无副作用。
- 测试基建就绪：`tests/conftest.py` 已设 `QT_QPA_PLATFORM=offscreen`，`tests/test_model_display_names.py` 已有实例化 ModelBar 的现成范式。

## 3. 方案设计

**D1（条件隐藏判定）**：显隐挂在 `_refresh_interfaces` 尾部——每次接口菜单重建后按**当前后台的接口总数**（含不可用项，见 D2）判定：

- 接口数 ≤ 1 → `self._interface_button.setVisible(False)`；
- 接口数 ≥ 2 → `setVisible(True)`。

挂重建尾部的理由：显隐与菜单数据同源同步，`_on_vendor_picked` / `set_selection` 等一切触发重建的路径自动覆盖，无需散点补丁。

**D2（判定口径取「接口总数」而非「可用数」）**：某后台若有两个接口但一个未安装（`available()=False`，菜单标「未检测到」），按钮仍显示——「未检测到」状态本身就是给用户的排错信息，藏起来反而遮蔽。

**D3（备注 why，防误删）**：模块 docstring 增一节 + `_refresh_interfaces` 显隐判定处行内注：接口级是厂商多接入实现的**扩展点**（2026-0730-0150 计划扩级缘由），当前六家均单接口故按钮默认隐藏，≥2 接口时自动恢复——注释只写设计意图与约束，不记日期流水（AGENTS.md 注释纪律）。

**D4（零改动红线）**：注册表、信号签名 `(backend, version)`、持久化键、tooltip 四行全名链（接口行保留，信息溯源不受按钮显隐影响）、设置中心分组逻辑——一律不动。改动只落在视图层显隐一处。

**D5（顺手清账）**：`src/gui/README.md` 两处过时描述（"模型选择三按钮"、"后台 → 接口 → 模型三级下拉 / 四后台"）随本计划一并修正为现行口径；`术语表.md`「模型选择四按钮」行补注"接口级单接口时隐藏"。

**D6（「本地模型」改名「Local」，2026-10-05 用户拍板）**：ModelBar 一级按钮的厂商名取注册项 `vendor_label`，本地后台现为「本地模型」四字，用户要求精简为「Local」（GUI 截图确认与其余短厂商名风格齐平）。改动点：`src/llm/registry.py` local-acp 注册项 `vendor_label="本地模型"` → `"Local"`。波及面核查：

- `vendor_label` 为纯 UI 呈现字段（一级按钮文本、设置中心分组标题、tooltip 后台行），注册键 `vendor="local"` / `name="local-acp"` / 持久化值均不动，选择链路与配置兼容零影响；
- 接口按钮短文本推导 `short_interface_label("Local ACP", "Local")` → `"ACP"`，剥前缀逻辑天然兼容（改名后接口按钮若显示反而更短）；
- `术语表.md`「后端 / 后台」行六家清单里的「本地模型」同步改「Local」；`维护手册/后端CLI工具维护说明手册.md` §5 标题「本地模型（Local CLI）」保留——手册语境指概念非按钮文本，不改。
