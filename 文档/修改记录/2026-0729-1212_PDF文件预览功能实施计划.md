## 3. 总体设计

### 3.1 架构形态（沿用图片/媒体/Markdown 三篇同型）

`ViewerPanel._stack`（`QStackedLayout`）新增**第五页**：

| 页 | 控件 | 承载 |
|:---|:---|:---|
| 文本页（现有） | `CodeViewer` | 文本、占位提示（二进制/不存在/已删除/预览失败回落） |
| 图片页（现有） | `ImageViewer` | 位图 / SVG / GIF |
| 媒体页（现有） | `MediaViewer` | 视频 / 音频 |
| Markdown 页（现有） | `MarkdownView` | .md/.markdown GFM 渲染 |
| **PDF 页（新增）** | `PdfViewer`（新文件 `gui/panels/viewer/pdf_viewer.py`） | `.pdf` 就地预览 |

`open_file` 分流（插入现有分流链，顺序无关正确性，按扩展名互斥）：

```python
# gui/panels/viewer/panel.py（open_file 分流示意）
if suffix in VIDEO_EXTS or suffix in AUDIO_EXTS:
    return self._open_media(p)
if suffix in IMAGE_EXTS:
    return self._open_image(p)
if suffix in MARKDOWN_EXTS:
    return self._open_markdown(p)
if suffix in PDF_EXTS:
    return self._open_pdf(p)          # 新增
```

- 扩展名表与前四页同型：`pdf_viewer.py` 模块导出 `PDF_EXTS: frozenset[str] = frozenset({"pdf"})`，panel import 消费（不内联字面量，AFCP 3.4 魔法值常量化）。

- 占位提示（文件不存在/读取失败/二进制不支持）仍走文本页 `_show_placeholder`，**现有四页行为零回归**。
- PDF 加载失败（加密/损坏/格式非法）→ 回落文本页占位提示「（PDF 无法预览：原因，可在外部程序打开）」。
- 离开 PDF 页无特殊释放义务（不同于媒体页 stop() 红线），`QPdfDocument.close()` 在切换文件/回落占位时调用释放内存。

### 3.2 PdfViewer 控件设计（新文件 `gui/panels/viewer/pdf_viewer.py`）

`QWidget` 组合 `QPdfView`（不派生，组合优先 AFCP 2.4；`QPdfDocument` 持有于控件内）：

```python
# 骨架示意
class PdfViewer(QWidget):
    page_info_changed = Signal(str)          # 页码/缩放弱提示（接 panel._show_hint）
    external_failed = Signal(str)            # 外部打开失败（同 Markdown 页 typora_failed 先例）

    def __init__(self, palette, parent=None): ...
    def open_pdf(self, path: Path) -> str | None:   # 成功 None；失败返回原因字符串
    def zoom_in(self) -> None: ...
    def zoom_out(self) -> None: ...
    def fit_width(self) -> None: ...
    def fit_page(self) -> None: ...
    def step_page(self, delta: int) -> None:  # ◀ ▶ 页码导航
    def open_external(self) -> None: ...      # QDesktopServices 兜底
    def apply_theme(self, palette) -> None: ...
    def close_document(self) -> None: ...
```

**模块级常量**（文件头带 `#:` 文档，同 image_viewer 先例，AFCP 3.4）：

```python
PDF_EXTS: frozenset[str] = frozenset({"pdf"})
#: 缩放步进与区间（步进值与图片页手感一致）
ZOOM_STEP = 1.25
ZOOM_MIN = 0.1
ZOOM_MAX = 8.0
#: 连续滚动页间距（px）
PAGE_SPACING_PX = 6
#: QPdfDocument.Error → 中文原因映射（加载失败回落占位提示用）
LOAD_ERROR_REASONS: dict[QPdfDocument.Error, str] = {...}
```

核心逻辑：

| 能力 | 实现 |
|:---|:---|
| 加载 | `QPdfDocument.load(str(path))` 返回 `QPdfDocument.Error`；`None` 为成功，其余经 `LOAD_ERROR_REASONS` 映射表查中文原因（`IncorrectPassword`→"PDF 已加密"、`InvalidFileFormat`→"文件损坏或格式非法"、`FileNotFound`→"文件不存在"；表外兜底 "未知错误"） |
| 显示 | `QPdfView.setDocument(doc)`；`setViewMode(QPdfView.ViewMode.MultiPage)`（决策锁定，连续滚动） |
| 缩放 | `ZoomMode.Custom` 下 `setZoomFactor` 步进 1.25×（与图片页手感一致），钳制 0.1–8.0；`fit_width()`/`fit_page()` 切对应 `ZoomMode`；`zoomFactorChanged` 信号刷新弱提示 |
| 页码 | `QPdfNavigator`（`pdfView.pageNavigator()`）`jump(currentPage ± delta)`；`currentPageChanged` → `page_info_changed` 发 `第 i/N 页 · 缩放%` |
| 重载状态保持 | `open_pdf` 前经私有 `_capture_view_state()` 记录旧文档 `currentPage`/`zoomFactor`/`zoomMode`（`@dataclass(frozen=True) _ViewState` 三字段承载，AFCP 3.1 数据结构显式），同路径重载（外部修改）经 `_restore_view_state()` 恢复，异路径重置为默认（fit_width 初始）；`open_pdf` 函数体 ≤50 行（AFCP 2.1 结构线） |
| 文本选择 | `QPdfView` 内建（鼠标拖选 + Ctrl+C 复制），零实现成本 |
| 外部打开 | `QDesktopServices.openUrl(QUrl.fromLocalFile(str(path)))`，返回值 False → `external_failed` 信号 → 面板弱提示 |
| 主题 | `apply_theme(palette)` 设置视口背景刷（取现有 `chrome` 令牌派生，**不新增令牌**，与 ImageViewer 同模式）；页间距取 `PAGE_SPACING_PX` 常量 |
