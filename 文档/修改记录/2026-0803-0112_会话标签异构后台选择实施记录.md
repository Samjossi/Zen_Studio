## 2. 各文件改动摘要

### `gui/panels/chat/tabs.py`（核心重构）

- **废除广播**：`_broadcast_selection` 删除。`_on_selection_changed(sender, backend, version)`
  改带发射者参数（`add_tab` 接线改 lambda 闭包携带 panel），仅当 sender 为当前活动标签时
  更新注入值与写盘（防御性校验；非活动标签不存在用户操作路径）；随后调
  `sender.set_model_selection(backend, self._version)` 完成**本标签** provider 切换
  （此步原经广播路径完成，漏调则 provider 永不切换——实施中识别的关键补全）。
- **新建注入值**：`_backend/_version` 语义收缩为「下一个新建标签的初始选择 + 重启默认」，
  来源 = 最近一次用户显式切换（任一入口）；持久化一期语义不变（`KEY_MODEL_BACKEND` +
  记忆表写「最近使用值」，零 schema 迁移）。
- **菜单作用域**：`apply_model_selection` → 当前活动标签 `set_model_selection`
  （传解析后的注入值，与改造前广播路径语义一致）；零标签只更新注入值 + 写盘 +
  `selection_changed`（设置中心展示注入值）。回退后有效值以 ModelBar 为准回发。
- **busy 收窄**：`_recompute_busy` 删除。`_on_tab_busy` 只 `panel.model_bar.set_busy`
  本标签；`busy_changed` 仅当该标签为当前时重报。新增 `_on_current_changed` 槽
  （`currentChanged` 接线）：切标签重报当前标签忙闲 + 当前标签选择（设置中心禁用态
  与展示值双跟随）。`is_busy()` 改答「当前活动标签响应中」。全关时显式
  `busy_changed.emit(False)` 防设置中心残留禁用态。`add_tab` 末尾显式
  `set_busy(False)` 防响应中新建标签继承禁用态。
- **标签标题**：`_tab_title(panel)` 拼「会话 N · {vendor_label}」（`VENDOR_LABELS`，
  未知 backend 回退原名）；序号簿记 `_tab_numbers: dict[ChatPanel, int]`（关闭随 panel
  剔除）；更新点 = 新建 + `_on_selection_changed` + `apply_model_selection` 三处。
- **查询接口语义升级**：`current_backend()/current_version()` 改答「当前活动标签
  ModelBar 有效值」（零标签回退注入值）——设置中心 T5 回读点。

### `gui/main_window.py`（注释级）
