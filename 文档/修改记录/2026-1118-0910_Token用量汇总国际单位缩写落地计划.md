# Token 用量汇总国际单位缩写落地计划

依据选型文档 `2026-1118-0910_Token用量汇总数字缩写方案选型.md` 的 R1~R4 决策（方案一：K / M / B 国际缩写，用户拍板），落地以下改动。

## 一、改动内容

### 1.1 新增公共纯函数 `format_token_amount()`

位置：`src/ide/core/token_stats.py`（零 Qt 依赖模块，便于单测与后续复用）。

分段规则：

| 区间 | 规则 | 示例 |
|:---|:---|:---|
| < 1,000 | 千分位原样 | `3,113` 不可达此档（≥1,000 才缩写）；`999` → `999` |
| < 1,000,000 | 转 K，至多 1 位小数并去尾零 | `3,113` → `3.1K`；`86,500` → `86.5K`；`500,000` → `500K` |
| < 1,000,000,000 | 转 M，至多 1 位小数并去尾零 | `368,598,460` → `368.6M`；`1,000,000` → `1M` |
| ≥ 1,000,000,000 | 转 B，至多 2 位小数并去尾零 | `1,200,000,000` → `1.2B`；`12,500,000,000` → `12.5B`；`12,250,000,000` → `12.25B` |

约束：

- 只接收非负 int，输入为其他类型抛 `TypeError`（与模块现有“非法输入不静默”的风格一致）。
- 纯函数、无副作用、无 I/O；不引入第三方依赖。
- 进位边界行为：格式化后允许出现 `999,999 → 1000K`、`999,999,999 → 1000M` 这类跨档进位，属可接受简写，不做回退档处理。
- 不改动 `UsageSummary`、`DayUsage`、`summarize()` 等数据结构与口径。

### 1.2 底部汇总标签接入

位置：`src/ide/gui/token_usage_dialog.py` 的 `TokenUsageDialog.reload()`。

将：

```python
# src/ide/gui/token_usage_dialog.py
self._summary_label.setText(
    f"今日用量 {summary.today:,} tokens　　"
    f"最近七天用量 {summary.last_7_days:,} tokens　　"
    f"最近三十天用量 {summary.last_30_days:,} tokens")
```

改为经 `token_stats.format_token_amount()` 格式化后的三项文本，其余布局、`tokens` 后缀、全角分隔空格不动。

### 1.3 保持不变的部分

- 格子 tooltip（`_tooltip_text()`）：继续显示精确千分位数字（输入/输出分项、分后端小计），缩写只用于底部汇总。
- 落盘 schema、`load_daily()`、`record_turn()`、分档 `level_of()`：一律不动。
- 弹窗尺寸、主题自适应（`apply_theme` / `refresh_font`）不动。

## 二、测试

在 `tests/test_token_stats.py` 追加针对 `format_token_amount()` 的参数化用例，至少覆盖：

- 零值与小数：`0` → `0`；`999` → `999`。
- K 档边界：`1,000` → `1K`；`3,113` → `3.1K`；`86,500` → `86.5K`；`500,000` → `500K`；`999,999` → `1000K`（进位边界）。
- M 档边界：`1,000,000` → `1M`；`368,598,460` → `368.6M`；`999,999,999` → `1000M`（进位边界）。
- B 档：`1,200,000,000` → `1.2B`；`12,500,000,000` → `12.5B`；`12,250,000,000` → `12.25B`。
- 尾零去除：`30,000` → `30K`，不得出现 `30.0K`。
- 非法输入：`float`、`str`、`None`、负数抛 `TypeError`。

既有用例（`tests/test_token_stats.py`、`tests/test_token_usage_dialog.py`、`tests/test_merge_token_usage.py`）必须全部保持通过。

## 四、风险与回退

- 风险低：纯显示层改动，数据链路零触碰；回退即撤销两处改动（函数 + `reload()` 格式化调用）。
- 已知取舍：`1B = 10亿` 与中文「亿」相差一个数量级，中文用户需自行换算，此为选型时已确认接受的代价；tooltip 的精确数字可兜底查证。
- 注意 `format_token_amount()` 命名与行为一旦发布，其他面板（如 Token 单价对比）可能复用，语义需保持稳定。
