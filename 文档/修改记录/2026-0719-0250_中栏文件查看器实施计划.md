## 1. 目标

按选型报告落地中栏（上）文件查看面板：文件树双击 → 中栏显示文件内容 + 语法高亮；AI-first **永久只读**定位；外部修改（AI 写盘）自动重载。

## 2. 设计要点（摘自选型报告第 5 节）

| 点 | 决策 |
|:---|:---|
| 子包 | `gui/panels/viewer/`：`CodeViewer`（只读 + 行号栏 + 当前行高亮）+ `PygmentsHighlighter` + `ViewerPanel`（标题行 + watcher） |
| 高亮 | 整文档一次 lexing → 区间缓存，`highlightBlock` 按块二分取格式（多行 token 天然正确）；未知扩展名回退纯文本 |
| 行号 | lineNumberArea 经典模式（人与 AI 的对话坐标系） |
| 重载 | `QFileSystemWatcher` + 150ms 防抖，保留滚动位置，标题行提示 |
| 主题 | 明暗双配色表（高亮 PALETTES + 控件 CHROME），`apply_theme` 联动重建 |
| 守卫 | >1 MB 截断提示；二进制占位提示 |
| 剔除 | 代码折叠（本期）；Markdown/图片预览（备案）；编辑/保存/补全（永久剔除） |

## 4. 验证标准

| 项 | 标准 |
|:---|:---|
| Python 高亮 | 打开 .py：关键字/字符串/注释等着色正确，行号栏与当前行可见，标题行显路径 |
| Markdown | 打开 .md：标题加粗、代码段着色 |
| 二进制 | 打开非 UTF-8 文件：占位提示"二进制文件"，不乱码不上屏 |

| 自动重载 | 外部改写当前文件：150ms 防抖后自动重载、内容更新、提示"已重新加载" |
| 主题 | 切换暗色：高亮配色与行号/当前行配色同步切换，无残色 |

## 5. 风险与对策

| 风险 | 等级 | 对策 |
|:---|:---:|:---|
| 大文档 lexing 耗时 | 🟡 | 1 MB 守卫封顶；区间缓存使 rehighlight 为 O(块命中区间数) |
| watcher 漏报（rename 替换保存） | 🟢 | 重载时重建监视路径；防抖合并多次触发 |
| 高亮配色与 qss 主题不协调 | 🟢 | 双配色表同源色板；走查双主题截图确认 |
