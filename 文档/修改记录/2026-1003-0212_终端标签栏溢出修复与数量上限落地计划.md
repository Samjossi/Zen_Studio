> **优先级**：中
> **前置文档**：
> - `work options/2026-1003-0206_终端标签栏溢出处理方案选型.md`（已拍板：方案 A + 方案 C，上限 40）

## 1. 需求/背景

用户实机反馈：中栏底部终端面板开太多终端后，标签栏把布局向左右顶宽，左栏被压窄（现象学名：标签栏溢出 tab overflow）。已拍板组合方案：

- **方案 A（根治）**：标签栏开省略号压缩，斩断"最小宽度随标签数线性增长"的死结；
- **方案 C（防呆兜底）**：终端标签总数上限 `MAX_TABS = 40`（暂定），到顶禁用 `+`。

## 2. 现状梳理

### 2.1 根因（调研已确认）

`src/gui/panels/terminal/panel.py` 的 `_build_header`：裸 `QTabBar`，`setUsesScrollButtons(False)`（2026-0818-1111 计划定版，用户嫌原生滚动箭头方向感反转），但**从未设 `setElideMode`**——Qt 默认 `ElideNone`，每个标签最小宽度含完整标题 + 关闭钮，`minimumSizeHint` 随标签数线性增长，沿"标签栏 → 头部栏 → PanelCard → TerminalPanel → 中栏 QSplitter"逐级顶宽，把左栏压到 460 下限。AI 会话标题 `🤖 <命令名>` 长度不可控，加剧膨胀。

注意：现有注释（"关滚动后 tab 压缩宽度挤入可视区，文字省略号兜底"）描述的是**期望行为而非实际行为**——未设 elideMode 且未解除最小宽度上报时，Qt 不会压缩标签，这正是死结的成因，注释需随本次改动一并修正。

### 2.2 新建会话入口清单（上限守卫需全覆盖）

| 入口 | 调用链 | 口径 |
|:---|:---|:---|
| 头部 `+` 按钮 | `_btn_new.clicked → _spawn` | 用户会话 |
| 终端菜单"新建终端" | `new_session → _spawn` | 用户会话 |
| 右键"重开"（无会话时） | `_restart_active → _spawn` | 用户会话 |
| 首启自动 spawn | `eventFilter → QTimer → _spawn` | 用户会话 |
| ACP AI 会话 | `AgentTerminalBridge._create_gui → spawn_agent_session` | AI 会话 |

用户会话四个入口全部收敛于 `_spawn`，单点守卫即全覆盖；AI 会话走 `spawn_agent_session`，需独立守卫。

### 2.3 AI 会话满员失败的协议出路（已确认安全）

`src/llm/providers/acp.py` 的 terminal 方法分发处对 handler 异常有兜底：`except Exception → _reply_error(request_id, -32603, ...)`。因此 `spawn_agent_session` 满员抛 `RuntimeError` 会经 `AgentTerminalBridge._invoke_gui` 透传为 ACP `-32603` 错误应答，agent 收到"terminal/create 失败"而非永久阻塞——语义诚实、链路已有先例，无需改 acp.py。

### 2.4 可复用先例

- `+` 钮达上限禁用 + tooltip 模式：仿 `src/gui/panels/chat/tabs.py` 的 `_refresh_add_button`（ChatTabs.MAX_TABS=4 同款交互）。
- 省略号压缩后完整标题的可读性兜底：`QTabBar.setTabToolTip`（Qt 原生，悬停显示完整标题）。

## 3. 方案设计

### 3.1 方案 A：省略号压缩（`_build_header` 内，两处配置）

1. `self._tab_bar.setElideMode(Qt.TextElideMode.ElideRight)`——Qt 计算最小标签尺寸时改用省略后文本，单个标签最小宽度从"完整标题"降为"省略号 + 关闭钮"。
2. 标签栏水平 Size Policy 改 `Ignored`（保留垂直向原值；`row.addWidget(self._tab_bar, 1)` 的 stretch 不变）——`minimumSizeHint` 不再约束布局，中栏最小宽度与标签数彻底解耦；标签多于可视宽度时 Qt 在栏内挤压省略（关滚动箭头后的原生挤压行为），不再外溢顶宽。
3. `_spawn_entry` 内 `addTab` 后补 `setTabToolTip(idx, session_entry.title)`——标签被省略后悬停仍可读完整标题（AI 会话长标题的主要可读性出口）。

### 3.2 方案 C：MAX_TABS = 40（上限守卫）

1. `panel.py` 模块级常量 `MAX_TABS = 40`（命名对齐 ChatTabs.MAX_TABS；why 注释：防呆兜底线，非正常使用约束）。
2. `_spawn` 开头守卫：`self._tab_bar.count() >= MAX_TABS` 时直接 return（覆盖 §2.2 全部用户入口）。
3. `spawn_agent_session` 开头守卫：满员抛 `RuntimeError(f"终端数量已达上限（{MAX_TABS}）")`——经桥透传为 ACP -32603（§2.3），agent 收到明确失败原因。
4. `+` 钮启停：新增 `_refresh_new_button()`（仿 ChatTabs `_refresh_add_button`），`count >= MAX_TABS` 时禁用并 tooltip "终端数量已达上限（40）"，否则恢复"新建终端"；在 `_spawn_entry`、`_close_tab` 与 `_refresh_nav_buttons` 同点位调用维护。

### 3.3 注释同步（why-only，符合 AGENTS.md 注释规范）

- `_build_header` 现有"文字省略号兜底"注释改写为真实机制说明（elide + Ignored 策略，为什么这样才不会顶宽布局）。
- `_spawn` / `spawn_agent_session` 守卫处各加一条 why 注释（防呆上限、ACP 失败语义出路）。

### 改动清单

1. `src/gui/panels/terminal/panel.py`：`MAX_TABS` 常量；`_build_header` 加 elide + Size Policy；`_spawn_entry` 加 tooltip + `_refresh_new_button()` 调用；`_spawn`/`spawn_agent_session` 守卫；`_close_tab` 补 `_refresh_new_button()`；注释同步。
2. `tests/test_terminal_tabs.py`（新）：offscreen 单测（见 T2）。

- 不改 `◀ ▶` 按钮语义与位置（2026-08-18 用户定版）。
