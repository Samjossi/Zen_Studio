## 1. 背景与目标

DSH 官方 `standard` 预设当前有 **31 个工具**（含 `glob` / `grep`）。IDE 已登记 19 个（其中 11 个与官方交集、8 个是兼容别名），另有 **20 个未登记**：`create_goal` / `get_goal` / `update_goal`、`exit_plan_mode`、`ask_user_question`、`list_agents` / `send_message` / `interrupt_agent` / `subagent_fork`、`job_list` / `job_output` / `job_kill`、`schedule_create` / `schedule_list` / `schedule_update` / `schedule_delete`、`present` / `skill` / `workflow` / `working_directory`。

这些未登记工具当前全部落 `McpCard`，图标 🧩，body 是 MCP 的「入参/出参」样式；用户已在真实会话中看到 `get_goal` / `update_goal` 的兜底形态。

本计划目标：

1. **31 个官方工具全部有明确落卡与图标**，不再有官方工具落 🧩。
2. 按语义分组建立专用卡：goal / plan / ask / job / agent control / schedule / skill / workflow / working dir / present。
3. 保留 8 个现有兼容别名（`pwsh` / `shell` / `terminal` / `patch` / `fs_search` / `web` / `fetch` / `task`）的既有映射，不因对齐而回退。
4. 图标继续遵守「按卡片类型分型、组内按动作细分」的原则；MCP `mcp__` 仍 🔌，未知工具仍 🧩。
5. 用单测锁 31 行矩阵，用截图锁每个工具的可见形态，并同步维护手册与测试记录。

本轮只写计划，不实施；审阅通过后再按 §5 执行。

| Q4 | 截图粒度 | 31 个工具各 1 张 | 按组拼图，减少张数 |

> Q1–Q4 只影响卡类数量与截图数量，不改变「31 个工具全部有明确落卡与图标」的目标。

## 9. 不在本轮范围

- Kimi / Local 的工具与图标（各自维护）。
- 公共 `_KIND_ICONS`、公共 `ToolCard` 构造签名、统一 `card_kind` 的重建。
- ACP 传输层、权限、会话存档、update mapper 的协议字段语义。
- 运行时图标配置、设置界面、新依赖。
- `present` 的文件打开/预览行为；`workflow` 的编辑器/可视化编排。
- Git 提交、推送与远程操作。
