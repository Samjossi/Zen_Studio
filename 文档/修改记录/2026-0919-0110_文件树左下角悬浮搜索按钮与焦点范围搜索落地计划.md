## 1. 需求

文件树右下角已有悬浮刷新按钮（见 `2026-0916-1353_文件树右下角悬浮刷新按钮落地计划.md`，已落地）。现要求在**左下角镜像增加一个悬浮搜索按钮**：

1. 点击后展开**一行搜索栏**，供用户输入关键词。
2. 搜索范围 = 文件树当前**焦点（选中/点亮）所在位置**：选中项为目录则搜该目录之下，选中项为文件则搜其父目录，无选中则搜根目录。
3. 图标字符用 `⌕`（U+2315）。该字形本身比刷新钮的 `⟳` 小，qss 字号要相应放大，使两者视觉墨盒相当。

## 2. 现状梳理

### 2.1 刷新按钮范式（本次 1:1 镜像复用）

`gui/panels/file_explorer/explorer.py` 中刷新钮的完整实现：

- 顶部常量区 `_REFRESH_BTN_MARGIN = 16` / `_REFRESH_BTN_SIZE = 32` / `_REFRESH_BTN_OPACITY = 0.5`。
- `_build_refresh_button()`：`QToolButton` parent 挂面板自身、objectName `FileTreeRefreshButton`、`setText("⟳")`、`ToolButtonTextOnly`、`QGraphicsOpacityEffect` 常态 0.5、`installEventFilter`。
- `_place_refresh_button()` 右下角手动 `move` + `raise_()`；`resizeEvent` 重定位；`eventFilter` 处理 Enter/Leave 透明度（含 `getattr` 早构造守卫）。
- `assets/themes/base.qss` 一条 `#FileTreeRefreshButton { padding: 0; border-radius: 16px; font-size: 22px; }` 规则，背景/hover 吃全局 `QToolButton`。

搜索钮完全照抄该模式，仅定位镜像到左下角、图标与字号不同。

### 2.2 面板布局与搜索栏插入点

`FileExplorer.__init__` 的布局为 `QVBoxLayout`：header（根目录名）→ `self.tree`，外边距 6px。搜索栏作为**树之下的一整行**插入布局（`layout.addWidget(search_bar)`），默认隐藏，点搜索钮显示并聚焦。

注意：悬浮钮定位用面板坐标（`self.height() - margin`），搜索栏显示后会占底部一行高度，两个悬浮钮须同步上移，否则会压住搜索栏（见 §3.4）。

### 2.3 树模型背景

- `QFileSystemModel` + `GitStatusProxyModel` 代理；`refresh()` 会重建模型实例并发射 `model_rebuilt` 信号（消费方须重新接线）。
- 树懒加载：未展开目录的节点模型里可能尚不存在，因此「在模型里找匹配」不可靠，搜索须直接扫文件系统（`os.walk`），命中后再让树展开定位（见 §3.3）。

## 3. 方案

### 3.1 悬浮搜索钮（左下角，镜像刷新钮）

- 常量：复用 `_REFRESH_BTN_SIZE/MARGIN/OPACITY` 数值，新增 `_SEARCH_BTN_*` 同名常量（数值相同，命名独立，便于日后单独微调）。
- `_build_search_button()`：objectName `FileTreeSearchButton`、`setText("⌕")`、toolTip「搜索文件树」、`clicked.connect(self._toggle_search_bar)`，透明度与 eventFilter 模式照抄刷新钮。
- `_place_search_button()`：左下角定位 `btn.move(_SEARCH_BTN_MARGIN, self.height() - btn.height() - _SEARCH_BTN_MARGIN - 底部偏移)`，`resizeEvent` 中两个钮一起重定位；`eventFilter` 增加对搜索钮的 Enter/Leave 分支。

### 3.2 搜索栏（一行）

- `_build_search_bar()`：`QLineEdit`，objectName `FileTreeSearchBar`，placeholder「搜索当前位置…」，默认 `hide()`，加入布局树之下。
- `_toggle_search_bar()`：隐藏→显示并 `setFocus()`；已显示→隐藏并清空状态（匹配列表、当前命中序号）。
- `Esc` 关闭搜索栏：给搜索栏 `installEventFilter`，KeyPress 为 Esc 时收起（焦点同时回树）。
- qss：搜索栏样式吃全局 `QLineEdit` 规则，仅按需追加 `#FileTreeSearchBar` 微调段（无则不添）。

### 3.3 搜索逻辑（跳转定位式，非过滤树）

**范围确定**（实施时修正为快照机制）：搜索栏展开时对焦点位置取**范围快照** `_search_scope`（目录搜其下，文件搜父目录，无焦点搜根）；之后用户在树上手动改选才更新快照（`currentChanged` 槽内以 `_search_revealing` 标志排除程序化点亮）。**不用懒计算**：点亮命中项会改 `currentIndex`，懒计算会让范围随命中位置收窄，导致后续输入搜不到原范围内的其它匹配。

**匹配** `_collect_matches(text)`：对范围目录 `os.walk` 自顶向下遍历，**文件名大小写不敏感子串匹配**，按遍历顺序收集相对路径；上限 `_SEARCH_MAX_RESULTS = 200`（防爆：大目录一次扫完可能卡顿，超限即截断并在搜索栏 placeholder 或 tooltip 提示已截断）。空串清空匹配。

**定位** `_reveal_match(path)`：由绝对路径逐级 `expand` 代理索引并 `setCurrentIndex` + `scrollTo`，即「点亮」命中项。`QFileSystemModel` 懒加载，展开后节点异步填充，沿用 `directoryLoaded` 接力思路：展开一层后若子索引尚不可用，等 `directoryLoaded` 回调继续向下钻取（复用 refresh 回填的同款异步接力模式）。

**交互**：

- `textChanged` → 重新收集匹配 → 命中则定位第 1 个；无命中时搜索栏文字与边框变警示色（qss 动态属性 `noMatch=true` 触发，色取 Git 状态色 deleted `#c0392b`，不落新调色板键）。
- `Enter` / `Shift+Enter`（搜索栏 eventFilter 内处理）→ 循环定位下一个 / 上一个命中。
- 树选中变化不主动重搜，仅更新范围快照；下次输入或 Enter 按新范围搜。

**与 refresh 的联动**：`model_rebuilt` 后索引全部失效，搜索状态（匹配列表、当前序号）清空，搜索栏文本保留（用户关键词不丢），下次 Enter 按新模型重搜。

### 3.4 悬浮钮与搜索栏的纵向避让

搜索栏可见时，两个悬浮钮的定位从「距面板底缘 margin」改为「距搜索栏顶缘 margin」：

```python
# gui/panels/file_explorer/explorer.py
def _floating_bottom_offset(self) -> int:
    """悬浮钮底部让位量：搜索栏展开时抬到栏顶之上，避免遮挡。"""
    bar = getattr(self, "_search_bar", None)
    if bar is not None and bar.isVisible():
        return _SEARCH_BTN_MARGIN + bar.height()
    return _SEARCH_BTN_MARGIN
```

`_place_refresh_button()` 与 `_place_search_button()` 统一改用该偏移；搜索栏显隐时（`_toggle_search_bar`）手动重定位一次（栏高度变化触发面板 resize 的场景靠 `resizeEvent` 兜底）。

### 3.5 字号处理

`⌕`（U+2315）字形墨盒明显小于 `⟳`（22px）。qss 规则初值：

```css
/* assets/themes/base.qss */
#FileTreeSearchButton {
    padding: 0 0 8px 3px;
    border-radius: 16px;
    font-size: 30px;
}
```

初估 28px，T3 截图校准至 30px（与刷新钮视觉大小相当）；⌕ 贴文本基线渲染导致墨心偏下，实机走查后以不对称 padding（左 3 / 底 8）把墨心推回钮中心（像素级实测校准）。

### 3.6 改动清单

1. `gui/panels/file_explorer/explorer.py`
   - 常量区加 `_SEARCH_BTN_SIZE/MARGIN/OPACITY`、`_SEARCH_MAX_RESULTS = 200`。

   - `_build_search_bar()`、`_toggle_search_bar()`、`_search_scope_dir()`、`_collect_matches()`、`_reveal_match()`、`_on_model_rebuilt_reset_search()`（接 `model_rebuilt`）。
   - **不动**：`refresh()`、树构建、Git 状态代理、右键动作集。

## 5. 影响面评估

- ✅ 纯新增：按钮、搜索栏、搜索方法均为新段落；`refresh()`、树构建、Git 着色零改动。
