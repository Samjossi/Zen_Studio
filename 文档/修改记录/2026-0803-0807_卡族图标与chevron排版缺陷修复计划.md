# 卡族图标与 chevron 排版缺陷修复计划

## 1. 背景

0741 修复（body 空白）真机收尾验证时，用户实机截图发现卡族 header
三类视觉缺陷：

1. **chevron（▸ 展开符号）被挤成一条竖线**——每张卡左侧开合指示不可读，
   开合可用性受损；
2. **Read/搜索/抓取卡图标是方框**——用户疑「图标没显示出来/变成方框」；
3. 用户要求顺带全面检查其他排版问题（图标对齐、状态图标、协议标题
   透传 emoji 等）。

用户拍板沿用 0741 方法论：offscreen 截图 + 多模态视觉查看 + 诊断先行，
诊断清楚后立项本文，拍板后再修。

**关键前提修正**：0741 及此前全部 offscreen 走查**未加载真实主题 QSS**
（裸 Qt 默认样式），与实机渲染环境不同——本缺陷正是该盲区漏出的
（见 §2 实证：同一代码加载 QSS 前后 chevron 形态完全不同）。本次
走查脚本 `.temp/shot_card_icons.py` 已改为 `apply_theme` 全量加载
（真实 QSS + 内置字体注册），与实机渲染环境对齐。

## 3. 根因（已定位，实证）

### 3.1 chevron 挤压：全局 QSS padding 吃掉固定尺寸内容盒

`assets/themes/base.qss` 全局规则：

```css
QToolButton { background-color: …; border: 1px solid …;
              border-radius: 6px; padding: 2px 8px; }
```

chevron 是 `QToolButton` 且 `setFixedSize(20, 20)`：水平方向
padding 8+8=16px + border 1+1=2px = **18px 被装饰吃掉，内容盒只剩
≈2px**——"▸"（字宽 7px 余）被裁成一条竖线。附带效应：
`setAutoRaise(True)` 被 QSS 覆盖，chevron 渲染成带边框实体小盒，
与 0640 轻量折叠符的设计意图不符。

裸 Qt 样式（无 QSS）下 padding 极小，20px 放得下 ▸——所以 0645/0741
两轮 offscreen 走查（未加载 QSS）全部漏诊。**验证环境盲区是共因**，
已由 shot_card_icons.py 永久填堵（§5 T5 纳入回归）。

### 3.2 方框图标：占位符从未被设计成真图标

`_KIND_ICONS`（cards.py:57）：

```python
"read": "☐", "search": "☐", "fetch": "☐", "other": "☐"   # U+2610 空投票箱
"execute": "$", "edit": "✎", "think": "⧉"
ThinkingCard icon "…"；TodoCard "☑"
```

read/search/fetch/other 四个 kind 共用 U+2610「空投票箱」字符**本体**
——用户看到的方框不是字形缺失（豆腐块），是这个占位字符的长相。
字形覆盖实测（`QRawFont.supportsCharacter`）：

- 内置思源黑体**覆盖**：现用全部符号（▸▾◐✔✖✎☐☑⧉…）及候选
  ≡▤❏⌕↧⇓⤓↓⬇✦❖◆⬡⚙⬢◈⌘✏✐▶▼›⌄❯ 等；
- **不覆盖**彩色 emoji：📄🔍🌐💭🧠📎🖼——实机能显示全靠系统回退
  字体，跨平台形态不可控，**emoji 路线不可用**。

### 3.3 协议标题透传 emoji（用户第二截图 🌐/👓 来源）

卡 header 的 title 文本来自协议 `title` 字段原文透传（acp.py 路由层
零加工）；agent 侧（MCP 工具等）标题自带 emoji，经系统回退字体渲染，
形态随平台漂移。**不在卡族图标体系内**，需实机抓帧确认来源帧后
另行决策（剥离/保留/映射），本计划只记录不扩散（§7）。

### 3.4 影响面

chevron 是 CollapsibleCard 基类成员——**全部可折叠卡**（bash/diff/
read/search/fetch/think/MCP/thinking）无一幸免；图标缺陷影响
read/search/fetch/other 四 kind + ThinkingCard 语义弱化的 "…"；
对齐漂移影响全部卡。修复点收敛于 cards.py 一处，全族共益。

## 4. 修复方案（待拍板）

### 4.1 技术方案

**chevron（D1）**：chevron 设 objectName（如 `ChatCardChevron`）+
局部 `setStyleSheet` 覆盖：`background: transparent; border: none;
padding: 0px;`——恢复 autoRaise 轻量文本钮形态，20×20 内容盒全量
可用。不动全局 QSS 的 QToolButton 实体化范式（惠及他处，§7）。

**图标集（D2/D3，0830 拍板翻案）**：**思源黑体保留 + 内置 Noto Color
Emoji 回退链 + 全 header 图标彩色 emoji 化**（用户拍板：彩色 emoji
更显眼）。实施要点：

- 字体资产：`assets/fonts/Noto彩色Emoji/NotoColorEmoji.ttf`（CBDT 彩色
  位图，10.1M，SIL OFL-1.1 随目录归档 LICENSE.txt/README.md），
  `gui/theme.py` 新增 `EMOJI_FONT_FILES` 注册；**不设任何控件显式
  字体**——Qt 回退链自动拼接（思源缺 emoji 字形时自动选用），
  顺带把既有 📎（附件按钮）/🖼（附件缩略图）从「系统字体施舍」转正
  为内置受控资产；
- **实证先行**（0830 探针）：注册后 11 个 emoji 全量彩色渲染成功
  （`.temp/shots/noto_emoji_probe.png` 多模态核验）；已知怪癖——
  `QRawFont.supportsCharacter` 对 CBDT 位图字体误报 False，实际
  光栅化正常，**字形覆盖探测方法勿用于 emoji**（已写入族 README）；
- 打包链路同步：`zen-studio.spec` datas 收编新族、`build_appimage.sh`
  解包冒烟补 LICENSE/ttf 两条 want、`NOTICE` 补字体条目、
  `assets/fonts/README.md` 族表更新（产物约 104M→114M）；
- 选品纪律：全部选**默认 emoji 呈现的单码点字形**（无需 VS16），
  状态图标 ◐/✔/✖ 与 chevron ▸/▾ **保持单色**（吃 tool_fg/tool_error_fg
  主题色语义，彩色 emoji 会破坏）。
