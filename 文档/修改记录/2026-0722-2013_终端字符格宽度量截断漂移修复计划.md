### 1.3 根因链

`widget.py::__init__/refresh_font`（当前 77/129 行附近）：

```python
font_metrics = self.fontMetrics()                    # QFontMetrics（整数度量）
self._cell_width = max(1, font_metrics.horizontalAdvance("M"))  # 8.484 → 8（截断）
```

1. **网格用整数度量**：Sarasa Term SC 13pt 的 M 前进宽 8.484px 被
   `QFontMetrics`（int 接口）截断为 **8px**，字符格宽 = 8px；
2. **文本用浮点度量排版**：`QPainter.drawText` 在 xcb 光栅引擎上按字体
   **设计浮点前进宽 8.484px** 逐字排布（run 合并绘制放大此效应——
   `_paint_grid` 同色格合并为一趟 drawText，漂移在 run 内逐字累积）；
3. **每字 +0.484px 漂移**：提示符第 51 字处文本比网格靠右 ≈25px（≈3 格）。
   后画的 run 覆盖先画 run 的尾巴 → `$` 盖住蓝字 "i"；网格对齐的光标块
   盖住蓝字 "o" 右半 → 残片即需求方看到的"不明符号"；冒号被绿色 run
   尾巴吞掉；
4. **offscreen 不可见的原因**：offscreen QPA 字体引擎的度量与绘制自洽
   （无此截断差），真实桌面 xcb 才暴露——与《1725 走查》"offscreen
   弱化平台差异、须实机走查"教训同类，本案为**度量类**平台差异首例。

## 2. 修复方案（P1 单期，三处改动）

### P1 🔴 格宽改浮点度量（与绘制引擎同源）+ 两个整数消费点收敛

**widget.py（`__init__` 与 `refresh_font` 两处同构，同步改）**：

```python
# 格宽须与 drawText 排版度量同源（浮点设计前进宽）；
# QFontMetrics 为 int 接口会截断 8.484→8，逐字累积漂移（2026-0722-2013 计划）
metrics_f = QFontMetricsF(font)
self._cell_width = max(1.0, metrics_f.horizontalAdvance("M"))
font_metrics = self.fontMetrics()
self._cell_height = max(1, font_metrics.height())
self._ascent = font_metrics.ascent()
```

- `_cell_height` / `_ascent` **维持 int**：垂直方向每行独立定位
  （`py = y * cell_height` + 行内基线），无行内累积路径，不在本案缺陷面
- 绘制侧（`_paint_grid` / `_paint_cursor` / `_paint_selection` /
  `_paint_search_runs`）的 `x * cell_width` 乘法天然兼容 float
  （PySide6 fillRect/drawText 有 QRectF/QPointF 重载，探针 9 实证）

**widget.py `get_grid_size`**：`//` 对 float 返回 float，补 int 收敛
（screen.resize / session.resize / setPageStep 均需 int）：

```python
column_count = max(1, int((self.width() - bar_width) // self._cell_width))
row_count = max(1, int(self.height() // self._cell_height))
```

**selection.py `pos_to_cell`**：除法结果补 int（选区坐标下游作切片索引，
float 会 TypeError）；签名类型 `cell_w/cell_h: int` → `float`：

```python
x = min(max(int(px // cell_w), 0), column_count - 1)
y = min(max(int(py // cell_h), 0), row_count - 1)
```

### 明确不改

- pyte buffer / PtySession / bash 配置：字节流与屏幕模型经探针 1/2/3 证伪；
- run 合并绘制优化：浮点格宽后 run 起点与逐字排版同源，对齐天然成立，
  不退回逐格绘制；
- `_cell_height` 浮点化：无缺陷面，不扩大改动。

## 5. 风险与回滚

| 风险 | 评估与对策 |
|:--|:--|
| 浮点格宽击穿某个 int 假设的消费点 | 全库仅三处除法/尺寸消费（§2 已尽数收敛）；绘制乘法 float 兼容经探针 9 实证；验证 3 兜底 |
| 网格列数变化（同窗口宽下列数可能 -0~1） | 8.484 > 8，列数略减属正确行为（此前是"虚列"——文本根本画不满）；resize 链按既有 SIGWINCH 重绘语义自适应 |
| 选区/查找高亮矩形与字形轻微错位（亚像素） | 高亮为半透明染色，亚像素级偏差不影响可读性；光标块验证图确认对齐 |
| 回滚 | 改动集中两个文件三个函数，`git revert` 即还原 |
