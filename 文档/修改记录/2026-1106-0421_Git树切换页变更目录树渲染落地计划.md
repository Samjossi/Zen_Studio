# Git 树切换页变更目录树渲染落地计划

> **状态**：草稿（待审阅）
> **范围**：右栏上 `FileExplorer` 的 Git 页、变更目录树控件与纯数据建树、主题样式、测试和 GUI 文档；不改右栏下 `ChangesPanel` 的外观与行为
> **时间**：2026-11-06 04:21（设计，UTC+8）
> **优先级**：中

## 1. 需求

依据已选定的 `2026-1105-2317_Git树切换页变更目录树渲染方案选型.md` 方案 A，将右栏上 Git 页从扁平 `ChangesList` 升级为独立的 `QTreeWidget` 原生变更树：

1. 默认按仓库相对路径展示目录层级，并提供小型“目录树 / 列表”切换；模式仅在当前控件会话内保留，不写设置文件。
2. 树模式显示目录图标、文件图标、文件名和增删统计；目录优先，同层按名称确定性排序。
3. 列表模式显示文件图标、文件名、弱化父目录和增删统计，不再用一整条长路径占据首列。
4. 保留 M/U/D 等状态色、删除线、完整相对路径 tooltip，以及 M/U 打开差异、D 删除提示、其他文件进入查看器的双击语义。
5. Git 刷新和主题重绘后按稳定路径恢复展开目录、选中文件与滚动位置；已消失节点自然丢弃。
6. 继续消费 `GitStatusController.refresh()` 聚合的同一份 `ChangeEntry` 快照，不增加 Git 查询、watcher、定时器或第二套数据通道。
7. 右栏下 `ChangesPanel` 继续使用现有扁平完整路径 `ChangesList`，本期不改其布局、渲染和公开信号。

## 2. 现状与方案决策

### 2.1 当前代码边界

- `src/gui/panels/file_explorer/explorer.py` 已用 `QStackedWidget` 管理文件树和 Git 页，头部 `⇄` 按钮、非 Git 回退、搜索栏关闭及悬浮钮显隐均已打通。
- `src/gui/panels/changes/list.py` 已提供三列扁平渲染、状态色、删除线、统计列、空态和三路双击信号；它同时服务两个界面，不能直接改成树，否则会连带改变右栏下。
- `src/gui/controllers.py` 已每次只调用一次 `collect_changes()`，再把同一清单分别喂给上方 Git 页和下方 `ChangesPanel`；差异弹窗、删除提示和主题重绘接线也已存在。
- `src/core/git/service.py` 的 `ChangeEntry` 已含 `path/status/added/deleted`，`collect_changes()` 排除 ignored 并按路径排序，足以直接建树，无需扩展 Git 数据模型。
- 当前没有通用文件图标 helper；可使用 Qt 自带 `QFileIconProvider` 和 `QStyle` 标准图标，不引入图标资源包。

### D1 控件隔离：上方新增 `ChangesTree`，下方保持原样

- 新增 `src/gui/panels/changes/tree.py`，实现上方专用 `ChangesTree`；对外保留 `apply_changes()`、`apply_theme()` 和 `file_opened` / `diff_opened` / `deleted_activated` 接口。
- `ChangesTree` 使用 QWidget 组合：顶部仅放右对齐的紧凑视图切换按钮，下方为内部 `QTreeWidget`；不重复 `ChangesPanel` 的标题、计数和收起按钮。
- `src/gui/panels/changes/list.py` 与 `src/gui/panels/changes/panel.py` 不做功能改造，不为复用而抽取基类，避免扩大下方回归面。
- `FileExplorer` 第二页改挂 `ChangesTree`，继续只转发三路信号；`GitStatusController` 无需功能改动。

### D2 纯数据建树：稳定路径身份与确定性排序

- 新增无 Qt 依赖的 `src/gui/panels/changes/tree_model.py`，以节点 dataclass 和 `build_change_tree(changes)` 纯函数完成路径分段、目录复用和排序。
- 节点保存完整仓库相对路径 `path`、末段名称 `name`、子节点和可选 `entry`；虚拟根不进入界面。目录与文件均以相对路径作为刷新恢复的稳定身份。
- 只按 Git 输出的 `/` 分段，不把 `\` 转成分隔符，也不 trim 路径空白，避免损坏 POSIX 合法文件名。
- 树模式同级先目录后文件，再按 `name.casefold()`、原始 `path` 次序排序，保证中文、大小写同名项和输入顺序变化时结果确定。
- 列表模式沿用 `collect_changes()` 的完整路径排序，不额外分组，不压缩单链目录，不虚构仓库根行。

### D3 双模式与窄面板布局

- 默认 `tree` 模式；切换按钮使用明确文字和动态 tooltip，不引入新的图标字体或生僻字形。
- 内部 `QTreeWidget` 固定四列：文件/目录名、父目录、`+N`、`-N`。树模式隐藏父目录列并启用展开装饰；列表模式隐藏展开装饰并显示父目录列。
- 名称列吃剩余空间；父目录列使用 `muted_text` 弱化且宽度受限，长父目录省略，完整路径放 tooltip；两个统计列继续按内容收紧并右对齐。
- 树模式文件行只显示文件图标 + 文件名 + 弹性空间 + 增删统计，不额外加入状态字母、悬浮操作按钮或双行路径。
- 目录行只承担展开/折叠与导航，不发射文件查看、差异或删除信号；目录不新增状态聚合着色语义。

### D4 图标、状态与空态

- 文件图标经 `QFileIconProvider.icon(QFileInfo(...))` 按路径/扩展名解析；查询失败或空图标回退 `QStyle.SP_FileIcon`，因此已删除文件不依赖磁盘仍存在。
- 目录使用 Qt 标准闭合/展开图标，并通过展开、折叠信号同步；不复制参考项目的 SVG 集合。
- 文件状态色和删除线沿用 `git_status_color()` 与现有状态常量；`+N/-N` 沿用 `ChangesList` 口径，`0` 和 `None` 不显示，不把 `None` 擅自解释为二进制或过大。
- `changes is None` 显示“（非 Git 仓库）”，空清单显示“（无变更）”；占位行不可选、不可双击分派。
- 文件行 UserRole 保存节点类型、原始相对路径、状态和绝对路径；双击只消费文件载荷，D 信号仍发送原始相对路径，其余两路发送绝对路径。

### D5 刷新与模式切换的状态保持

- 每次 `clear()` 前采集已展开目录相对路径、选中/当前文件相对路径和垂直滚动值；重建后在仍存在的节点中恢复，并使用 `setUpdatesEnabled(False)` 包裹重建，避免闪烁。
- 首次非空树默认展开全部；后续刷新只恢复此前展开的目录，用户已折叠目录不得被重新展开，新出现目录不强制展开。
- 同模式刷新恢复滚动值，超出新范围时由滚动条自然钳制；节点消失后清除对应恢复状态，不报错误。
- 目录树/列表切换保留选中文件；若有选中文件则滚动到该项，否则从顶部开始，不跨两种行结构机械复用滚动像素。
- `apply_theme()` 只按缓存数据重建配色和图标，不触发 Git 查询，也不丢弃展开、选中和滚动状态。
- 非 Git 回退仍由 `FileExplorer.apply_git_status()` 强制返回文件树；Git 页内部的列表/树偏好不持久化。

## 3. 实施步骤

### 3.1 纯数据建树与单元测试

新增 `src/gui/panels/changes/tree_model.py` 和 `tests/test_changes_tree.py`：

1. 定义轻量节点与 `build_change_tree()`，输入 `list[ChangeEntry]`，输出虚拟根及已排序子节点；不 import PySide6。

### 3.2 实现 `ChangesTree`

2. 将纯数据节点递归映射为目录/文件项，接入标准目录图标、按路径文件图标和通用回退。
3. 复用现有状态色、删除线、tooltip 与三路双击分派语义；目录项和占位项无文件载荷。
4. 实现渲染前快照、渲染后恢复、首次展开、滚动恢复和模式切换选中恢复；主题切换走同一缓存渲染路径。
5. 对内部树提供仅供测试使用的明确只读访问或遍历辅助，不把实现细节扩散为新的包级公共 API。

2. `apply_git_changes()` 和 `apply_theme()` 改调新控件；`apply_git_status()`、`_set_git_mode()` 和头部 `⇄` 行为保持现状。

4. 更新模块 docstring 中“扁平变更列表”的旧描述；`src/gui/controllers.py` 仅在实际措辞需要时同步注释，不改刷新算法和信号连接。

### 3.4 主题与紧凑样式

3. 不复制各主题样式表，不新增 QSS 色值令牌；若原生分支箭头或图标在全部注册主题中可读，则不追加装饰样式。

### 3.5 回归测试补强

### 4.2 视觉验证闭环

按 `维护手册/视觉验证闭环开发指南.md`，用生产 `FileExplorer` / `ChangesTree` 和生产 QSS 编写同一份 offscreen 探针，修前/修后使用同一 mock 数据；脚本与 PNG 仅放 `.temp/`：

2. 240px 与 360px 宽度分别覆盖深层目录、根文件、中文/空格长路径、长文件名、删除文件、无统计项和空态；文件名允许省略，统计列不得被挤没，tooltip 必须保留完整相对路径。
3. 抓折叠目录刷新前后、选中项刷新前后和列表/树切换帧，确认不闪回全展开、不无故回顶部、选中色和状态色可读。

### 4.3 真机自然操作终裁

- 从头部分别进入 Git 页、切换列表/目录树、返回文件树，原文件树展开和选中不变。
- 修改、新增、删除文件后，两个 Git 界面随现有刷新链同步更新；上方结构变化时保留用户折叠状态。
- 双击 M/U 打开差异，D 仅显示删除提示，其他文件进入查看器；目录只展开/折叠。
- 打开非 Git 文件夹时仍只显示原文件树，无 Git 切换按钮；右栏下“已变更”外观与操作与改造前一致。

## 6. 非目标

- 不实现 Staged/Unstaged 分组、组计数或 XY 状态拆分。
- 不实现暂存、取消暂存、丢弃、提交、推送、分支切换或提交历史 DAG 改造。
- 不加入单链目录压缩、行内悬浮操作、悬停 diff 预览或二进制/过大精确标签。
- 不引入 WebEngine、React、图标字体、新依赖或参考目录运行时依赖。
- 不改右栏下 `ChangesPanel`，不删除其扁平完整路径列表。
- 不持久化 Git 页列表/树模式，不增加设置中心选项。
- 不在没有实测性能证据时转向 `QAbstractItemModel` + 全量委托自绘；极端规模优化另立计划。
