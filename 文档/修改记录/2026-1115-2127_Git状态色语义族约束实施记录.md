## 1. 背景与 why

Git 状态是**语义信息，不是装饰色**：modified 蓝族 / untracked 绿族 / deleted·conflict 红族 / ignored 灰族，主题只允许在族内微调明暗/饱和度，禁止跨族。1643 蓝键归位按 accent 同族取色，把 wheat modified 带成琥珀 `#b85e14`、mint 带成深绿 `#0f6e3f`——暖米主题变更面板「已修改」不读作已修改；薄荷主题 modified 绿与 untracked 绿 `#1f8a3d` 近同不可分（bug 级观感缺陷）。本计划把 drift 出去的值拉回蓝族，并把铁律固化成机器断言防再漂移。

## 5. 遗留与边界

- 走查中发现 sky modified（hue 201.3°）与 sky ignored 蓝灰（hue 约 192°）hue 差仅 8.7°，但 RGB 距 159.9、明度/饱和度差异显著（正文级蓝 vs 弱化灰），且语义层级不同，可辨无问题——记录在案，非缺陷。
- 语义族铁律目前只对 modified 有 hue 机器断言（计划 §5.2 口径：untracked/deleted/conflict 由 `_SHARED_LEGACY` 逐值相等断言守护，出族必改值、改值必被逐值断言拦截）；未来若给灰族（ignored）开跨主题漂移口子，再扩断言。
- git_graph 徽标四色、terminal ANSI、chat diff 四键不在本计划范围（0253 D4 口径：走查碍眼再立小计划）。
