## 3. 总体设计

### 3.1 架构形态（沿用选型 §4.3 形态 1 + §4.4 路由①）

`ViewerPanel` 引入 `QStackedLayout`，两个页面：

| 页 | 控件 | 承载 |
|:---|:---|:---|
| 文本页（现有） | `CodeViewer` | 文本、占位提示（二进制/不存在/已删除） |
| 图片页（新增） | `ImageViewer`（新文件 `gui/panels/viewer/image_viewer.py`） | 位图 / SVG / GIF |

`open_file` 头部按扩展名分流：

```python
# gui/panels/viewer/panel.py（open_file 分流示意）
if p.suffix.lower() in IMAGE_EXTS:      # 含 .svg .gif
    return self._open_image(p)
# 以下维持现有文本流程不变
```

- 扩展名表：`QImageReader.supportedImageFormats()` 动态生成 + 手工补 `.svg`（`QImageReader` 部分构建不含 svg）。
- 占位提示（文件不存在/读取失败/二进制不支持）仍走文本页 `_show_placeholder`，**现有行为零回归**。
- 图片打开失败（损坏/解码失败/超防护阈值）→ 回落文本页占位提示「（图片无法预览：原因）」。

### 3.2 ImageViewer 控件设计（新文件 `gui/panels/viewer/image_viewer.py`）

`QGraphicsView` 派生，单 `QGraphicsScene`，内容 item 按类型三选一：

| 文件类型 | item | 说明 |
|:---|:---|:---|
| 位图（png/jpg/webp/bmp/...） | `QGraphicsPixmapItem` | `QImageReader` 读入（`setAutoTransform(True)` 尊重 EXIF 方向） |
| SVG | `QGraphicsSvgItem` | `QSvgRenderer` 矢量原生，放大无损 |
| GIF | `QGraphicsPixmapItem` + `QMovie` | `frameChanged` → 更新 pixmap；静态首帧场景自动退化为位图 |

核心交互：

- **缩放**：`wheelEvent` 锚点缩放（`setTransformationAnchor(AnchorUnderMouse)`），倍率钳制 0.05–16.0；`fit()` = `fitInView(item, KeepAspectRatio)`，`actual()` = `resetTransform()`；`resizeEvent` 时若处于 fit 模式自动重 fit。
- **平移**：`setDragMode(ScrollHandDrag)`，图小于视口时禁用拖动光标。
- **大图防护**：读入后判定 `max(w,h) > 32768` 或 `w*h > 80_000_000` → 拒绝渲染并返回原因字符串（由面板转占位提示）。
- **棋盘格透明底**：重载 `drawBackground`（或视口背景刷），`QPainter` 以两色 8px 方块拼 16px 棋盘平铺——透明 PNG/GIF/SVG 的可读性刚需。棋盘两色随主题明暗取调色板现有令牌派生（**不新增令牌**，`apply_theme` 时重建画刷）；位图不透明场景棋盘被图像遮盖，无视觉副作用。思路借鉴 Multi_Cli_Studio（CSS 渐变棋盘），`QPainter` 自绘独立实现。
- **翻页**：`open_image(path)` 时扫描同目录同扩展名表文件集排序，记忆索引；`prev()`/`next()` 循环步进。
- **主题**：视口背景刷（含棋盘两色）由 `apply_theme(chrome)` 注入（与 `CodeViewer.apply_theme` 同模式，色值取主题调色板现有令牌，**不新增令牌**）。
- **字号**：图片页与等宽字体无关，`refresh_font` 对其空操作。

### 3.3 ViewerPanel 改造点清单

| # | 改造 | 说明 |
|:--|:---|:---|
| 1 | `QStackedLayout` 替换卡片内单一 `addWidget(self.viewer, 1)` | 文本页/图片页切换；卡片、标题行、外边距不动 |
