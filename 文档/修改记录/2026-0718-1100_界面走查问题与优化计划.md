## 2. 问题清单与处理方案

### 2.1 🔴 右栏路径标签被裁剪

| 项 | 内容 |
|:---|:---|
| 现象 | 右栏顶部完整绝对路径 `~/.../Zen_Studi…` 超出栏宽被截断，且与树内容信息重复 |
| 位置 | [`gui/panels/file_explorer.py`](../../gui/panels/file_explorer.py) 的 `path_label` |
| 方案 | 标签只显示根目录名（`Path(root_dir).name`）；保留完整路径在 `setToolTip` 中悬停可见 |
| 优先级 | 🔴 高（可视缺陷，随下次改动顺带修复） |

### 2.2 🟡 文件树缺少噪音过滤

| 项 | 内容 |
|:---|:---|
| 现象 | `__pycache__` 等噪音目录出现在树中 |
| 方案 | `QFileSystemModel.setNameFilters()` + `setNameFilterDisables(False)`，默认隐藏 `__pycache__`、`.git`、`.venv`、`node_modules`；预留开关接口（后续放入视图菜单） |
| 优先级 | 🟡 中（随"忽略目录清单"第二阶段功能合并实施） |

### 2.3 🟡 视觉一致性缺失

| 项 | 内容 |
|:---|:---|
| 现象 | 三个占位面板有边框，文件树面板无边框，四区视觉不统一 |
| 方案 | 建立全局 QSS 样式表模块（如 [`gui/theme.py`](../../gui/theme.py)），统一面板边框/间距/配色；为后续暗色主题打地基（参考 PyGPT 主题系统的 apply_stylesheet 模式） |
| 优先级 | 🟡 中（在内容模块填充前完成，避免返工） |

### 2.4 🟡 缺少菜单栏与状态栏

| 项 | 内容 |
|:---|:---|
| 现象 | 无菜单栏、工具栏、状态栏，不具备 IDE 基本骨架 |
| 方案 | 在 [`gui/main_window.py`](../../gui/main_window.py) 增加 `QMenuBar`（文件/编辑/视图，仅骨架无业务）+ `QStatusBar`（状态文本，参考 PyGPT 的 59 行状态栏实现 [`参考代码/VS_Code_Python/src/pygpt_net/ui/layout/status.py`](../../参考代码/VS_Code_Python/src/pygpt_net/ui/layout/status.py)） |
| 优先级 | 🟡 中（建议在中栏代码编辑器之前完成） |

### 2.5 🟢 左栏宽度待调整

| 项 | 内容 |
|:---|:---|
| 现象 | 左栏 250px 对占位内容偏大 |
| 方案 | 待左栏用途确定后再调整 `setSizes` 比例，暂不处理 |
| 优先级 | 🟢 低（备案） |
