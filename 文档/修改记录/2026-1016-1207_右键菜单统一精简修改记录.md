## 1. 问题现象（用户反馈）

应用内右键菜单形态不统一（三截图取证）：AI 回复右键 = 「复制」「全选」纯文字两项（用户拍板为统一标准）；用户气泡右键 = Qt 原生英文带图标菜单（Copy / Copy Link Location / Select All）；文件查看面板右键 = 仅「全选」单项。

用户三条拍板：①只读文本区统一为「复制」「全选」两项、无图标、中文；②菜单项与 Ctrl+C/Ctrl+A 快捷键正交并存（非二选一）；③「无图标」为全局要求，所有右键菜单一律不出现旧版带图标样式。

## 2. 根因

- 卡片轨全部只读正文的基类 `BodyText` / `BodyHtml`（`src/gui/panels/chat/cards.py`）从未覆写 `contextMenuEvent`——精简当年只接到 `TextStreamBlock` / `ChatOutput` / `ChatInput` 三个点，基类漏接，气泡与各卡片正文回落 Qt 默认菜单；
- 中栏查看器两处是 0806 计划「只留全选」的历史拍板，与新标准冲突；
- 三个对话框只读文本与三个零散输入框历次开发各自 new 裸控件，从未纳入右键菜单规约；
- 所有图标均来自 Qt 内建标准菜单（应用自建菜单本就纯文字），全局无图标 = 把一切仍走 Qt 原生标准菜单的控件纳入 `simplify_standard_menu()` 覆盖。

## 3. 实施内容

- `cards.py`：`BodyText` / `BodyHtml` 覆写 `contextMenuEvent` → `exec_standard_context_menu(simplify=True)`，只读控件经 Qt 标准菜单仅产出 Copy/Select All（QTextBrowser 的 Copy Link Location 由精简逻辑删除），恰为「复制」「全选」两项；气泡体、`SystemBlock`、`ThinkingCard`、全部工具卡随继承覆盖。`TextStreamBlock`（`transcript.py`）原覆写与基类雷同，删除改走继承。
- `code_viewer.py` / `markdown_view.py`：自绘菜单「全选」前补「复制」项（`setEnabled(textCursor().hasSelection())`）；`code_viewer.py` 顺手对齐构建/弹出分离结构（`_build_context_menu()`，探针可断言）；`markdown_view.py` `_build_context_menu` 未使用的 `pos` 参数一并去除。
- `popups.py`：新增只读简化封装 `SimplifiedMenuTextBrowser` / `SimplifiedMenuTextEdit`（后者构造即只读，职责与可编辑封装分清）；`TranslucentMenuLineEdit` / `TranslucentMenuPlainTextEdit` 改 `simplify=True`（保完整编辑项，去图标 + 中文化）；模块 docstring 统一形态规约同步。
- 三处对话框换用只读封装：`git_graph_dialog.py` 降级 `QTextBrowser`、`diff_view_dialog.py` `QTextBrowser`、`settings_dialog.py` 黑名单 `QTextEdit`。
- `explorer.py` 文件树搜索框裸 `QLineEdit` 换 `TranslucentMenuLineEdit`（顺带补上缺失的菜单透明化）。
- 边界不动：聊天输入框（可编辑全项，已精简）、终端/文件树功能菜单（本已纯文字无图标）、菜单栏。

## 4. 验证

- 新增 `tests/test_context_menu.py` 11 用例：只读六类控件菜单恰为「复制」「全选」、无图标、无 `\t` 快捷键后缀、复制启停随选区；锚点上右键仍恰两项（link-copy 剔除）；可编辑输入框完整编辑项中文化无图标；Ctrl+C 复制进剪贴板、Ctrl+A 全选生效（正交性断言）。全绿。
- 探针手法教训：PySide6 无法 monkeypatch Qt 类方法（`patch.object(QMenu, "exec")` 不拦截，真弹模态菜单卡死 offscreen 用例）——改用 app 级事件过滤器捕获 QMenu Show 并立即关闭，真实 exec 走嵌套循环即返回。
- offscreen 探针（`.temp/probe_ctx_menus.py`，环境对齐真机：`apply_theme(app)` 挂应用级 qss/QPalette/字体）十帧抓图目检：只读六处菜单形态一致（复制/全选、无图标），可编辑两处完整编辑项中文无图标。
- 真机终裁：待用户实机右键核对（计划 T7 后半）。

## 5. 开放项

- 空文档时 Qt 标准菜单「全选」项置灰（Qt 原生语义，无可选内容），不做干预。
- 可编辑输入框若未来也想砍到两项，需先解决粘贴入口去向，再立项。
