## 1. 目标

| 目标 | 说明 |
|:---|:---|
| 窗口几何持久化 | 主窗口位置、大小（含最大化状态）关闭时保存，下次启动复原 |
| 分隔栏持久化 | 三处 `QSplitter` 的分割位置保存并复原（详见 3.1 清单） |
| 模型/版本持久化 | 聊天面板顶行的模型（后端）与版本下拉选择即时保存，下次启动复原 |

## 2. 现状盘点

- GUI 框架为 PySide6。[`gui/main_window.py`](../../gui/main_window.py) 中窗口大小硬编码 `resize(1200, 800)`，外层水平 `QSplitter` 硬编码 `[320, 630, 250]`，中栏垂直 `QSplitter` 硬编码 `[550, 250]`；[`gui/panels/chat/panel.py`](../../gui/panels/chat/panel.py) 内部输出/输入区 `QSplitter` 硬编码 `[550, 180]`。均无任何状态恢复。
- 配置系统已有雏形：[`gui/theme.py`](../../gui/theme.py) 的 `load_settings()` / `save_theme()` 读写 [`config/settings.json`](../../config/settings.json)，`DEFAULT_SETTINGS` 提供默认值回退，目前仅 theme/font 三键。
- 模型选择：[`gui/panels/chat/model_bar.py`](../../gui/panels/chat/model_bar.py) 初始后端硬编码 `"kimi-cli"`、版本默认取下拉第一项；`selection_changed` → `ChatPanel._on_selection_changed` → `llm.set_model(version)`，无持久化。
- ⚠️ 隐患：`config/settings.json` 当前被 git 跟踪，用户每次拖窗口/改主题都会污染工作区。

## 3. 已确认决策（2026-07-19 与用户确认）

1. ✅ `config/settings.json` 从 git 移除跟踪（`git rm --cached`）并加入 [`.gitignore`](../../.gitignore)；代码内 `DEFAULT_SETTINGS` 兜底，新克隆仓库无配置文件也能正常运行。
2. ✅ 聊天面板内部输出/输入区分隔栏一并持久化。
3. ✅ 保存时机：布局在关闭时一次性保存；模型/版本选择变更即时保存。

### 阶段二：窗口位置/大小/分隔栏持久化

| # | 任务 | 涉及文件 |
|:--|:---|:---|
| 2.1 | 采用 Qt 原生能力：窗口用 `saveGeometry()` / `restoreGeometry()`（含最大化状态，且自动处理副屏拔出后窗口落屏外的情况）；分隔栏用 `QSplitter.saveState()` / `restoreState()`；`QByteArray` 转 base64 存 JSON | `gui/main_window.py` 等 |
| 2.2 | 外层水平 splitter 从局部变量提升为成员变量；三处 splitter 清单：外层水平（聊天/中栏/文件树）→ `splitter_main`；中栏垂直（查看器/终端）→ `splitter_middle`；聊天面板内部（输出/输入）→ `splitter_chat` | `gui/main_window.py`、`gui/panels/chat/panel.py` |
| 2.3 | 恢复时机：`MainWindow.__init__` 搭完 UI 后、show 之前恢复；`restoreState()` 返回 False（数据损坏）时静默保留硬编码默认值兜底 | `gui/main_window.py` |
| 2.4 | 保存时机：重写 `MainWindow.closeEvent`，关闭时一次性写入全部几何/分隔栏状态；不做拖动中实时保存（避免高频写盘） | `gui/main_window.py` |
| 2.5 | `ChatPanel` 暴露 `save_state()` / `restore_state()` 方法负责内部分隔栏，由 `MainWindow` 统一调用 | `gui/panels/chat/panel.py` |

## 6. 依赖与风险

- 依赖：无外部依赖，全部基于 PySide6 现有 API 与项目已配置的 `.venv`。
- ⚠️ 风险：`settings.json` 移出 git 跟踪后，团队成员本地的主题配置不受影响（文件保留在磁盘）；仅新克隆仓库回退代码内默认值。
- ⚠️ 风险：`restoreGeometry()` 对 Wayland 下窗口位置的恢复依赖合成器行为，若实测位置不生效仅回退为系统默认摆放，大小/分隔栏不受影响（Linux 当前环境影响有限）。
