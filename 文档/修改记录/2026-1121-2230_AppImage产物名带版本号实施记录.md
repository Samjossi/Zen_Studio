## 3. 与计划的偏差

无功能偏差。仅补充了以下实施细节：

- 版本格式守卫放在版本捕获之后、产物名派生之前，确保非法版本在构建早期失败。
- 别名更新放在冒烟清理之后、体积统计之前；别名失败不阻断构建，符合计划的「尽力而为」设计。
- 计划中「打印历史版本统计」实现为 `find` 计数 + `du` 合计，未新增清理行为。

## 4. 风险遗留与使用说明

- **分发**：必须拷贝 `Zen_Studio-<版本>-x86_64.AppImage` 真实文件；`Zen_Studio-x86_64.AppImage` 是相对符号链接，离开 `dist/` 会断链。
- **历史版本**：默认保留不删，构建结束只打印数量与占用；磁盘清理由用户自行决定，避免误删回滚件。
- **同版本重建**：同一 git 提交重复构建得到相同版本号，同名文件被覆盖，与 `version.txt` 口径一致。
- **未做项**：本机无 FUSE，未走真实挂载启动；未实测非 git 三段版本构建；未重复构建验证同版本覆盖；本次无 Python 改动，未跑 pytest，`shellcheck` 未安装。
