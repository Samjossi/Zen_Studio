## 3. 与计划的偏差

1. **行数预算未达原口径**：计划要求「运行时部分 ≤ 900 行」，实际 `provider.py` 380 + `updates.py` 567 + `permissions.py` 69 = 1016。原因是 900 把 `updates.py`（ACP 帧→界面投影，属协议翻译而非防御层）计入运行时；按「生命周期代码」口径，`provider.py` + `permissions.py` = 449 行，旧实现对应部分为 719 + 69 = 788 行。整包 1320 行，旧包 2925 行（−55%）。未为凑数字删减协议处理。
2. **S4 未复现**：没有主动构造后台任务通知轮。方案 A 下该场景本就会如实反映上游提前 `end_turn`，验收不设门槛。
3. **S8 图片**：计划写「第一版不搬」，实施中发现图片走公共 `build_prompt_blocks`、不引入私有旁路，故保留且未额外验证。
4. **`session/close` 完全移除**：标签关闭只 `terminate()` 进程；`cancel` 只发 `session/cancel` + 本地 abort。
5. **删除测试 5 个**：`test_kimi_acp_turns` / `test_kimi_turn_state` / `test_kimi_wire_usage` / `test_kimi_subagent` / `test_kimi_session_close`——它们断言的机制已不存在，属实现对应测试而非契约测试。

## 4. 风险遗留

- **假完成可能重现**：这是方案 A 明确接受的代价。出现时按上游缺陷记录（Kimi 版本、`stopReason`、响应后的帧序列），不得在本实现上临时加私有判定。
- **用量徽章数据变少**：Kimi 不再有私有用量差量，只显示 ACP `usage_update` 推流；轮内可能长时间无值。
- **子代理嵌套卡片消失**：子代理活动只在 ACP 帧出现时展示，不再从 `wire.jsonl` 合成。
- **未提交**：全部改动留在 `feat/kimi-min-provider` 工作树，等用户确认后提交。
