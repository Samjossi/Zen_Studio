## 3. 总体设计

### 3.0 设计原则：OOP 模块化（2026-07-29 11:24 审阅增补）

本期开发遵循面向对象模块化设计，与项目现有面板/控件体系同构：

1. **单一职责、控件自封装**：`MediaViewer` 为独立自治控件（独立文件、独立类），播放器接线、控制条装配、进度/音量事件处理、错误信号、生命周期 `stop()` 全部封装在类内部；对外仅暴露最小公开接口（`open_media(path)` / `stop()` / `apply_theme(chrome)` / 错误信号），调用方不得触及其内部控件。
2. **组合优于耦合**：`ViewerPanel` 只通过公开接口与 `MediaViewer` 协作（分流调用 + 停播通知 + 主题分发），不感知 `QMediaPlayer` 细节；媒体逻辑零侵入文本/图片页代码路径。
3. **依赖方向单向**：`media_viewer.py` 不 import `panel.py`，错误经信号上抛由面板决策回落占位，避免环依赖。
4. **可替换性**：`MediaViewer` 作为 `QStackedLayout` 中一页，与文本页/图片页地位对等；未来更换实现（如换后端）时面板侧改动限于分流分支。
5. **移植代码就地重构**：PyGPT 移植片段（状态机/扩展名表）须剥离其 `window.tools`/`trans()` 依赖并重构进本类的方法/类常量，禁止保留其 `QDialog` 形态或过程式残留。

### 3.1 架构形态（沿用图片计划 §3.1 的 `QStackedLayout` 分流）

`ViewerPanel` 卡片内容区为 `QStackedLayout`，三个页面：

| 页 | 控件 | 承载 |
|:---|:---|:---|
| 文本页（现有） | `CodeViewer` | 文本、占位提示（二进制/不存在/已删除） |
| 图片页（图片计划） | `ImageViewer` | 位图 / SVG / GIF |
| 媒体页（本期新增） | `MediaViewer`（新文件 `gui/panels/viewer/media_viewer.py`） | 视频 / 音频 |

> **实施顺序说明**：图片计划（`2026-0729-1102_图片文件预览功能实施计划.md`）与本计划共用 `QStackedLayout` 分流架构。**先落地者负责引入 `QStackedLayout` 并改造 `open_file` 分流骨架；后落地者只追加自己的页与扩展名分支**，不重复改造。本计划任务按"图片计划已落地"编写；若本计划先行，T4 需额外承担 `QStackedLayout` 引入工作（改造点与图片计划 §3.3 第 1/2 项相同）。

`open_file` 头部按扩展名分流：

```python
# gui/panels/viewer/panel.py（open_file 分流示意）
if p.suffix.lower() in VIDEO_EXTS | AUDIO_EXTS:
    return self._open_media(p)
if p.suffix.lower() in IMAGE_EXTS:   # 图片计划分支（若已落地）
    return self._open_image(p)
# 以下维持现有文本流程不变
```

- 扩展名表移植自 PyGPT `get_video_ext`/`get_audio_ext`，按 §1 决策裁减为主流子集。
- 占位提示（文件不存在/读取失败/解码失败/不支持格式）仍走文本页 `_show_placeholder`，**现有行为零回归**。
- 媒体打开失败（后端缺失/编码不支持）→ 回落文本页占位提示「（无法播放：原因，请用外部程序打开）」——纯文字提示，**不提供外部打开按钮**（§1 决策），由用户自行在文件管理器中打开。

### 3.2 MediaViewer 控件设计（新文件 `gui/panels/viewer/media_viewer.py`）

`QWidget` 派生，垂直布局 = 画面区 + 控制条：

| 区域 | 控件 | 说明 |
|:---|:---|:---|
| 画面区 | `QVideoWidget` | 视频渲染；纯音频时无画面，叠加显示文件名 + 「音频」占位标签（`QStackedLayout` 或简单覆盖，不做波形可视化） |
| 控制条 | 播放/暂停按钮 + `QSlider` 进度 + 时间标签（`mm:ss / mm:ss`）+ 音量 `QSlider` | 复用 PyGPT 播放状态机的事件处理逻辑（移植须带版权头） |

核心逻辑：

- **播放器**：单例 `QMediaPlayer`；视频 `setVideoOutput(QVideoWidget)`，音频/视频统一 `setAudioOutput(QAudioOutput)`（Qt 6 要求显式挂音频输出，否则无声）。
- **自动播放（§1 决策）**：`open_media` 置 `_autoplay` 标志，`mediaStatusChanged(LoadedMedia)` 触发 `play()`——双击打开即播；`stop()` 清标志，防切页后异步加载完成又出声。
- **进度**：`positionChanged`/`durationChanged` 信号驱动进度滑块与时间标签；拖动滑块 `sliderMoved` → `setPosition`；播放中拖动用标志位防信号回写打架。
- **音量**：`QAudioOutput.setVolume`（0.0–1.0），默认 0.7；静音按钮本期不做（音量拖到 0 即可）。
- **生命周期（红线）**：`open_media(path)` 前先 `stop()` 旧源；面板切换文件/回落占位/关闭时由 ViewerPanel 调 `media_viewer.stop()` 释放，防后台继续播放。
- **错误兜底**：`errorOccurred` 信号 → 向面板抛原因字符串，面板回落占位提示。
- **主题**：控制条按钮/滑块沿用现有 qss 令牌（`apply_theme(chrome)` 注入背景/前景色，**不新增令牌**）；`refresh_font` 空操作。
