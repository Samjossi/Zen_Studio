## 3. 修复方案

### T1：帧证据制度化（F3）

**T1-1 `.gitignore` 豁免帧存档**：

```
# 临时文件
.temp/*
!.temp/frame_archive/
```

原理：原 `.temp/` 整目录排除时，git 规则上无法再 re-include 其子路径（父目录被排除不可豁免）；改为 `.temp/*`（排除内容而非目录本身）后豁免生效。`.temp/` 其余内容（card_shots、探针脚本、诊断截图）维持忽略，行为不变。

**T1-2 capture 脚本迁移**：`.temp/capture_askuser_frames.py` → `scripts/capture_askuser_frames.py`（git mv 语义）：

- docstring 运行路径同步为 `.venv/bin/python scripts/capture_askuser_frames.py`；
- `ARCHIVE_DIR` 不变（仍写 `.temp/frame_archive/`——该目录经 T1-1 入库）；
- `scripts/README.md` 脚本清单补登记一行（注：清单现漏登记 `shot_tool_cards.py` 等既有脚本，属历史欠账，本计划不顺手补，仅记录于此）。

**T1-3 既有证据入库**：`.temp/frame_archive/` 现存 7 份 askuser 真机帧 git add 提交。

**T1-4 docstring 证据引用标注**：`llm/providers/acp.py:449` `_extract_write_diff` docstring 引用的 `.temp/write_frames_kimi.json` 已丢失（`.temp` 未入库，git 无历史），加注——"该取证文件未入库已随 .temp 清理丢失，T3 重取证后回填新存档路径"；T3 完成时回填。同法检查 `edit_frames_{kimi,kilocode}.json` 引用（0919 计划文档内，归档文档不改，仅在审计报告已记录）。

**验收**：`git status` 可见 `.temp/frame_archive/` 7 份 JSON；`git check-ignore` 确认 `.temp/card_shots/` 等仍被忽略。
