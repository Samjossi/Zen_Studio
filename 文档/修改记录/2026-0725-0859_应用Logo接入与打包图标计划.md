# 应用 Logo 接入与打包图标计划

> **平台约束**：Zen Studio 仅在 **Linux** 上使用，Windows / macOS 一概不考虑。全计划只覆盖 Linux 图标体系（窗口图标 + 任务栏 / Dock + `.desktop` 入口），不产出 `.ico` / `.icns`。

## 1. 背景与目标

从 `assets/logo候选池/B_禅圈.svg` 定版 Zen Studio 官方 Logo，完成两条链路：

1. **运行时图标**：窗口标题栏图标 + 任务栏 / Dock 图标 + 「关于」对话框 Logo。
2. **打包产物图标**：PyInstaller 打包（Linux onedir）后的运行图标与 `.desktop` 桌面入口图标（PNG）。

定版资产**复制出候选池**，且**不散放 `assets/` 根下**——新建 `assets/logo/` 专目录集中收纳（与 `assets/fonts/` 一族一目录的既有约定一致），候选池原文件保留不动（后续换标只改正式目录，不动候选池）。

### 1.1 关于「标题栏中间显示 Logo」的约束说明 ⚠️

当前标题栏是 **Qt 原生标题栏**（`gui/main_window.py` 中 `setWindowTitle` 设置文字，由操作系统绘制）。Linux 下原生标题栏的 Logo 能力 = **窗口图标**（`setWindowIcon`），显示位置：

| 场景 | 图标来源 | 位置 |
|:---|:---|:---|
| 窗口标题栏 | `setWindowIcon` | 标题**最左侧**（文字左边；视桌面环境，部分 DE 不显示） |
| 任务栏 / Dock（X11） | `setWindowIcon` | 任务管理器、Alt-Tab |
| 任务栏 / Dock（Wayland） | `.desktop` 文件的 `Icon=`（经 `StartupWMClass` / `setDesktopFileName` 关联） | 任务管理器、Alt-Tab |

原生标题栏**不支持**在居中标题文字旁嵌入图标。若确需「标题正中 + Logo」的视觉效果，须改自绘无边框窗口（`FramelessWindowHint` + 自绘标题栏），工程量大且涉及拖拽 / 缩放 / 系统按钮重实现，**列为本计划非目标**（见 §7），待运行时图标落地后再评估。

## 3. 定版资产方案

### 3.1 目录结构

Logo 全套资产集中入 `assets/logo/`（专目录，与 `assets/fonts/<族名>/` 约定同构）：

```
# assets/logo/
assets/logo/
├── logo.svg          # 矢量母版（换标唯一改动点）
├── logo_16.png       # 窗口标题栏 / 任务栏小图标
├── logo_24.png
├── logo_32.png
├── logo_48.png       # .desktop 菜单 / 启动器常用
├── logo_64.png       # 「关于」对话框（缩放自 64 原生件，不二次压缩）
├── logo_128.png
├── logo_256.png      # .desktop 主图标 / 任务栏大图
└── logo_512.png      # 高分屏 / 大图标场景
```

- **母版**：`logo.svg` 复制自 `assets/logo候选池/B_禅圈.svg`，是换标时**唯一**手改文件。
- **PNG 全规格成套产出**：16/24/32/48/64/128/256/512 八件**全部为正式资产**入库（非临时预览）——栅格化成本为零（同一脚本一次渲染），各桌面环境按自身规范取对应尺寸，避免「缺尺寸被 DE 放大插值糊边」。
- Linux 图标体系以 PNG 为准（freedesktop 规范），**不产出 `.ico`**。

### 3.2 栅格化脚本

`scripts/render_logo.py`：用 PySide6 `QSvgRenderer` + `QImage` 读 `assets/logo/logo.svg`，一次渲染八尺寸 PNG 落回同目录（幂等，覆盖写）。**零新增第三方依赖**。脚本入库留存，换标流程 = 改母版 → 重跑脚本。

### 3.3 运行时取图策略

`QIcon` 支持多尺寸注册（`addFile` 逐尺寸挂入），Qt 按显示场景自动挑最近尺寸、杜绝缩放糊边——窗口图标注册 16–256 六件（512 留给 `.desktop` 与高分屏场景）；「关于」对话框直接取 `logo_64.png` 原生件。

## 6. 风险与注意事项

| 符号 | 项 | 说明 |
|:--:|:---|:---|
| ⚠️ | 深色 Logo 辨识度 | 母版主体 `#1B1B22`，深色主题任务栏上 16px 尺寸可能糊成一团，T3 目检兜底 |
| ⚠️ | Wayland 任务栏图标 | Wayland 下任务栏图标取自 `.desktop` 而非 `setWindowIcon`——T5 的 `setDesktopFileName` 与 T10 的 `StartupWMClass` 必须同名（`zen-studio`），缺一环则任务栏显示默认齿轮图标 |
| ⚠️ | `PROJECT_ROOT` 语义漂移 | T4 改路径推导后，`config/`（设置、最近项目）在打包态的写入位置仍是「解包目录」——用户数据应写用户目录而非安装目录，属**打包配置专题**，本计划只保证资源读取正确，写入路径另立计划处理 |
| 🟡 | 资产目录纪律 | Logo 全套只入 `assets/logo/`，禁止向 `assets/` 根散落文件；换标 = 改母版 + 重跑脚本，禁止手改单件 PNG 造成尺寸间不一致 |

## 7. 非目标（本期不做）

- ❌ 自绘无边框标题栏（标题正中嵌入 Logo 的唯一途径，工程量大，运行时图标落地后再评估立项）
- ❌ 候选池其余 5 稿的清理 / 删除
- ❌ Windows / macOS 任何适配（`.ico` / `.icns` / 签名 / 安装包，平台已排除）
- ❌ Linux 发行版包（.deb / .rpm / AppImage）制作——`.desktop` 手动拷贝即够当前使用
- ❌ hicolor 图标主题体系注册（多尺寸 PNG 已备源，需要时另立任务）
- ❌ 用户数据目录迁移（见 §6 风险表第三项）
