# Git 文件装饰与差异统计实施计划

## 一、目标与范围

按选型结论实现两个功能：

1. **Git 文件装饰**：文件树节点按 Git 状态变色——M 已修改（黄/橙）、U 未跟踪（绿）、D 已删除（红/灰）、ignored 忽略（变灰）
2. **文件级差异统计**：当前查看文件相对 HEAD 的 `+新增 -删除` 行数，显示于查看器标题行 tooltip 与状态栏

明确不做：Git 提交树、行粒度 gutter 色条、内嵌 diff 视图、标签页体系（当前查看器为单文件只读模式，无 tab，装饰落点为文件树 + 标题行）。

## 二、现状摸底（计划前提）

| 落点 | 现状 | 本计划动作 |
|---|---|---|

| 查看器 | `gui/panels/viewer/panel.py`：**只读**，AI-first 场景 agent 直接写盘，`QFileSystemWatcher` 监听外部修改自动重载 | 标题行追加 `+a -b` 统计与 tooltip；**无"用户保存"事件，刷新触发点需适配** |
