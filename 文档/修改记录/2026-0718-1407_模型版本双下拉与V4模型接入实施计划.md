## 1. 目标

将聊天面板的版本切换升级为"模型 + 版本"双下拉结构，并接入 DeepSeek V4 系列模型。前置计划：`2026-0718-1335_模型版本切换与思考块实施计划.md`（单下拉版已落地归档）。

## 2. 官方文档核实结论（[api-docs.deepseek.com](https://api-docs.deepseek.com/zh-cn/)，2026-07-18 时查）

### 2.1 模型清单

| 模型 ID | 性质 | 思考模式 | 备注 |
|:---|:---|:---|:---|
| `deepseek-v4-flash` | 正式（DeepSeek-V4-Flash） | 支持思考/非思考，**默认思考** | 输入 1 元/M、输出 2 元/M，并发 2500 |
| `deepseek-v4-pro` | 正式（DeepSeek-V4-Pro） | 支持思考/非思考，**默认思考** | 输入 3 元/M、输出 6 元/M，并发 500 |
| `deepseek-chat` | 遗留别名 = v4-flash **非思考** | — | ⏳ 2026/07/24 23:59 弃用 |
| `deepseek-reasoner` | 遗留别名 = v4-flash **思考** | — | ⏳ 2026/07/24 23:59 弃用 |

### 2.2 思考模式参数化（V4 关键架构变化）

- 开关：`extra_body={"thinking": {"type": "enabled" | "disabled"}}`（OpenAI SDK 写法），**默认 enabled**
- 强度：`reasoning_effort: "high" | "max"`（`low`/`medium` 映射为 `high`，`xhigh` 映射为 `max`；普通请求默认 `high`）
- 思维链仍经流式 `delta.reasoning_content` 返回——**现有 Chunk 解析代码继续兼容，无需改动**
- 思考模式下 `temperature`/`top_p` 等采样参数不生效（设置不报错）
- ⚠️ 认知更正：多轮拼接中，无工具调用时 `reasoning_content` 回传会被 API **忽略**（非 400；仅工具调用轮次必须回传否则 400）。现有"思维链剥离不入历史"策略继续安全，前次归档文档中"回传会 400"的表述应以此为准

## 3. 架构设计

核心变化：思考模式从"独立模型 ID"变为"请求参数"，版本项数据结构升级为 **模型 ID + 思考开关** 的组合。

```
llm/providers/deepseek.py     # 改：MODELS 重构为版本项列表（api_id + alias + thinking + deprecated）
                              #     chat() 按当前版本构造 extra_body thinking 参数
gui/panels/chat/model_bar.py  # 改：单 QComboBox → 双 QComboBox（模型 | 版本），模型变更刷新版本列表
```

### 3.1 版本项数据结构

```python
@dataclass(frozen=True)
class ModelVersion:
    api_id: str        # API 模型 ID
    alias: str         # 版本别名（UI 显示）
    thinking: bool     # 思考模式开关（经 extra_body 下发）
    send_thinking: bool = True  # 是否下发 thinking 参数（预留，本期恒 True）

MODELS: tuple[ModelVersion, ...] = (
    ModelVersion("deepseek-v4-flash", "V4 Flash · 思考", thinking=True),
    ModelVersion("deepseek-v4-flash", "V4 Flash · 非思考", thinking=False),
    ModelVersion("deepseek-v4-pro", "V4 Pro · 思考", thinking=True),
    ModelVersion("deepseek-v4-pro", "V4 Pro · 非思考", thinking=False),
)
DEFAULT_VERSION = MODELS[0]  # V4 Flash · 思考（官方默认即思考）
```

> 说明：旧别名（chat/reasoner，2026/07/24 弃用）经决策**不纳入**版本清单，直接以 V4 版本项起步，无兼容包袱。

### 3.2 组件职责

| 组件 | 职责 |
|:---|:---|
| `ModelVersion`（dataclass） | 版本项：API ID + 显示别名 + 思考开关 |
| `DeepSeekLLM.set_version(index \| api_id, thinking)` | 切换当前版本项；`chat()` 按 `send_thinking` 决定是否携带 `extra_body={"thinking": {"type": ...}}` |
| `label_for(version)` | 显示格式单点维护（沿用现有约定） |
| `ModelBar` | 双下拉：左「模型」（本期仅 DeepSeek 一项，占位未来多 provider）+ 右「版本」（4 项）；模型变更时刷新版本列表 |
| 思考强度 | 本期不显式传 `reasoning_effort`（走服务端默认 `high`），UI 暴露强度选择列为后续 |

### 3.3 关键行为约定

- 默认版本：**V4 Flash · 思考**（`deepseek-v4-flash` + thinking enabled，对齐官方默认）
- 旧别名（chat/reasoner）不纳入版本清单，无兼容包袱
- 切换语义不变：写 provider 单例状态、下次请求生效、发送中双下拉均锁定
- 思维链渲染链路（Chunk → Worker → Output 灰斜体）零改动
