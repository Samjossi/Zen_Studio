## 1. 说明范围

仅观察 PyGPT **主页面**的整体风格、配色与线条，不做全量样式统计。样式来源文件：

- 主题色定义：`参考代码/VS_Code_Python/src/pygpt_net/data/themes/dark.xml`（qt-material XML）
- 自定义覆盖：`参考代码/VS_Code_Python/src/pygpt_net/data/css/style.dark.css`
- 默认主题配置：`dark_darker`（见 config.json）
- **主题列表**：暗色 4 款（`dark` / `dark_gray` / `dark_darker` / `dark_darkest`）+ 浅色 2 款（`light` / `light_gray`），运行时可在设置中切换

## 2. 主页面风格速览

### 2.1 暗色主题（默认 `dark_darker`）

| 维度 | 样式 | 具体值 |
|:---|:---|:---|
| 整体风格 | **深色扁平风**（qt-material 打底 + 自定义 CSS 覆盖） | 默认主题 `dark_darker` |
| 背景色 | 深灰黑三层递进 | 主背景 `#232629`，次背景 `#31363b`，浅色面板 `#4f5b62` |
| 文字色 | 纯白 | `#ffffff` |
| 强调色 | 蓝色（选中态） | `#0765d4`，选中文字 `#ffffff` |
| 边框线条 | **细实线直角**，无圆角 | `1px solid #5c5c5c` |
| 字体 | Lato 全局强制 | `font-family: 'Lato' !important` |
| 控件高度 | 输入/列表行高紧凑 | 行高 30px，item 内边距 4px |
| 悬停反馈 | 极微弱提亮 | `rgba(255, 255, 255, 5)` |
| 文字变换 | 按钮/标签/表头不转大写 | `text-transform: none`（material 默认大写被关闭） |

### 2.2 浅色主题（`light` / `light_gray`）

| 维度 | 样式 | 具体值 |
|:---|:---|:---|
| 背景色 | 浅灰白 | `light`：主背景 `#dedede`；`light_gray`：主背景 `#ffffff`（面板 `#ebebeb`） |
| 文字色 | 纯黑 | `#000000` |
| 强调色 | 中灰 | `#828282`（浅色系选中强调较克制） |
| 边框/风格 | 与暗色一致 | 同款细实线直角，仅配色反转 |

> 说明：本文第 1 版只记录了默认暗色主题，浅色主题确实存在（`light.xml` / `light_gray.xml`），本节为补充。

## 3. 风格特征小结

1. **深色为主**：三层灰黑背景递进区分面板层级，无彩色装饰，视觉安静，适合长时间盯屏
2. **线条克制**：1px 细灰实线、直角无圆角，边界靠"色块差 + 细线"划分，不靠阴影
3. **去 material 化痕迹**：按钮不大写、悬停极弱，比原生 qt-material 更素
4. **蓝底白字选中**是唯一强对比元素，焦点导向明确

## 4. 对 Zen Studio 的参考结论

### 4.1 落地约定：`config/` 配置目录

项目根目录设 `config/` 存放配置选项与持久化配置：

| 文件 | 说明 |
|:---|:---|
| `config/settings.json` | 持久化用户配置，当前字段：`theme`（用户所选主题，默认 `dark`）、`font_family`、`font_size` |
| `config/themes/dark.qss` | 暗色主题配色文件（按本文 2.1 节色值编写） |
| `config/themes/light.qss` | 浅色主题配色文件（按本文 2.2 节色值编写） |

主题加载机制：启动时读 `settings.json` 的 `theme` 字段 → 加载对应 `config/themes/<主题名>.qss` 应用到 `QApplication`；用户切换主题时回写 `settings.json` 实现持久化。新增主题只需在 `config/themes/` 增加 qss 文件。

### 4.2 可借鉴点

| 可借鉴 | 说明 |
|:---|:---|
| ✅ 配色方案 | 暗色 `#232629`/`#31363b`/`#5c5c5c`/`#0765d4`、浅色 `#ffffff`/`#dedede`/`#828282` 两套体系均可直接作为主题初值（已落地为 4.1 的 qss 文件） |
| ✅ 明暗双主题 | 其"暗色 4 款 + 浅色 2 款、运行时切换"的机制值得借鉴；我们的主题系统应预留明暗切换（`config/themes/` 目录结构已预留） |
| ✅ 细线直角 | 与 IDE 气质相符，QSS 实现成本极低 |
| ✅ 覆盖模式 | qt-material 打底 + 自定义 CSS 覆盖的机制可照搬（`uv add qt-material` 即可，无前端工具链） |
| ⚠️ 字体 | Lato 对中文无覆盖，我们需换为系统中文字体栈（如 Noto Sans CJK） |
| ❌ 不宜照搬 | 其全局 `!important` 强制字体过于粗暴，建议改为应用级 `QFont` 设置 |

**结论**：主页面"深色扁平 + 细线直角 + 蓝色强调"的风格完全适合 IDE，配色值已落地为 `config/themes/` 下的 qss 主题文件，主题选择经 `config/settings.json` 持久化；同时作为 `2026-0718-1100_界面走查问题与优化计划.md` 第 2.3 节"全局 QSS 样式表"的输入。
