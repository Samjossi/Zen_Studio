## 1. 改动内容

`ChatTabs.__init__` 构造 `QTabWidget` 处（`setDocumentMode(True)` 之后）追加一行：

```python
# src/ide/gui/panels/chat/tabs.py
self._tabs.setDocumentMode(True)
# 关原生基线：drawBase 默认 True 时 QCommonStyle 以 palette.light()
# 在标签条顶画 1px 白线，透明 tab 盖不住，非白底主题显形
self._tabs.tabBar().setDrawBase(False)
```

根因：`QTabBar.drawBase` 默认 `True`，`paintEvent` 画任何标签之前先以 `palette.light()`（恒纯白）在基线矩形顶部画 1px 横线（`PE_FrameTabBarBase`）；本应用 QSS 规定未选中标签 `background: transparent` 盖不住基线，选中标签最后绘制置顶才把基线抹掉——故白线显形规律为「未选中区与空白区恒在、选中标签正上方缺失、非白底主题可见」。`setDrawBase(False)` 是 `QTabBar` 官方为自定义样式场景提供的开关，语义正中问题。
