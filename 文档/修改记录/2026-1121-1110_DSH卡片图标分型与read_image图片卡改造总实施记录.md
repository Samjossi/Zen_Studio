## 2. 结构映射

### 2.1 图标覆盖机制

```
公共 CollapsibleCard / ToolCard：_KIND_ICONS[kind] → _icon_label
DSH ToolCard：
  _header_icon: str = ""            # 类属性，空串表示不覆盖
  __init__(..., *, header_icon=None)
  super().__init__() 之后 _apply_header_icon()
      icon = header_icon or self._header_icon
      icon 非空 → self._icon_label.setText(icon)
```

覆盖点只在 DSH 厂商包内，Kimi/Local 与公共构造签名零改动。

### 2.2 卡型 → 图标

| 卡片类型 | 图标 | 来源 |
|:---|:---:|:---|
| `BashCard` | 💻 | 公共 `_KIND_ICONS[execute]` |
| `DiffCard` | 📝 | 公共 `_KIND_ICONS[edit]` |
| `TextOutputCard`（read/search/fetch） | 📄 / 🔍 / 🌐 | 公共 `_KIND_ICONS` |
| `SubagentCard` | 🤖 | 公共 `_KIND_ICONS[think]` |
| `MediaReadCard` | 👁️（`\U0001F441\uFE0F`） | 本类 `_header_icon` |
| `TodoListCard` | 🎯 | 本类 `_header_icon` |
| `McpCard`（MCP 服务器） | 🔌 | 工厂 `header_icon="🔌"` |
| `McpCard`（未知工具 / AskUserQuestion） | 🧩 | 本类 `_header_icon` |
| `QuestionCard` | ❓ | 预留类属性，未接分派 |
| `TodoCard`（计划通道） | 📋 | 保持不变（硬编码 QLabel） |
| `ThinkingCard` | 🧠 | 公共卡，未改 |

### 2.3 MCP 分派

```
make_tool_card:
  1. title 归一化 → _TOOL_NAME_CARDS（read_image / todo_write / subagent）
  2. tool_kind → execute / edit / read|search|fetch / think 专类
  3. 兜底：_is_mcp_tool(title) ? McpCard(header_icon="🔌") : McpCard()
```

`mcp__demo__read_image` 在第 1 步就命中 `MediaReadCard`（👁️），不会进入 🔌 分支；未知工具与裸 `AskUserQuestion` 仍是 🧩。

### 2.4 `read_image` 卡片

```
旧：MediaReadCard(McpCard)
    body = 入参标签 + 路径文本 + 320px 入参缩略图 + 出参标签 + BodyHtml

新：MediaReadCard(ToolCard)
    body = 主图 caption（输入/结果）
         + BodyHtml 主图（480px）
         + 入参 caption + BodyHtml 次级图（320px，仅结果图不同源时）
         + 降级说明（缺失/过大/不可读）
         + BodyText 出参文本兜底
         + 底部路径行（省略显示 + 复制完整路径）
```

- 副标题：`文件名 · 父目录名`，完整路径进 `_path_label` / `_subtitle_label` tooltip。
- 入参图与结果图同源（`file://` 归一后比较）时只显示结果图一次。
- `>10MB` 用 `MEDIA_THUMB_MAX_BYTES` 护栏，只出说明不内嵌。
- 无 `media_path` 时路径行隐藏，completed 的 `output` 进文本兜底区。
- failed 走 `_on_failed`，错误全文进文本兜底区（红色）。
- `_attach_input_detail = False`，不再挂通用入参块。
