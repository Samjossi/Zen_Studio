## 4. 经验沉淀

- **阻塞点的停止检查永远够不到**：只要 worker 线程可能无限阻塞，停止标志就必须让阻塞原语本身可中断（拆拍 + 事件），不能只靠上层轮询 chunk。
- **协议 cancel 与本地中断是互补关系**：协议通知给 agent 优雅收场的机会，本地事件保证 agent 沉默时也能解封；两者都要，顺序先通知后中断。
- **管道文件对象的关闭顺序纪律**：被另一线程迭代/读取的文件对象，主线程直接 close 会等读锁；必须先关写端让对方读 EOF 退出，再关读端。适用于一切 pipe/fd 测试桩。
- **看门狗判定口径取「无任何消息帧」而非「无正文」**：execute 运行中 in_progress 帧、思维链、tool 活动都算存活信号，只有 agent 彻底沉默才触发——避免误杀正常长等待任务（OAuth 授权）。
