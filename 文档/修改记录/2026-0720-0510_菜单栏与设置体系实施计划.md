---

## 1. 目标

按选型结论落地 **A2（模块化菜单 + 全局 Action 注册表）× S3（菜单直挂 + 打开原始配置文件双通道）**：

1. 菜单逻辑从 `gui/main_window.py` 迁出，新建 `gui/menus/` 包（每菜单一文件 + 装配器 + action 注册表）。
2. 补全五个顶层菜单：文件 / 编辑 / 视图 / 终端 / 设置 / 帮助（六含帮助）。
3. 落地两个新功能：**打开文件夹（工作区根切换）**、**查看器查找浮层**。
4. **全部菜单项不绑定快捷键**（选型 §4.4 排除项首条）。

目标菜单结构以选型文档 §4.1 为准，本文不重复，只列实施拆解。

## 2. 架构设计

### 2.1 新包结构

```
gui/menus/
├── __init__.py        # 对外导出 MenuBar 装配器
├── registry.py        # ActionRegistry：全局 action 注册表（字典 + 键名规范）
├── assembler.py       # MenuBar：依次调用各菜单构建函数，登记 action
├── file_menu.py       # 文件：打开文件/打开文件夹/打开配置目录/退出
├── edit_menu.py       # 编辑：复制/全选/查找（焦点转发与分发）
├── view_menu.py       # 视图：四面板显隐/噪音过滤/恢复默认布局/Git 刷新/外观▸主题
├── terminal_menu.py   # 终端：新建会话/清屏/重开/终止
├── settings_menu.py   # 设置：AI 模型▸/字体大小▸/打开配置文件/恢复默认设置
└── help_menu.py       # 帮助：关于（二期）
```

### 2.2 关键约定（实施时必须遵守，引自选型 §4.2 并具体化）

| 机制 | 约定 |
|:---|:---|
| action 注册表 | `ActionRegistry` 为 `dict[str, QAction]` 薄封装；键名 = `菜单.动作`（如 `file.open_folder`、`view.terminal`、`settings.font_size`）；装配器统一登记；模块经 `menus.action("view.terminal")` 按名取用 |
| 上下文注入 | 各菜单构建函数签名统一为 `build(menubar, ctx)`；`ctx` 为 `MainWindow` 本身（面板与槽的持有者），不另建上下文对象 |
| 面板显隐 | 沿用「单一入口」法：`_set_xxx_visible(v)` 同步 `setChecked` + `setVisible`；菜单勾选与面板头部「−」按钮汇入同一入口 |
| 单选组 | `QActionGroup(exclusive)` + `setData()` 载荷，单一回调读 `action.data()`；现有主题组的 N 闭包写法顺手重构 |
| 持久化 | 一律 `update_settings` 合并写回；`DEFAULT_SETTINGS` 补登 `font_family`、`workspace_root` |
| 快捷键 | 一律不绑定；Qt 控件内建 Ctrl+C/V/A 属控件级行为，不处理 |
| 跨平台 | 「退出/设置/关于」类 action `setMenuRole(NoRole)` 防 macOS 系统菜单抢走 |

### 2.3 MainWindow 减重后的职责

保留：面板创建与 splitter 装配、Git 状态服务、窗口几何持久化、**菜单槽函数**（打开文件夹、字体调整、恢复布局等）、面板显隐单一入口。迁出：全部 `addMenu`/`addAction` 代码与主题组构建。
