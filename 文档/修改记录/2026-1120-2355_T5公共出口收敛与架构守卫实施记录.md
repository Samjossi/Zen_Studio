## 4. 边界与偏差

- **`BACKEND_KIMI_ACP` 删除而非保留别名**：全库仅 `settings.py` 消费该常量；保留别名会形成第二个公共入口，违背 T5.1 收敛目标。改名为注册表常量 `DEFAULT_BACKEND` 后值不变、持久化键不变、用户可见默认后台不变。
- **`registry.py` 内仍保留具体 vendor ID 与 `reasoning_effort` 注释**：注册表是 T5 明定的组合根，必须知道注册名、厂商分组与装配细节；公共层词表守卫因此只扫描 `ide/llm/__init__.py`、`base.py`、`permission_policy.py`、`providers/__init__.py`、`providers/acp/` 与通用聊天 GUI，不把组合根算作公共层。
- **公共 ACP/base 注释中性化**：只改说明文字，不改字段、常量、异常类型或调用链；守卫用精确词表锁定，避免宽泛字符串规则误伤正常日志。
- **`PermissionDialog` 仍显示「Kimi ACP 请求执行工具」**：这是 T4 明确保留的用户可见文案，T5 的范围不含文案改版；已作为已知残留记录，后续如需中性化应单独立项并同步 DSH/Local 验收。
- **`KEY_KIMI_WIRE_SIDECAR` 仍留在 `settings.py`/`panel.py`**：它是 Kimi 子代理旁路的用户配置开关，不属于 T5「公共出口再导出」与「公共层词表」范围；通过 duck typing 注入，未形成厂商 ID 分支。
- **守卫为静态 AST 检查**：能阻止常见 import 与字符串回潮，但不能阻止 `getattr`/动态 `import_module` 绕过；代码评审红线仍需保留。厂商 GUI 包被允许 import 本厂商 `models.py` 纯类型（计划 §5.3 允许项），其余 LLM 模块一律禁止。
- 未启动 T6：按子计划门禁，T5 勾选后停止并等待用户明确批准。
