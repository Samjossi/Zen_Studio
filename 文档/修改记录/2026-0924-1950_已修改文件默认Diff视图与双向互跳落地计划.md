## 1. 需求背景

1749/1914 两计划已落地 Unified Diff 视图（difflib 行级差异 + 整行红绿底色 + hunk 蓝带 + 双列行号），但呈现形态是**弹窗对话框**（`DiffViewDialog`）。用户实测后明确反馈形态不对：

**要的不是弹窗，而是中栏内嵌**——文件树双击一个有改动（M）的文件时，直接在**中栏主显示区**（查看器面板，即平时显示文件全文的那块最大区域）渲染 diff 内容，不开任何弹窗。diff 成为中栏查看器的一种**显示模式**，与全文模式同位切换。

本 IDE 查看器只读（代码由 AI 改），M 文件默认 diff 模式直接回答"AI 改了什么"这一首要问题。

> 修订说明：本文档初版为"弹窗对话框 + 双向互跳"方案，实施完成后被用户否决形态，代码变更已整体抛弃（未提交），改写为本中栏内嵌方案。

## 2. 现状盘点

- 中栏查看器 `ViewerPanel`（`src/gui/panels/viewer/panel.py`）：只读，标题栏有路径标签 + git 徽标（`+a -b`）+ 阅览模式开关先例（Markdown 预览切换）
- 弹窗对话框 `DiffViewDialog`（`src/gui/diff_view_dialog.py`）：1914 计划的渲染成果（表格布局、整行底色、hunk 蓝带、行号列）在其 `_render` 内，数据链路（基准/工作区读取 + `unified_rows`）在其 `reload` 内
- 文件树双击链路：`main_window.py` 中 `file_explorer.file_opened → viewer_panel.open_file` 直连，无状态分发
- 变更面板双击：M → `diff_opened` → 弹窗；其余 → `file_opened` → 查看器
- 状态判定现成：`GitStatusService.status_of(abs)` + `MODIFIED` 常量

## 3. 方案

**D1：渲染与数据能力从对话框抽到共享模块 `src/gui/diff_render.py`。**
把 1914 成果的两部分原样搬迁、与对话框解耦：
- `build_diff_rows(repo_root, abs_path) -> tuple[str, list[DiffRow]] | tuple[None, str]`：基准读取 + 工作区读取 + `unified_rows`，返回（相对路径, 行序列）或（None, 降级文案）——六类降级判定原样保留
- `render_rows_html(rows, theme) -> str`：表格化 HTML 渲染（整行底色/hunk 蓝带/行号列，现状逻辑原样）
`src/core/` 零改动。

**D2：`ViewerPanel` 新增 diff 显示模式。**
- 新增 `open_diff(path)`：走 D1 数据链路，成功则把 diff HTML 渲染进查看器主显示区（与全文同一 QTextBrowser 通路）；失败按降级文案走既有占位形态
- 标题栏新增「差异 / 全文」模式切换（仿阅览模式开关先例）：仅当前文件有改动（numstat 存在）时可见；切到「全文」即调既有 `open_file` 重渲染
- `_current_path`、git 徽标、状态栏统计、外部重载监听等既有链路不变：diff 模式下 `_current_path` 照常记录该文件
- 字号链/主题链：查看器既有 `refresh_font`/`apply_theme` 覆盖 diff 渲染（重渲染即可）

**D3：入口分发收编到 `GitStatusController`。**
- 断开 `main_window.py` 的 `file_opened → viewer_panel.open_file` 直连，改接 controller `_open_from_explorer(path)`：`is_enabled` 且 `status_of == MODIFIED` → `viewer.open_diff(path)`；其余一切情况（无 git/U/无改动/读取失败）→ `viewer.open_file(path)`，行为不变
- 变更面板双击：M 行同样改指 `viewer.open_diff`（不再开弹窗），U/D 行为不变

**D4：删除弹窗对话框。**
`src/gui/diff_view_dialog.py` 整体删除；controllers 的 `_diff_dialog` 单例、`main_window.py` 字号链引用、变更面板 `diff_opened` 信号及接线同步移除。渲染成果已由 D1 继承，无功能损失。

**D5：降级原则。**
git 不可用、状态未知、基准读取失败等任何一环失败，静默落全文模式；diff 模式的六类降级文案原样保留（内嵌于中栏占位形态）。

**改动清单**：

1. `src/gui/diff_render.py`：新增（从对话框搬迁数据链路 + 渲染）。
2. `src/gui/panels/viewer/panel.py`：`open_diff` + 模式切换 + 显隐联动。
3. `src/gui/controllers.py`：`_open_from_explorer` 分发；变更面板 M 行改指 `open_diff`；移除对话框单例与接线。
4. `src/gui/main_window.py`：断文件树直连；移除字号链对话框引用。
5. `src/gui/panels/changes/panel.py`：移除 `diff_opened` 信号。
6. `src/gui/diff_view_dialog.py`：**删除**。
7. `tests/test_diff_view.py`：对话框用例改为查看器 diff 模式用例；新增分发分支用例。
8. `src/gui/README.md`：接线表/信号说明同步。
9. **不动**：`src/core/`、`src/gui/theme.py`（色键已就绪）、状态栏统计链路。

**明确不做**：Side-by-Side、词级高亮、折叠、全文与 diff 双栏同屏。
