## 1. 需求/背景

用户对 FindBar 三按钮的观感提出更大调整（实机截图反馈）：

1. **按钮内文字未居中**：▲▼× 字形在 24×22 钮内视觉偏位，需像素级居中。
2. **按钮太显眼**：希望复用文件树左下角悬浮搜索钮的**透明悬浮效果**——常态整体半透明、低调不抢眼，hover 时恢复全亮。
3. **字形定款 ▲/▼/×**：实心大三角本来扎眼，但配合透明悬浮把颜色调淡后就不再刺眼，且实心款辨识度最好。

> 另：用户同期让画的 SVG 箭头（`assets/icons/arrow_up.svg` / `arrow_down.svg`）是**独立素材**，用户未来手动迁移到其他项目使用，**不进 FindBar、不参与本计划**；已在 `assets/README.md` 登记为不打包素材库。

## 2. 现状梳理

### 2.1 FindBar 三按钮现状

- `src/gui/panels/find_bar.py`：三枚裸 `QPushButton`（▴/▾/×，`setFixedSize(24, 22)`），吃 `base.qss` 的 `#FindBar QPushButton { padding: 0; }`（1353 计划修复字形裁剪所加）。
- 现状钮为**常显全亮**：无透明度处理，按钮背景/hover 吃全局 `QPushButton` 规则，在浮层里存在感偏强。
- 居中问题：padding 已清零，Qt 默认居中对齐，但字形墨盒受字体度量影响可能偏位（文件树 ⌕ 钮曾实测偏位，靠不对称 padding 校准，见 §2.2）。

### 2.2 可复用的透明悬浮范式（文件树悬浮搜索钮/刷新钮）

`src/gui/panels/file_explorer/explorer.py` 的既有范式（`_build_search_button` / `_build_refresh_button` + `eventFilter`）：

- **常态半透明**：每钮挂 `QGraphicsOpacityEffect`，`setOpacity(0.5)`——整钮含符号一起变淡，不碰主题色键，六主题通吃。
- **hover 恢复**：钮上 `installEventFilter`，`QEvent.Enter → setOpacity(1.0)` / `Leave → 回落常态值`，瞬时切换无动画。
- **居中校准**：`#FileTreeSearchButton` qss 用不对称 padding（左 3 / 底 8）把偏小墨盒的 ⌕ 推回钮中心，像素实测校准（探针截图留档 `.temp/`）。

### 2.3 改动面

FindBar 被查看面板与终端面板共用，单点改动两处面板同时生效。无其他调用方触碰按钮外观。

## 3. 方案设计

### 3.1 透明悬浮化（复用文件树范式）

- `find_bar.py` 三按钮各挂一个 `QGraphicsOpacityEffect`，常态透明度常量 `_BUTTON_OPACITY`（**待定决策 1**，建议 0.5 与文件树一致）。
- FindBar 自身作 `eventFilter` 目标：三钮 `installEventFilter(self)`，`Enter → 1.0` / `Leave → _BUTTON_OPACITY`，逐钮独立恢复（与文件树逐钮范式一致）。
- 不动按钮背景/hover 的 qss 规则——变淡完全由 opacity 承担，六主题零适配成本。

### 3.2 字形定款 ▲/▼/× 与像素居中

- `prev_button`/`next_button` 文本 ▴▾ → ▲▼（× 不动），单点替换；文件内三处字形注释同步。
- 居中校准：探针放大截图逐钮目验墨盒位置；若偏位，按文件树 ⌕ 先例在 `#FindBar QPushButton` 规则上加小量不对称 padding 校准（像素实测，截图留档），不预设数值。
- 透明度落在实心大三角上后，「扎眼」问题由 §3.1 的常态变淡解决，与需求意图吻合。

### 改动清单

1. `src/gui/panels/find_bar.py`：三钮挂 `QGraphicsOpacityEffect` + eventFilter hover 恢复；字形 ▴▾ → ▲▼；注释同步。
2. `assets/themes/base.qss`：仅当 T2 目验确认偏位时，`#FindBar QPushButton` 加校准 padding（否则不动）。
3. 测试：无逻辑行为变化（信号/按键分发不动），不新增单元测试；视觉项走 T2 探针验证。

### 明确不做

- 不给透明度加渐变动画（文件树范式为瞬时切换，保持一致；动画属过度设计）。
- 不动输入框的半透明样式与浮层整体布局。
- 不动 × 关闭钮字形。
- 不改按钮尺寸（24×22 维持）。
- FindBar 不接入 SVG 图标（`assets/icons/` 为独立素材库，与本计划无关）。
