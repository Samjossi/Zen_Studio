> **时间**：2026-07-20 00:50（设计，UTC+8）/ 2026-07-20 01:15（实施）/ 2026-07-20 01:25（归档）
> **优先级**：中

## 1. 背景与目标

右栏文件树经 [2026-0719-0610 苹果风改造](文档/修改记录/2026-0719-0610_面板最小尺寸与苹果风界面改造计划.md) 后已有"白底卡片 + 1px 描边 + 6px 圆角 + 内留白"的完整包裹，观感良好，是当前界面的设计基准。但其余面板仍缺圆角卡片包裹：

- 中上文件查看器：`QPlainTextEdit` 仅 1px 描边、圆角归零（当时注释定为"保持文档感"），面板布局 0 边距直接顶满；
- 中下终端：`TerminalWidget` 为 `paintEvent` 自绘背景（`fillRect` 填满整个矩形），qss 的 `border-radius` 对其无效，完全无包裹，是三栏中最突兀的区域；
- 左栏聊天：`ChatOutput` 透明融入侧栏灰底，`ChatInput` 与模型行（QComboBox）零散铺在灰底上，无卡片聚合感。

**目标**：以文件树卡片为基准，为查看器、终端、聊天三处补齐统一的圆角卡片包裹，五主题（cloud/wheat/sky/mint/dark）同步生效，不破坏终端自绘、面板最小尺寸约束与窗口状态持久化等既有机制。

## 2. 现状分析

| 区域 | 现状 | 观感 |
|:---|:---|:---|
| 右栏文件树 [gui/panels/file_explorer/explorer.py](gui/panels/file_explorer/explorer.py) | `QTreeView` 在 qss 已有 `border + 6px 圆角 + 2px 内留白`，白底卡片浮于侧栏灰底 | ✅ 设计基准 |
| 中上查看器 [gui/panels/viewer/panel.py](gui/panels/viewer/panel.py) | `QPlainTextEdit` 1px 描边、圆角归零；布局 0 边距 | ❌ 直角、贴边 |
| 中下终端 [gui/panels/terminal/panel.py](gui/panels/terminal/panel.py) | `TerminalWidget` 自绘背景填满矩形，无包裹 | ❌ 直角、贴边，最突兀 |
| 左栏聊天 [gui/panels/chat/panel.py](gui/panels/chat/panel.py) | 输出区透明、输入框/下拉零散分布于灰底 | ⚠️ 半吊子 |

**关键技术约束（决定方案选型）**：

1. 终端自绘背景 → 不能只改 qss，必须**容器包裹**：外层 `QFrame` 圆角卡片 + 内边距，终端矩形缩进卡片内侧，圆角由容器背景兜住；`TerminalWidget.paintEvent` 本身零改动。
2. qss 不可使用全局 `QFrame`/`QWidget` 选择器——cloud.qss 头部注释明确警告：全局选择器会触发子控件 `WA_StyledBackground` 背景接管。卡片容器必须走 `objectName` 接线（如 `#PanelCard`），与现有 `#SidePanel` / `#PanelTitle` / `#PanelHint` 同一套机制。
3. 五份主题 qss 结构同构，样式需五份同步修改，暗主题用其既有色值体系。

## 3. 设计原则

1. **统一卡片规范**：新增 `#PanelCard` 规则——亮主题白底 + `#d2d2d7` 1px 描边 + 8px 圆角 + 内边距；暗主题用其深色底与既有描边色。容器圆角（8px）略大于内容物圆角（6px），符合设计惯例，不引入新色值。
2. **"标题行 + 内容"完整卡片**：各面板标题行（查看器路径行、终端 tab 头部栏）纳入卡片顶部，与文件树"根名标题 + 树"结构对齐。
3. **卡片内控件去双重描边**：`QPlainTextEdit`、终端等被卡片包裹后，自身描边改透明，由卡片统一描边。
4. **卡片间留白**：面板布局加 6~8px 外边距，卡片"浮"起于窗口底，形成苹果风卡片间距。
5. **零逻辑改动**：不触碰终端 `paintEvent`、pty 会话、watcher 重载等运行逻辑，仅调整容器装配与 qss。

## 4. 改造方案

### 4.1 qss：新增 `#PanelCard` 规则（五主题同步）

| 主题 | 卡片底色 | 描边 | 圆角 |
|:---|:---|:---|:---|
| cloud / wheat / sky / mint | `#ffffff` | `#d2d2d7`（沿用现有描边色） | 8px |
| dark | 沿用 dark.qss 既有深色面板色 | 沿用 dark.qss 既有描边色 | 8px |

同时调整：

- `QPlainTextEdit`：卡片内去描边（`border: none`），圆角归零的注释更新为"由卡片容器统一描边"；
- 终端查找浮层 `#TerminalFindBar` 是终端子控件，不受影响，保持现状。

### 4.2 终端面板卡片化（核心改动）

[gui/panels/terminal/panel.py](gui/panels/terminal/panel.py) `_build_terminal_area`：

- 新建 `QFrame`（`objectName="PanelCard"`，设 `WA_StyledBackground`），内部 `QVBoxLayout` 依次装入头部栏（tab 区 + 操作组）与 `TerminalWidget`；
- 卡片内边距 6~8px，终端矩形缩进后四角自然露出容器圆角；
- 面板主布局加外边距（见 4.5）。

**风险核查**：终端网格尺寸由 `TerminalWidget.grid_size()` 按自身控件尺寸计算，包裹后仅网格少几列，逻辑自洽；首启延迟 spawn 的 Resize 事件过滤安装在 `self.terminal` 上，包裹后 resize 仍正常派发，预计无碍，实施时截图验证首屏输出位置。

### 4.3 查看器面板卡片化

[gui/panels/viewer/panel.py](gui/panels/viewer/panel.py)：

- 标题行（路径 + 状态提示）与 `CodeViewer` 一并装入 `PanelCard`；
- `CodeViewer`（`QPlainTextEdit`）经 qss 去自身描边，由卡片统一描边。

### 4.4 聊天面板整合

[gui/panels/chat/panel.py](gui/panels/chat/panel.py)：

- 输出区 + 模型行 + 输入框整体装入一张 `PanelCard`（内部保留垂直 splitter，输出/输入比例可调与状态持久化逻辑不变）；
- `ChatOutput` 保持透明融入卡片白底；输入框/下拉保留各自 6px 圆角，嵌于卡片内。

### 4.5 面板间留白

各面板顶层布局 `setContentsMargins` 由 `(0,0,0,0)` 调整为 6~8px（左/右栏面板与中栏上下两面板统一），使卡片不贴窗口边缘与 splitter 把手。

### 4.6 验收：双主题截图走查

```bash

uv run python main.py --auto-screenshot --screenshot-on-start

# 切换视图菜单至暗色主题后再次截图走查
```

检查项：圆角完整无裁切、无双重边框、终端文字/光标不被圆角吃掉、splitter 拖至极限后卡片不破、面板最小宽度/高度约束（`MIN_WIDTH=240` / `MIN_HEIGHT=140`）不回退。

- 文件树：已是设计基准，不动；
- 菜单栏/状态栏/滚动条/菜单浮层等现有苹果风基底：不动；
- 终端 `paintEvent` 自绘逻辑、pty 会话栈、查找浮层定位逻辑：不动；
- 文件树选中态、hover 态等交互配色：不动。
