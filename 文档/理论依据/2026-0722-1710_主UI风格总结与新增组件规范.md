## 1. 设计基因（一句话基调）

**苹果风 + 1px 描边体系**：描边层次优于色块分区；焦点只变色不出框；
卡片化圆角层级递减；滚动条隐形；菜单栏/状态栏融入窗口底色；反色浮层提示。

圆角层级（全局统一，不可自创）：

| 层级 | 圆角 | 对象 |
|:---|:---:|:---|
| 容器 | 8px | 面板卡片 `#PanelCard`、浮层（QMenu/下拉弹出） |
| 内容物 | 6px | 输入框、按钮、下拉框、树/列表卡片 |
| 项 | 3~4px | 列表选中块、菜单项、菜单栏项 |

## 2. 主题架构（颜色唯一来源）

### 2.1 三层结构

```text
config/themes/base.qss      ← 唯一 qss 模板，$token 占位符，禁写死色值
gui/theme.py THEME_PALETTES ← 每主题一包令牌（当前四主题：云白/晴空/薄荷/麦黄，全亮色系）
gui/theme.py 资源包 ×5      ← SYNTAX/TERMINAL/CHROME/GIT_STATUS/CHAT 全库各一套，
                              四主题共享引用（共享即引用，不复制）
```

渲染：`string.Template.substitute` 全量替换，**缺键即抛 KeyError（fail-fast）**；
应用：`apply_theme(app)` 设 app 级样式表 + 全局字体（**不设 QPalette**）。

### 2.2 qss 令牌清单（新增组件可用的全部颜色词）

| 令牌 | 语义 | 典型用途 |
|:---|:---|:---|
| `accent` | 主题强调色 | 选中块、焦点描边、激活下划线 |
| `text` / `muted_text` | 正文 / 次级弱化 | 标题/正文 vs 提示说明 |
| `window_bg` / `sidebar_bg` / `card_bg` | 窗口底 / 侧栏底 / 卡片底 | 三层背景递进（三栏似分未分） |
| `border` / `border_hover` | 描边 / 悬停加深 | 1px 描边体系主力 |
| `input_bg` | 输入实底 | 输入框、按钮实底 |
| `combo_hover_bg` | 下拉 hover 底 | 仅 hover 伪态（亮色主题为 transparent） |
| `popup_bg` / `popup_border` / `popup_separator` / `menu_border` | 浮层系列 | 菜单、下拉弹出 |
| `list_item_hover` | 列表项悬停微染 | 树/列表 hover |
| `button_hover_bg` / `button_pressed_bg` | 按钮悬染/按染 | 按钮 |
| `button_disabled_text/bg/border` | 按钮禁用三件套 | 按钮 |
| `separator` / `splitter_hover` | 分隔线 / 分栏把手 | 1px 低存在感分隔 |
| `scrollbar_handle` / `scrollbar_handle_hover` | 隐形滚动条滑块 | 滚动条 |
| `tooltip_bg` / `tooltip_text` | 反色提示 | QToolTip |

**例外**：`WARNING_COLOR = #c0392b`（theme.py 单一来源）为跨主题固定警示红，
仅限危险操作/高危选项文案，不随主题。

### 2.3 新增主题

`THEME_PALETTES` 加一行字典（令牌全量 + 资源包引用或 `{**CHROME_PACK, ...}` 单项
覆盖）；架构中**不存在任何明暗判断代码**，新增深色主题同样逐值手写。

## 3. 布局骨架

```text
QMainWindow（$window_bg 底 + 融合菜单栏/状态栏）
└─ 中央容器：窗口级外边距 (12, 6, 12, 0)，spacing 0
   └─ QSplitter 水平三栏（把手 4px 常态透明 hover 显现）
      ├─ 左栏  ChatTabs      #SidePanel 侧栏底
      ├─ 中栏  垂直 QSplitter：ViewerPanel / TerminalPanel（#PanelCard 卡片）
      └─ 右栏  垂直 QSplitter：FileExplorer / ChangesPanel（#SidePanel + #PanelCard）
```

**objectName 接线表**（base.qss 已定义样式，新面板直接复用，禁止自造配色）：

| objectName | 样式 | 用法 |
|:---|:---|:---|
| `#SidePanel` | `sidebar_bg` 侧栏分区底 | 左/右栏面板容器 |
| `#PanelCard` | 8px 圆角卡片（card_bg + 1px border） | 面板内容统一包裹；卡内控件去自身描边防双重边框 |
| `#PanelTitle` | 半粗 500 + padding 2px 8px | 面板标题行 |
| `#PanelHint` | `muted_text` 次级灰 | 提示/徽标等弱化文字 |
| `#TerminalTabs` | 透明 tab 条 + 激活 2px accent 下划线 | 细条标签页 |
| `#ChatOutput` | 透明融入侧栏 | 只读输出区（双层 ID `#SidePanel #ChatOutput` 压特异性） |

接线铁律：自定义 QWidget/QFrame 子类挂 qss 背景必须
`setAttribute(WA_StyledBackground, True)`，否则不绘制。

## 4. 控件风格规范（逐项）

| 控件 | 规范 |
|:---|:---|
| 输入框 QLineEdit/QTextEdit | `input_bg` 实底 + 1px `border` + 6px 圆角 + padding 3px 7px；`:focus` 描边转 `accent`（只变色不出框） |
| 代码查看器 QPlainTextEdit | 透明融入卡片、自身无边框（文档感） |
| 按钮 QPushButton | 实体化：`input_bg` 实底 + 描边 + 6px 圆角 + padding 3px 11px；hover 主题色微染 + 描边加深；pressed 染加深；disabled 三件套 |
| 下拉框 QComboBox | 透明底（随所在面板）+ 描边 + 6px 圆角；**普通态禁设 background-color**（1259 教训：qss 背景接管 → 弹出列表选中白底白字）；hover 描边加深 |
| 树/列表 QTreeView/QListView | 卡片化：card_bg + 1px 描边 + 6px 圆角 + 2px 内留白；项 padding 4px 6px、选中 accent 实底白字不贴边、hover `list_item_hover` 微染、`outline: none` 去焦点虚线 |
| 菜单 QMenu/菜单栏 | 菜单栏透明融入窗口（文字距上缘 24px）；菜单为 8px 圆角浮层 + `menu_border` 描边保层级；选中 accent 白字；分隔线 1px |
| 滚动条 | 隐形：10px 宽无箭头、半透明圆角滑块（min 30px）、hover 加深 |
| 分隔 | 1px 低存在感 `separator`；QSplitter 把手 4px 常态透明 hover 显现 |
| 状态栏 | 透明融入、去尺寸把手、定高紧凑；操作反馈 `showMessage(文案, 3000)` |
| 工具提示 | 反色浮层（tooltip_bg/tooltip_text）、无边框 6px 圆角 |

## 5. 字体体系

- **双字体族全部自带**（`assets/fonts/` 注册，不引用系统字体）：
  UI 族 = 思源黑体 Source Han Sans CN；等宽族 = 更纱黑体 Sarasa Term SC（中英 2:1 严格等宽）
- UI 文字零设置（`apply_theme` 全局下发）；**等宽场景一律 `get_mono_family()`**
  （终端、代码查看器、黑名单只读区），禁手写 `"monospace"` 或系统字体名
- 字号用户可调（设置中心外观页，8~pt 上限经 MainWindow 收敛），组件不得写死字号

## 6. 新增组件硬规范（DO / DON'T）

### 6.1 颜色与样式

- ✅ 颜色一律来自 base.qss 令牌或 objectName 复用；非 qss 场景（model ForegroundRole
  等）从 `get_theme_palette(theme)` / 资源包取色
- ✅ 主题敏感的内联 style（如 hint 灰）须注册到面板 `apply_theme(theme)` 收敛点，
  挂 `MainWindow.switch_theme` 链随主题重刷
- ❌ 禁止 `setStyleSheet("color: #xxx")` 硬编码 hex（WARNING_COLOR 例外）
- ❌ 禁止 `QWidget { ... }` 全局选择器（子控件背景被 WA_StyledBackground 接管，
  盖住 #SidePanel 分区——base.qss 头部有专项警告）
- ❌ QComboBox 普通态禁设 background-color（1259 事件，机器断言拦截）
- ❌ 禁止新建第五套 qss 副本/第二模板；样式只进 base.qss

### 6.2 浮层与菜单

- ✅ 新建 QMenu 一律 `make_translucent_popup()`；新建 QComboBox 一律
  `make_translucent_combo_popup()`（gui/popups.py，消矩形底双框观感）
- ✅ 文本控件右键标准菜单用 `exec_standard_context_menu()` 或
  `TranslucentMenuLineEdit/PlainTextEdit`，不覆盖 contextMenuEvent 自弹
- ❌ 禁自建右键菜单项（取控件内建 createStandardContextMenu，不丢项）

### 6.3 尺寸与布局

- ✅ 物理尺寸（行高/最小尺寸/定高）走代码：`setSizeHint(QSize(0, h))`、
  `setFixedHeight`、`setMinimumSize`——**禁 qss min-height 控 item 行高**
  （1510 复核教训：平台 QStyle 不采纳致文字重叠；`QSize(-1, h)` 无效尺寸
  会被 setSizeHint 清除，宽须 0 占位）
- ✅ 外边距/间距职责分离：窗口级边距在中央容器，面板级 6px 各自管理
- ❌ 禁给 QMainWindow 的 menubar 设 qss margin（不采纳；镜像余量已有
  `_fit_menubar_height` 代码侧截断先例）

### 6.4 交互与反馈

- ✅ 偏好类改动即时生效 + 状态栏反馈：`showMessage(f"{页名}：{项} → {值}", 3000)`
- ✅ 破坏性操作二次确认（默认按钮为取消）+ 文案警示用 WARNING_COLOR
- ✅ busy 态禁用相关控件（模型切换等），与既有收敛点对齐
- ✅ 新设置项走 settings_dialog docstring 四步流程（KEY 常量 → build →
  reload → 注册表一行），禁止向菜单直挂偏好项
