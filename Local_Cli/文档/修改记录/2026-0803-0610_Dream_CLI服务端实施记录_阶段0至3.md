## 2. 关键设计决策

- **OOP 模块式重构**：以 `参考代码/dream-acp/example/dream`（零依赖单文件参考实现）为
  行为基准，按单一职责拆为 `acp/transport.py`、`acp/dispatcher.py`、`acp/session.py`、
  `acp/turn.py` 四层；模型层 `model/base.py`（ABC 仅 3 个小契约）+ `model/mock.py`。
- **协议附录 A 教训落码**：A.1 不动 authMethods；A.2 cwd 相对路径硬拒 -32602；
  A.3 轮次失败显式 `stopReason="error"`；A.4 容忍空 text 块；A.5 错误文案含引导；
  A.6 日志一律 stderr（stdout 只写协议帧）。落码处均有出处注释。
- **反向请求 id 独立编号空间**：`"perm-N"` 字符串，与客户端整数 id 不碰撞。
- **TurnRunner 依赖 MockLanguageModel 而非 ABC**：意图分类 `classify()` 是 Mock 私有
  能力，不污染「小而专」的 LanguageModel 抽象；真实模型接入时轮次编排随之演进。
- **GUI 服务语义 = 内嵌 ACP 客户端自连**：`GuiAcpService` 用 `MemoryPipe` 顶替 stdio
  端点，守护线程运行完整协议内核，GUI 侧内嵌最小 ACP 客户端走真实 ndjson 帧握手。
  会话 ID/模型别名/连接状态均为协议协商真值；停止服务 = 关管道送 EOF，与 CLI 模式
  同一条收尾路径。内核 `acp/` 零改动、不 import GUI。
- **GUI 视觉**：云白主题语义令牌（`gui/theme.py`），QSS 实现 1px 描边、圆角三级
  8/6/3、隐形滚动条等核心铁律；优雅退出挂 `aboutToQuit`，幂等 `stop()`。
