# GUI 包说明

> **状态**：草稿

## 1. 概述

`gui/` 存放 Zen Studio 全部图形界面代码，基于 **PySide6**。入口文件 [`main.py`](../main.py) 仅负责创建应用并显示主窗口，不包含任何界面实现。

## 2. 文件结构

| 文件 | 说明 |
|:---|:---|
| [`__init__.py`](__init__.py) | 包初始化，对外导出 `MainWindow` |
| [`main_window.py`](main_window.py) | 主窗口与三栏式布局实现 |

## 3. 布局图

主窗口采用 `QSplitter` 嵌套布局：外层水平三栏，中栏内部垂直拆分为上下两部分，分隔条均可拖动调整：

```
┌────────────────────────── Zen Studio (1200×800) ──────────────────────────┐
│                                                                            │
│ ┌──────────────┬──────────────────────────────────┬──────────────┐      │
│ │              │                                  │              │      │
│ │              │         中栏（上，550 px）        │              │      │
│ │              │                                  │              │      │
│ │     左栏     ├──────────────────────────────────┤     右栏     │      │
│ │   (250 px)   │  ▲ 可拖动分隔条 (垂直 QSplitter) ▼ │   (250 px)   │      │
│ │              │         中栏下（250 px）          │              │      │
│ │              │                                  │              │      │
│ └──────────────┴──────────────────────────────────┴──────────────┘      │
│        ◀═══ 可拖动分隔条 (水平 QSplitter) ═══▶                             │
└────────────────────────────────────────────────────────────────────────────┘
```

| 栏位 | 初始尺寸 | 当前内容 |
|:---|:---:|:---|
| 左栏 | 250 px | 占位面板 |
| 中栏（上） | 550 px（高） | 占位面板 |
| 中栏下 | 250 px（高） | 占位面板 |
| 右栏 | 250 px | 占位面板 |

## 4. 运行方式

# 项目根目录执行
