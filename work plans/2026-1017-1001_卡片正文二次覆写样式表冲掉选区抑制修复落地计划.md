## 1. 需求背景

`2026-1013-1105_卡片轨选区高亮偏下修复落地计划.md` 已实施并真机验证闭环：AI 正文流式块选区带上下对称（用户截图①确认）。

用户新反馈（2026-10-17，截图②）：**工具卡内文字选区高亮仍是修复前的原生形态**——Grep 卡「入参」区拖选时，高亮带整行高铺满、贴行框下缘（偏下），且色深明显重于正文块的半透明带。

## 2. 现状诊断

**根因：二次 `setStyleSheet` 整表替换，把构造时并入的 `SUPPRESSION_QSS` 冲掉。**

`BodyText` / `BodyHtml` 构造时在 ID 选择器样式表内并入抑制声明（1105 计划 T1/T2），但 `cards.py` 有四处对正文块实例**再次调用 `setStyleSheet` 整表覆写**（为上色/斜体），新样式表不含抑制声明——Qt 样式表是整表替换语义，抑制随之丢失：

| # | 位置 | 场景 | 覆写目的 |
|:---:|:---|:---|:---|
| ① | `src/gui/panels/chat/cards.py` `ToolCard._add_input_detail` | **通用入参区（截图② Grep 卡即此）** | 弱化灰字 |
| ② | `src/gui/panels/chat/cards.py` `ToolCard._set_error_body` | 各工具卡 failed 错误全文块 | 红字 |
| ③ | `src/gui/panels/chat/cards.py` `BashCard._on_failed` | bash 失败输出区换色 | 红字 |
| ④ | `src/gui/panels/chat/cards.py` `ThinkingCard.__init__` | 思维链正文 | 灰斜体 |

**表现加重的原因**：`paintEvent` 自绘带是类方法、始终在位；抑制丢失后原生带回归，自绘带仍照常叠绘——**双层带叠加**（原生带不透明铺满整行高 + 自绘带 alpha 110），正对应截图②的深重色带观感。

**未受影响面（已逐一核对）**：`McpCard` 入参/出参、BashCard 命令头与输出、DiffCard、TextOutputCard、AskCard 兜底块、MediaReadCard 略缩图、用户气泡体（`src/gui/panels/chat/transcript.py`）——构造后均无二次覆写，抑制在位。存量测试 `tests/test_card_selection_band.py` 只断言构造态样式表，覆写路径无覆盖，故漏网。

## 3. 方案设计

**D1（收敛覆写入口，单一 choke point）**：`BodyText` / `BodyHtml` 各增一个附加样式方法，约定**禁止对正文块裸调 `setStyleSheet` 覆写**：

```python
# src/gui/panels/chat/cards.py
def set_extra_style(self, extra: str) -> None:
    """附加声明（颜色/斜体等）统一入口：重建整表，抑制声明常驻。

    Qt 样式表整表替换——裸 setStyleSheet 会冲掉 SUPPRESSION_QSS
    致原生偏下带回归（2026-1017 用户真机截图实证）。
    """
    self.setStyleSheet(
        "#CardBodyText { background: transparent; border: none; "
        + SUPPRESSION_QSS + " " + extra + " }")
```

`BodyHtml` 同型（选择器 `#CardBodyHtml`）。构造期样式表逻辑不变，本方法与其共用同一段拼接（私有 helper 收敛，避免两处字符串漂移）。

**D2（四处点位改走 D1 入口）**：

- ① `_add_input_detail`：`text.set_extra_style(f"color: {self._colors.tool_fg};")`
- ② `_set_error_body`：`body.set_extra_style(f"color: {self._colors.tool_error_fg};")`
- ③ `BashCard._on_failed`：`self._output.set_extra_style(f"color: {self._colors.tool_error_fg};")`
- ④ `ThinkingCard.__init__`：`self._text.set_extra_style(f"color: {colors.reasoning_fg}; font-style: italic;")`

**D3（回归测试，覆写路径首次入测）**：`tests/test_card_selection_band.py` 增补——

- 单元级：`BodyText` / `BodyHtml` 调 `set_extra_style` 后样式表仍含 `selection-background-color: rgba(0,0,0,0)` 与 ID 选择器；
- 集成级：实例化 `ThinkingCard`（stub `split_heading`）、`BashCard` 走 `_on_failed` 帧、任一 `ToolCard` 子类触发 `_add_input_detail` / `_set_error_body`，断言对应正文块样式表抑制在位（offscreen，卡构造所需 `CardColors`/`OpenStateMap`/payload 按最小桩构造）。

**D4（零改动红线）**：`selection_band.py` 算法与常量、构造期样式表、旧轨三处挂载点、终端面板一律不动；未覆写的正文块实例不逐个点名改动（D1 入口自然覆盖）。

**D5（QLabel 开放项维持不处理）**：`_selectable(QLabel)` 短单行标签原生选区偏下问题，沿用 1105 计划 D5 结论——本计划不处理，用户真机仍觉碍眼另立项。

**D6（静态守卫硬拦截，用户拍板并入）**：`scripts/check_qss_selector_guard.py` 增第二条规则——扫描 `src/gui/panels/chat/` 下全部 `setStyleSheet` 调用，命中「字符串常量段含 `#CardBodyText` / `#CardBodyHtml` 选择器 **且** 参数表达式未引用 `SUPPRESSION_QSS`」（AST 层判 Name 节点，与既有 `_constant_parts` 同手法）即违规非零退出。T2 落地后全仓仅剩构造期/helper 内两处合法引用（均含 `SUPPRESSION_QSS`），规则零误报；未来任何裸覆写在门禁阶段即被拦。守卫 docstring 补根因一句。

## 5. 风险与开放项

- ⚠️ **气泡/主题色注入**：`set_extra_style` 走 palette 兜底带色口径不变（1105 计划 D3），本计划不新增主题注入通道。
- ⚠️ **守卫口径**：D6 规则只认「引用 `SUPPRESSION_QSS`」为合法，若未来出现正当的第三处整表覆写场景，须走 helper 或显式引用抑制常量过检——刻意抬高裸覆写成本。
- 开放项：`_selectable(QLabel)` 原生选区偏下（D5）；`band_color` 主题注入通道（1105 计划 D3 遗留）。
