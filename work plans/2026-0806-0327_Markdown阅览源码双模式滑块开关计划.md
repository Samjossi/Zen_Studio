# 中栏 Markdown 阅览/源码双模式滑块开关实施计划（初稿，待审阅）

日期：2026-08-06

## 一、需求

1. 在中栏查看面板（ViewerPanel）标题行增加一个**动态标签滑块开关**（复用 `动态标签滑块开关_复用说明.md` 中的 ToggleSwitch 方案）。
2. 开关**仅在阅览 Markdown 文档时生效**（仅在 Markdown 页可见、可操作）；
   其他所有场景（文本/图片/媒体/PDF/占位页）一律隐藏，不呈现任何编辑入口。
3. 开关两态文案定制：
   - 关（左，默认）：「**阅览模式**」——现状的 GFM 渲染预览。
   - 开（右）：「**源码模式**」——**仅显示源码、不渲染、也不能编辑**（只读源码视图）。
4. 本项目不支持编辑功能：源码模式复用只读 CodeViewer 展示，而不是提供编辑器。

## 二、现状分析

- `gui/panels/viewer/panel.py` ViewerPanel：QStackedLayout 五页
  （文本 CodeViewer / 图片 / 媒体 / Markdown / PDF）。
  `.md/.markdown` 经 `open_file` → `_open_markdown()` 直进 `MarkdownView` 渲染页
  （当初决策：不做源码↔渲染双模式，本计划**推翻该决策**，改为开关切换双模式）。
- 标题行已有「按钮组按页显隐」先例：`_image_buttons` / `_pdf_buttons`
  均为独立 QWidget 容器，`setVisible()` 随页切换——开关组完全套用该模式。
- `MarkdownView` 负责渲染；源码态所需的只读 + 语法高亮能力
  已由文本页 `CodeViewer` + `PygmentsHighlighter` 具备（`.md` 有 Pygments lexer）。
- ToggleSwitch 参考实现见 `动态标签滑块开关_复用说明.md`，
  关键坑：动画属性必须注册为 Qt `Property`（Python `@property` 无效）。

## 三、方案设计

### D1 开关组形态与位置

标题行新增 `_md_switch_box` 容器（`_build_md_switch()` 装配，镜像 `_build_image_buttons` 先例）：

```
[动态标签 QLabel] + [ToggleSwitch]
```

- 位置：标题行右侧，位于 `_hint_label` 之前、按钮组之后。
- 可见性：**仅 Markdown 页可见**。`_open_markdown()` 中 `setVisible(True)`；
  其余所有上屏/回落路径（文本页、`_open_image`、`_open_media`、`_open_pdf`、
  `_show_placeholder`）统一 `setVisible(False)`——与 `_image_buttons.setVisible(False)`
  同点补一行，漏补审查点列入 T 任务。
- 默认态：**关 = 阅览模式**（保持现状首进渲染页行为，不改变既有用户习惯）。

### D2 两态语义与配色

| 态 | 标签文本 | 语义 | 轨道色 |
|---|---|---|---|
| 关（左） | 阅览模式 | GFM 渲染预览（现状） | 主题 accent（蓝系） |
| 开（右） | 源码模式 | 只读源码 + Pygments 高亮 | 自定义对比色（蛋黄色 `#f5b301`，同参考文档） |

两态对色表达「模式差异」而非「开/关」语义。颜色首期按参考文档构造函数传参；
如需主题化留后续（参考文档「可选：接入主题系统」一节）。

### D3 源码模式实现：复用文本页 CodeViewer

源码模式**不新建控件**，复用现有文本页 `self.viewer`（CodeViewer 只读 +
PygmentsHighlighter）：

- 切到源码模式：
  1. 读盘 → 1MB 截断守卫 → UTF-8 解码（与文本页 open_file 同套守卫；
     MarkdownView.open_markdown 已有同逻辑，提取为面板级私有方法 `_read_text(p)`
     供两态共用，避免双份守卫漂移）。
  2. `self.viewer.setPlainText(text)` + `self._highlighter.set_source(p.name, text)`。
  3. `self._stack.setCurrentWidget(self.viewer)`。
- 切回阅览模式：`self._stack.setCurrentWidget(self.markdown_view)`——
  **不重渲染**（MarkdownView 文档仍在，setMarkdown 内容未丢），零开销瞬时切换。
- watcher / Git 徽标 / 标题行路径均不受影响（同一文件，已在 `_open_markdown` 挂好）。

### D4 查找浮层在源码模式下的行为

- 现状：Markdown 渲染页 `show_find()` 降级弱提示「Markdown 渲染页不支持查找」，
  判定依据是 `_stack.currentWidget() is self.markdown_view`。
- 切到源码模式后当前页变为 CodeViewer，`show_find()` 自动恢复可用——
  **无需改动**，天然符合「源码可查找」直觉。收益点写入文档。

### D5 toggled 槽与标签更新

```python
def _on_md_mode_toggled(self, checked: bool) -> None:
    self._md_mode_label.setText("源码模式" if checked else "阅览模式")
    ...  # D3 切换逻辑
```

- 开关 `toggled` 信号驱动：标签文本 + 页面切换同一槽内完成。
- `_open_markdown()` 打开新 md 文件时**复位开关**：
  `self._md_switch.setChecked(False)`（触发 toggled → 标签自动回「阅览模式」，
  无需额外同步代码——参考文档要点）。注意复位发生在渲染上屏**之后**，
  避免 toggled 槽把刚切的页面又切走（槽内加守卫：仅当 `_current_path`
  是 md 文件时才执行页面切换）。

### D6 非 Markdown 场景的隔离保证

- 开关组默认 `setVisible(False)`（构建时），仅 `_open_markdown` 置 True。
- toggled 槽守卫：`self._current_path` 后缀不在 `MARKDOWN_EXTS` 时直接 return，
  双保险防信号误触。
- 其他页（文本/图片/媒体/PDF）无任何入口可达此开关。

### D7 ToggleSwitch 控件落地

新建 `gui/widgets/toggle_switch.py`（若 gui/widgets 包不存在则建之，
或放 `gui/panels/viewer/toggle_switch.py`，实施时按包结构惯例定）：
逐字采用参考文档「完整代码 §1」实现（Qt `Property` 注册动画属性、
150ms InOutCubic、两态对色轨道 + 白色圆形滑块），不改逻辑，仅定模块位置。

## 四、任务分解

- **T1** 新建 `toggle_switch.py`：照参考文档实现 ToggleSwitch（QAbstractButton
  自绘 + Qt Property 动画）。离屏冒烟：offscreen 实例化、setChecked、
  offset 属性读写断言（参考文档「验证」一节脚本）。
- **T2** ViewerPanel `_build_md_switch()`：装配「动态标签 + 开关」容器，
  默认隐藏；插入标题行布局（hint_label 之前）。
- **T3** 提取 `_read_text(p) -> tuple[str, bool] | str`（成功返回 (文本, 是否截断)，
  失败返回原因）供 Markdown 渲染/源码两态与既有文本页共用（文本页 open_file
  顺路收敛，不强行重构，允许保留现状仅 Markdown 路径使用）。
- **T4** `_on_md_mode_toggled` 槽：标签切换 + D3 页面切换 + D6 守卫接线。
- **T5** `_open_markdown()` 改造：开关组 `setVisible(True)` + 复位
  `setChecked(False)`；其余五条上屏/回落路径补 `setVisible(False)`。
- **T6** 冒烟验证（QT_QPA_PLATFORM=offscreen 探针）：
  1. 打开 md → 开关组可见、标签「阅览模式」、当前页 markdown_view；
  2. setChecked(True) → 标签「源码模式」、当前页 viewer、内容为源码文本、
     viewer 只读（`isReadOnly()`）；
  3. setChecked(False) → 回到渲染页；
  4. 打开 .py → 开关组隐藏；打开图片/PDF → 开关组隐藏；
  5. 源码模式下 show_find() 不出现降级提示。
- **T7** 视觉验证（按 `视觉验证闭环开发指南.md`）：截图两态标题行 + 页面，
  确认开关颜色、滑块位置、标签文本、源码高亮正确。

## 五、影响面与风险

| 项 | 说明 |
|---|---|
| 行为变更 | md 文件新增可切源码视图；默认仍为渲染页，既有习惯不变 |
| 推翻旧决策 | 2026-0729-1155 计划「不做源码↔渲染双模式」——panel.py / markdown_view.py 模块 docstring 相应更新注明本计划 |
| 风险 R1 | `_open_markdown` 复位 setChecked(False) 触发 toggled 过早切页——D5 守卫 + 复位顺序约束 |
| 风险 R2 | 漏补某条路径的 setVisible(False) 导致开关在错误页面残留——T5 清单化五条路径逐一核对，T6-4 探针覆盖 |
| 风险 R3 | ToggleSwitch 动画属性误用 Python @property——T1 直接照抄参考实现规避 |

## 六、不做的事

- 不提供任何编辑能力（源码模式只读）。
- 不为非 Markdown 文件提供此开关。
- 不改动 MarkdownView 渲染逻辑、链接分发、Typora 入口。
- 开关颜色暂不接入主题令牌（硬编码构造参数，后续需要再主题化）。
