# 自定义标题栏增量实施计划

## 1. 目标

隐藏系统原生标题栏，改用自绘 `TitleBar`：左侧 Logo（16×16）+ 标题 "Zen Studio"，
右侧最小化 / 最大化 / 关闭三按钮；支持拖拽移动、双击切换最大化、最大化态拖拽
自动还原并跟随鼠标。**零回归**：菜单栏、状态栏、中央三栏、全部右键菜单与快捷键
行为不变。不做边缘缩放、Aero Snap、标题栏系统右键菜单。

## 2. 现状摸底（实施前已核实）

| 事实 | 影响 |
|:---|:---|
| `gui/menus/assembler.py` 的 `MenuBar.setup()` 调用 `self._window.menuBar()`，占用 QMainWindow 菜单槽位 | QMainWindow 布局为 [菜单槽][工具栏][中央][状态栏]，**无公开 API 在菜单槽之上插部件** → 菜单栏须迁入中央容器（见 §3 选型） |
| 中央容器边距体系精密（`gui/main_window.py` 头注释：左/右 12px、上 6px、底 0） | TitleBar 与菜单栏行插入时 margin/spacing 必须为 0，不触碰既有数值 |
| Logo 资产齐全：`assets/logo/logo.svg` + `logo_16.png` 等成套 PNG（`core/paths.py` 的 `LOGO_DIR`） | 无需新增资产；SVG 经 Qt svg 插件加载，失败回退 `logo_16.png` |
| 窗口几何持久化在 `WindowStateStore`（`gui/controllers.py`），closeEvent 单一入口保存 | 无边框化后 `saveGeometry/restoreGeometry` 语义不变，但最大化态恢复需走查 |
| 现有四主题均为亮色，色值集中在 `gui/theme.py` 调色板 + `assets/themes/base.qss` 令牌 | 需求指定深色标题栏（`#252526`/`#cccccc`），与亮色主题并存属**决策点 D1** |

## 3. 方案选型

### 3.1 标题栏挂载位置（核心决策）

| 方案 | 结论 |
|:---|:---|
| A. `setMenuWidget(titlebar)` 占用菜单槽，菜单栏另寻位置 | ❌ 否决：`menuBar()` 被调时会替换 menu widget（`_fit_menubar_height` 正在调用），互相覆盖 |
| B. TitleBar 作首行插入中央容器 QVBoxLayout，菜单栏 reparent 为其下第二行 | ✅ 采纳：官方支持、改动集中、菜单栏对象本身零改动 |
| C. TitleBar 塞进工具栏区（QToolBar 承载） | ❌ 否决：工具栏可拖动/可右键，语义错误 |

**方案 B 布局结果**（中央容器 vbox，margins/spacing 全 0）：

```
[TitleBar（新增，定高 32）]
[QMenuBar（原有，reparent 迁入；_fit_menubar_height 定高逻辑不变）]
[原内容包装器（原有 margins 12,6,12,0，内含 splitter_main）]
[StatusBar（QMainWindow 原生槽位，不动）]
```

### 3.2 拖拽移动实现

| 手段 | 结论 |
|:---|:---|
| 优先 `windowHandle().startSystemMove()` | ✅ Wayland(xdg-toplevel move)/X11 均由 WM 接管，流畅无闪烁，且自动处理"最大化态拖拽还原跟随"的一半语义 |
| 手动 `move(globalPos - offset)` 兜底 | 保留：`startSystemMove()` 返回 False（罕见 WM 不支持）时降级 |

最大化态拖拽：按下时若 `isMaximized()`，按光标在栏内横向比例换算还原后窗口左上
（`newX = globalX - ratio * normalWidth`），`showNormal()` 后立即接续拖拽。

### 3.3 无边框化方式

`setWindowFlags(self.windowFlags() | Qt.FramelessWindowHint)` 一行；保留 `Window`
类型标志（任务栏/Alt-Tab/最小化行为正常）。副作用走查清单见 §6。

## 5. 集成改动示例（交付时精确到行）

`gui/main_window.py` 预期净增约 10 行、改动 2 行：

```python
# gui/main_window.py
def __init__(self, ...):
    super().__init__()
    self.setWindowFlags(self.windowFlags() | Qt.WindowType.FramelessWindowHint)  # 新增：隐藏原生标题栏
    ...

def _build_layout(self) -> None:
    ...  # 原有 splitter 装配不动
    central = QWidget(self)
    outer = QVBoxLayout(central)
    outer.setContentsMargins(0, 0, 0, 0)   # 改动：原 (12, 6, 12, 0) 下沉到 wrapper
    outer.setSpacing(0)
    # ---- 新增：标题栏 + 菜单栏行 ----
    self.title_bar = TitleBar(self)
    outer.addWidget(self.title_bar)
    outer.addWidget(self._menu_bar)        # 原 QMenuBar reparent（T8 创建）
    # ---- 新增结束 ----
    content = QWidget()                    # 新增：原 margins 原样承接
    inner = QVBoxLayout(content)
    inner.setContentsMargins(12, 6, 12, 0) # 原有数值，未改
    inner.setSpacing(0)
    inner.addWidget(self._splitter_main)
    outer.addWidget(content)
    self.setCentralWidget(central)
```
