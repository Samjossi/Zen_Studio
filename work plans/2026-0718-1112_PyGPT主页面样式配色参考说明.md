## 1. 说明范围

仅观察 PyGPT **主页面**的整体风格、配色与线条，不做全量样式统计。样式来源文件：

- 主题色定义：[`参考代码/VS_Code_Python/src/pygpt_net/data/themes/dark.xml`](参考代码/VS_Code_Python/src/pygpt_net/data/themes/dark.xml)（qt-material XML）
- 自定义覆盖：[`参考代码/VS_Code_Python/src/pygpt_net/data/css/style.dark.css`](参考代码/VS_Code_Python/src/pygpt_net/data/css/style.dark.css)
- 默认主题配置：`dark_darker`（见 config.json）

## 2. 主页面风格速览

| 维度 | 样式 | 具体值 |
|:---|:---|:---|
| 整体风格 | **深色扁平风**（qt-material 打底 + 自定义 CSS 覆盖） | 默认主题 `dark_darker` |
| 背景色 | 深灰黑三层递进 | 主背景 `#232629`，次背景 `#31363b`，浅色面板 `#4f5b62` |
| 文字色 | 纯白 | `#ffffff` |
| 强调色 | 蓝色（选中态） | `#0765d4`，选中文字 `#ffffff` |
| 边框线条 | **细实线直角**，无圆角 | `1px solid #5c5c5c` |
| 字体 | Lato 全局强制 | `font-family: 'Lato' !important` |
| 控件高度 | 输入/列表行高紧凑 | 行高 30px，item 内边距 4px |
| 悬停反馈 | 极微弱提亮 | `rgba(255, 255, 255, 5)` |
| 文字变换 | 按钮/标签/表头不转大写 | `text-transform: none`（material 默认大写被关闭） |

## 3. 风格特征小结

1. **深色为主**：三层灰黑背景递进区分面板层级，无彩色装饰，视觉安静，适合长时间盯屏
2. **线条克制**：1px 细灰实线、直角无圆角，边界靠"色块差 + 细线"划分，不靠阴影
3. **去 material 化痕迹**：按钮不大写、悬停极弱，比原生 qt-material 更素
4. **蓝底白字选中**是唯一强对比元素，焦点导向明确

## 4. 对 Zen Studio 的参考结论

| 可借鉴 | 说明 |
|:---|:---|
| ✅ 配色方案 | `#232629`/`#31363b`/`#5c5c5c`/`#0765d4` 这套深灰蓝体系可直接作为我们的暗色主题初值 |
| ✅ 细线直角 | 与 IDE 气质相符，QSS 实现成本极低 |
| ✅ 覆盖模式 | qt-material 打底 + 自定义 CSS 覆盖的机制可照搬（`uv add qt-material` 即可，无前端工具链） |
| ⚠️ 字体 | Lato 对中文无覆盖，我们需换为系统中文字体栈（如 Noto Sans CJK） |
| ❌ 不宜照搬 | 其全局 `!important` 强制字体过于粗暴，建议改为应用级 `QFont` 设置 |

**结论**：主页面"深色扁平 + 细线直角 + 蓝色强调"的风格完全适合 IDE，配色值与覆盖机制可直接参考，作为 [work plans/2026-0718-1100_界面走查问题与优化计划.md](work%20plans/2026-0718-1100_界面走查问题与优化计划.md) 第 2.3 节"全局 QSS 样式表"的输入。
