# 移除噪音过滤与全量文件可见改造计划

## 1. 问题现象与设计决策

### 1.1 现象

文件树无法显示 `.gitignore`、`.git/`、`.venv/` 等以 `.` 为前缀的
文件与目录；即使取消勾选「过滤噪音目录」也依然不可见。

### 1.2 决策（用户拍板）

**「过滤噪音目录」功能整体移除。** IDE 的基本职责是让用户看到
所有的东西：

- 所有隐藏文件/目录（dotfile）恒可见；
- `.git/`、`.venv/`、`__pycache__/`、`node_modules/` 恒可见，
  不再提供任何隐藏开关。

不存在"保留选项但修 bug"的中间态——选项本身即缺陷设计。

## 2. 诊断结论（已实证，作为移除的技术依据）

诊断脚本：`.temp/diagnose_dotfile_visibility.py`（项目 `.venv` 的
PySide6，offscreen 运行），输出已确认：

### 2.1 根因：QFileSystemModel 默认 filter 不含 Hidden

```
默认 filter: Filter.Dirs|Files|Drives|AllDirs|NoDot|NoDotDot
  包含 Hidden: False
```

所有 `.` 前缀条目从未进入模型数据源，上层任何开关都无法让它们
出现。必须在 `_build_model()` 显式 `setFilter(... | QDir.Filter.Hidden)`。

### 2.2 现有噪音过滤是"双重冗余"

`NOISE_NAMES` 中的 `.git` / `.venv` 因 §2.1 从未显示过，代理过滤
对它们形同虚设；`__pycache__` / `node_modules` 才是该功能实际
过滤的全部。一个只对两个目录生效、且与 IDE 职责相悖的开关，
没有保留价值。

### 2.3 修复路径已验证

同一脚本在 `setFilter(AllEntries | NoDotAndDotDot | Hidden)` 后，
`.gitignore`、`.git`、`.venv`、`.temp` 全部出现在可见条目中。

## 4. 改造方案

### 4.1 文件树模型层（model.py）：代理模型剥离过滤职责，改名归位

代理模型现存两个职责：噪音过滤（本次删除）与 Git 状态着色
（`data()` ForegroundRole，须保留）。改造：

- 类改名 `NoiseFilterProxyModel` → `GitStatusProxyModel`，
  职责单一化；
- 基类 `QSortFilterProxyModel` → `QIdentityProxyModel`：过滤职责
  删除后不再需要排序/过滤基建，恒等代理（mapFromSource/
  mapToSource 直通）语义更贴切、行为更稳，索引映射调用点
  （explorer.py 136/180）无需改动；
- 删除 `noise_names`、`is_filter_enabled`、`filterAcceptsRow()`；
- 更新模块与类 docstring（移除"噪音过滤"叙述）。

### 4.2 文件树主控件（explorer.py）：补 Hidden + 删除过滤接口

```python
from PySide6.QtCore import QDir
...
def _build_model(self) -> None:
    self.model = QFileSystemModel(self)
    self.model.setRootPath(self.root_dir)
    self.model.setReadOnly(False)
    # Qt 默认 filter（Dirs|Files|Drives|AllDirs|NoDot|NoDotDot）不含
    # Hidden，dotfile 永不入模型；IDE 须全量可见（诊断见 §2）。
    self.model.setFilter(
        QDir.Filter.AllEntries
        | QDir.Filter.AllDirs
        | QDir.Filter.NoDotAndDotDot
        | QDir.Filter.Hidden
    )

    self.proxy = GitStatusProxyModel(self)
    self.proxy.setSourceModel(self.model)
```

同步删除：`NOISE_NAMES` 类属性、`set_noise_filter()` 方法、
import 更新。

## 7. 风险与回归点

- **Git 状态着色**：dotfile 入模型后，`.gitignore` 若被 git 管理
  会参与着色（预期行为）；`.git/` 目录不入 status 映射，不着色。
  目录聚合着色（status_of_dir）对新增可见目录自动生效，无需改动。
- **索引映射**：`QIdentityProxyModel` 的 mapFrom/ToSource 为直通
  实现，explorer.py 全部调用点（root 索引、双击、拖出、右键）
  行为不变；这是换基类而非删代理的原因（着色 data() 必须保留）。
- **`.git/` 展开的目录规模**：`.git/` 子树可能较大，懒加载机制
  仅枚举已展开节点，默认折叠态无开销；用户展开属主动行为。
- **菜单分隔符**：动作删除后检查相邻分隔符不产生空段/双分隔符。
- **历史文档**：`文档/` 与 `work plans/` 历史记录中对噪音过滤的
  叙述属历史档案，不回溯修改。
