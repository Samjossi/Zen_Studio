> **状态**：草稿（待审阅）
> **范围**：`assets/themes/base.qss` 模板、`src/ide/gui/theme.py` 令牌与渲染、`src/ide/gui/settings.py` 持久化、`src/ide/gui/settings_dialog.py` 外观页、`src/ide/gui/main_window.py` 热应用；不动阴影体系与六套共享资源包
> **时间**：2026-11-14 16:00（设计，UTC+8）；2026-11-15（移植适配本项目）

## 1. 背景与需求

用户希望给主窗口加一圈 **1px 主题色描边**，并在设置中心提供开/关。边的颜色取「主题色中比较重的颜色」——即以各主题 accent 为准。四款主题都要新增这一项（主窗边框色），且可开关。

价值：无边框窗口（FramelessWindowHint）在 X11 下无投影环、浅色窗口底与白色壁纸相邻时分界不清；1px 主题色边给主窗口一个明确的「轮廓」，同时是主题个性的延伸。

## 2. 现状机制（落点已探明）

- **窗口结构**（`src/ide/gui/main_window.py` `_build_layout`，:316-347）：MainWindow 无边框（:158）；可视壳 `#WindowShell`（:326，`WA_StyledBackground`）自上而下装 [TitleBar][QMenuBar][内容][QStatusBar]，外套 `ShadowHost`（`src/ide/gui/window_shadow.py`，:347）——Wayland 四边留 15px 透明环绘投影，X11 零边距直通。**在 `#WindowShell` 上加 QSS 边框，两个平台都恰好画在可视窗口边缘**，且壳已开 `WA_StyledBackground`，QSS 边框可生效。
- **模板**：base.qss 已有 `#WindowShell { background-color: $window_bg; }` 规则（:35-37，带 Wayland 投影环注释），扩一条 border 声明即可，令牌渲染机制不变。
- **主题切换是重启生效**（2026-0820-1642 计划移除热链，`main_window.switch_theme` :537-551 只持久化+弹窗）；但**字号是热生效范本**——`MainWindow.set_font_size`/`_apply_font_size`（:833-863）持久化后 `apply_theme(app)` 重渲染全局样式。边框开关只影响 app 级 QSS、不碰任何冻结色，热应用安全。
- **设置体系**（`src/ide/gui/settings.py`）：`KEY_*` 常量（:53-77）+ `AppSettings`（:106）/`AppSettingsPatch`（:148）TypedDict + `DEFAULT_SETTINGS`（:170）三处同步登记；缺失字段回退默认，旧 settings.json 无迁移负担。
- **外观页**（`settings_dialog.py` `_build_appearance_page`，:462-489）：QFormLayout 行式装配（主题/字号/对话区渲染），ctx 处理器（`_on_theme_activated`/`_on_font_changed` 范式）+ `reload()` 的 `_reloading` 守卫回显（`_reload_appearance`，:686）。ctx 鸭子类型清单在类 docstring（:166-167），新增方法需同步该注释。
- **守卫**：不存在模板占位符双向校验脚本；`tests/test_theme.py` 断言「`QSS_TOKEN_KEYS + PACK_KEYS` ⊆ 调色板键」（:74）且「渲染产物无残留 `$token`」（:76），新增令牌必须四主题全填否则天然拦截。`scripts/check.sh` = 隐私扫描 + 可选中 QLabel 守卫 + ruff + pytest（offscreen）。

首个可见成果：主窗口四周出现 1px 主题色描边（暖米 = 橙边、薄荷 = 绿边），设置中心外观页新增开关，取消勾选后边立即消失、勾选立即恢复，重启后状态保持；四款主题各用自己的 accent 作边色。

1. 四主题调色板新增 `window_border` 令牌（= 各主题 accent，见 D3）。
2. base.qss `#WindowShell` 规则加 `border: 1px solid $window_border;`。
3. 新持久化键 `window_border`（bool）+ 外观页复选框 + MainWindow 热应用方法。
4. 全量门禁通过 + offscreen 截图走查（开/关 × 至少两款主题）。

## 4. 非目标与硬边界

- 🔴 不改阴影体系（ShadowHost/SHADOW_MARGIN/剖面参数一律不动），不加圆角——窗体是矩形，圆角会与直边子控件打架。
- 🔴 不动六套共享资源包与所有文字/前景色（延续「不改字体色」禁令）。
- 🔴 不重开主题热切换（聊天卡片冻结色问题仍在，仅边框开关本身热应用）。
- 🔴 不动对话框、提交历史图窗口等其他窗口；不加平台特例代码（QSS 方案两平台天然一致）。
- 现有四主题其余令牌一个不改。

## 5. 设计

### 5.1 令牌与模板

- `QSS_TOKEN_KEYS` 追加 `"window_border"`；四个调色板各加一键，值 = 该主题 accent：

| 主题 | window_border | 主题 | window_border |
|:---|:---|:---|:---|
| cloud 云白 | `#0765d4` | sky 晴空 | `#0284c7` |
| wheat 暖米 | `#c26a1a` | mint 薄荷 | `#15803d` |

- base.qss `#WindowShell` 规则扩为：
  ```css
  #WindowShell {
      background-color: $window_bg;
      border: 1px solid $window_border;  /* 1px 主题色轮廓边：无边框窗分界 + 主题个性 */
  }
  ```

### 5.2 开关实现（关闭态）

`render_theme(theme)` 保持纯函数（永远渲染带边模板）。`apply_theme` 读取 `window_border` 设置：**关闭时**在渲染产物末尾追加一条同选择器覆盖规则 `#WindowShell { border: none; }`（QSS 后写胜出，无平台差异；1px 几何差不可感知）。覆盖片段由 theme.py 一个小函数产出，单测直断。

### 5.3 持久化

- `KEY_WINDOW_BORDER = "window_border"`；`AppSettings`/`AppSettingsPatch` 增 `window_border: bool`；`DEFAULT_SETTINGS` 登记（默认值见 D1）。

### 5.4 UI 与热应用

- 外观页「对话区渲染」行下加一行：`layout.addRow("主窗色边", self._border_check)`，复选框文案「主窗口 1px 主题色描边」；勾选变化 → `self._ctx.set_window_border(checked)`（`_reloading` 守卫内不触发）。
- `MainWindow.set_window_border(enabled)`：持久化 → `apply_theme(QApplication.instance())` 重渲染 → 状态栏短提示 → `_sync_settings_dialog()`。完全镜像 `set_font_size` 路径（:833-863）。
- `reload()`/`_reload_appearance` 回显勾选状态。
- `settings_dialog.py` 类 docstring 的 ctx 鸭子类型清单（:166-167）补 `set_window_border`。

### 5.5 测试

- `tests/test_theme.py`：四调色板含 `window_border` 且**值等于 accent**（防两值漂移）；渲染产物无残留 `$window_border`。
- 新增：关闭态覆盖片段存在性/内容单测（纯函数，不依赖 QApplication）。
- 新增：外观页复选框存在、初始态跟随设置、`toggled` 调用 ctx 方法（fake ctx 补 `set_window_border` 桩，可参考 `tests/test_settings_hint_icons.py` 的对话框构造方式）。
- `tests/test_settings_hint_icons.py` 等现有外观页测试不受影响（对话框构造不触碰新 ctx 属性，仅切换时才调）。

- 四主题主窗口均带 1px 主题色边，边色 = 该主题 accent；暖米橙边、薄荷绿边一眼可辨。

## 8. 决策点（请审阅时拍板）

- **D1 默认开还是关**：🟡 建议**默认开**——功能即「给主窗口加边」，老用户升级后无感知等于没做。姊妹项目按此执行无副作用记录。若担心打扰可默认关。
- **D2 生效时机**：🟡 建议**即时热生效**（沿字号路径 `apply_theme` 重渲染），与主题切换的「重启生效」口径不同但体验更好；也可为一致性改为重启生效。
- **D3 边色来源**：🟡 建议**四主题一律取 accent**。备选：非灰系主题取 accent、未来新增灰主题取深灰文字色更低调。
- **D4 关闭态实现**：🟡 建议**追加 `#WindowShell { border: none; }` 覆盖**（语义干净）。备选：令牌替换 `transparent`——几何恒 1px inset，但语义含糊。
- **D5 最大化时**：🟡 建议**保留边框**（实现零成本）。备选：最大化随投影环一并收起需改 changeEvent 链路，非目标。

## 9. 风险与对策

| 风险 | 等级 | 对策 |
|:---|:---:|:---|
| QSS border 使 #WindowShell 内容内缩 1px，与投影环/边距体系叠加产生接缝 | 🟡 | §6 截图走查专查四边贴边与角部；有问题再改自绘方案（paintEvent 画线），QSS 先行因零代码 |
| 热重渲染触碰聊天卡片冻结色导致视觉不一致 | 🟢 | 边框不含颜色语义变化，卡片不受影响（字号热路径同机制，线上稳定） |
| 旧 settings.json 无新键 | 🟢 | load_settings 缺键回退默认值，天然兼容 |
| X11 无投影环，色边成唯一轮廓线，存在感强于 Wayland | 🟢 | 预期行为；1px 低存在感激进，可接受 |
