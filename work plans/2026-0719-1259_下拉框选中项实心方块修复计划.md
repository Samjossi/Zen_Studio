# 下拉框选中项实心方块（文字被遮）修复计划

## 1. 事件背景

2026-07-19 用户报告：在聊天面板选择模型时，点击下拉框（[`gui/panels/chat/model_bar.py`](gui/panels/chat/model_bar.py) 的模型/版本两个 `QComboBox`），弹出列表中的**焦点项变成一个实心方块，直接挡住了该项的文字**。本计划记录完整诊断报告（现象复现 → 实验归因 → 根因确认）与修复方案。

## 2. 现象复现

使用临时走查脚本（`.tmp/repro_combo*.py`，项目 `.venv` + PySide6 6.11.1 + X11）程序化弹出下拉并放大 4 倍截图，现象稳定复现：

| 截图（`./.tmp/`） | 场景 | 现象 |
|:---|:---|:---|
| `zoom_2_popup_current0.png` | 弹出瞬间（当前项 "Kimi CLI"） | 🔴 第一项文字消失，呈白底灰边矩形块 |
| `zoom_3_popup_hover1.png` | hover 移至 "Kimi ACP" | 🔴 第一项文字恢复，第二项变白块 |

规律：**凡是处于选中/hover 高亮态的项，文字即不可见**；移走后恢复正常。非选中项显示完全正常。

## 3. 诊断过程（实验链）

共 9 组对照实验，逐步隔离变量（全部截图留存于 `./.tmp/`）：

### 3.1 分水岭：裸样式 vs 样式表

| 实验 | 配置 | 结果 |
|:---|:---|:---:|
| bare_1 | 不加载任何样式表，裸 Fusion 弹出 | 🟢 正常高亮（深青底白字） |
| bare_2 | 裸 QListWidget 对照 | 🟢 正常 |

→ 定性为**样式表（QSS）引发**，与字体库统一计划无关（字体渲染本身正常）。

### 3.2 单变量隔离：独立列表 vs Combo 弹出

| 实验 | 配置 | 结果 |
|:---|:---|:---:|
| G | 独立 QListWidget + `::item:selected` 蓝底白字 | 🟢 规则生效 |
| H | 独立 QListWidget + view 级 `selection-*` | 🟢 规则生效 |
| I | QComboBox + 仅 `QListView::item:selected` | 🟢 正常（但该规则的背景色未生效，回退 palette 默认） |

→ 问题具有 **QComboBox popup 特殊性**：独立列表一切正常。

### 3.3 元凶定位：`QComboBox` 普通态 `background-color`

| 实验 | 配置 | 结果 |
|:---|:---|:---:|
| O | 主题全部 popup 相关规则（view/item 系列），**无** combo 本体背景 | 🟢 蓝底白字 |
| P | O + `QComboBox { background-color }` 等本体规则 | 🔴 白块复现 |
| R | 仅 `QComboBox { background-color }` + 最小 `selection-*` | 🔴 白块复现 |
| W | 移除 combo 本体 `background-color`，保留 border/圆角/padding | 🟢 完全正常 |

→ **必要且充分条件：`QComboBox` 普通态的 `background-color`**。

### 3.4 补救写法海选（均失败）

| 实验 | 尝试 | 结果 |
|:---|:---|:---:|
| S | view 加 `show-decoration-selected: 1` | ❌ 白块 |
| T | 追加 `QAbstractItemView::item:selected` | ❌ 白块 |
| U | 追加 `QComboBox QAbstractItemView::item:selected` | ❌ 白块 |
| C | 同 U（全局样式表环境） | ❌ 白块 |

→ 在 combo 本体背景被接管的前提下，**QSS 内无任何手段恢复选中背景**，只能移除本体背景色。

### 3.5 hover 态排查（方案完整性验证）

dark 主题的 `QComboBox:hover { background-color: #454548 }` 是否同样触发？

| 实验 | 配置 | 结果 |
|:---|:---|:---:|
| X | 无普通态背景 + hover 背景色，鼠标真实悬停弹出 | 🟢 正常 |
| Y | 无普通态背景 + hover 仅描边（亮色结构） | 🟢 正常 |

→ **仅普通态 `background-color` 触发**；`:hover` 伪态背景不触发，dark 主题 hover 提亮可保留。

## 4. 根因归因

问题写法（五套主题同构，以 [`config/themes/cloud.qss`](config/themes/cloud.qss) 为例）：

```css
# config/themes/cloud.qss（当前）
QComboBox {
    background-color: #ffffff;   /* ← 根因 */
    border: 1px solid #d2d2d7;
    border-radius: 6px;
    padding: 2px 7px;
}
QComboBox QAbstractItemView {
    background-color: #ffffff;
    color: #1d1d1f;
    border: 1px solid rgba(0, 0, 0, 0.15);
    selection-background-color: #0765d4;  /* 实际被忽略 */
    selection-color: #ffffff;             /* 仍然生效 → 白字 */
    padding: 4px;
    outline: none;
}
```

机制链条：

1. QSS 的 background 语义沿控件树传播（cloud.qss 头部注释亦自述此特性）。`QComboBox` 设置普通态 `background-color` 后，其弹出列表（内部 QListView）的背景绘制被 QStyleSheetStyle **接管**。
2. 背景被接管后，Qt 绘制选中项时**不再使用调色板 Highlight 颜色**——`selection-background-color` 被忽略，选中项背景保持 view 的白色。
3. 但选中项**文字颜色仍走调色板**——`selection-color: #ffffff` 生效，文字被画成白色。
4. **白底 + 白字 → 文字不可见**，只剩灰边矩形，即用户所见"实心方块挡住字体"（灰边为接管路径下绘制的当前项边框）。
5. 亮色主题白底白字直接隐形；暗色主题 view 底色为深灰 `#2c2c2e`，白字仍可读，故症状为**选中高亮失效**而非文字消失（同属本 bug，一并修复）。

## 6. 修复方案（选定：方案 A —— 移除 combo 本体背景色）

五套主题统一修改：删除 `QComboBox` 规则中的 `background-color` 行，**保留** border / border-radius / padding 与全部 `QComboBox QAbstractItemView` 规则；dark 主题 `QComboBox:hover` 的 `background-color: #454548` **保留**（§3.5 已验证不触发）。

修改清单（每个文件删除一行）：

| 文件 | 删除内容 |
|:---|:---|
| `config/themes/cloud.qss` | `QComboBox { background-color: #ffffff; ... }` 中的 `background-color: #ffffff;` |
| `config/themes/wheat.qss` | 同上（`#ffffff`） |
| `config/themes/sky.qss` | 同上（`#ffffff`） |
| `config/themes/mint.qss` | 同上（`#ffffff`） |
| `config/themes/dark.qss` | 同上（`#3a3a3c`；hover 的 `#454548` 保留） |

以 cloud.qss 为例，修改后：

```css
# config/themes/cloud.qss（修改后）
QComboBox {
    border: 1px solid #d2d2d7;
    border-radius: 6px;
    padding: 2px 7px;
}
```

同时修订各文件 `/* ---- 下拉框：白底描边 ... ---- */` 段注释，去掉"白底"表述，改为"透明底（随侧栏）+ 描边"，避免后续误回加。

### 6.1 视觉影响评估（⚠️ 需用户确认）

移除背景色后 combo 透明，透出所在侧栏底色：

| 主题 | 原 combo 底 | 修改后（透出 SidePanel） | 色差 |
|:---|:---|:---|:---|
| cloud | `#ffffff` | `#fafafb` | 极小（近白灰） |
| wheat | `#ffffff` | `#fefdfb` | 极小 |
| sky | `#ffffff` | `#fbfdfe` | 极小 |
| mint | `#ffffff` | `#fbfefb` | 极小 |
| dark | `#3a3a3c` | `#252527` | 小（hover 仍有 `#454548` 提亮反馈） |

亮色四主题侧栏底色均为近白微染色，视觉变化轻微；dark 主题下拉框融入侧栏、hover 提亮，层级感保留。整体判定可接受，与"侧栏融入"的苹果风基底一致。
