# Git 变更面板实施计划

## 一、目标与范围

新增一个**独立面板**（不嵌入 FileExplorer），以 VS Code 源代码管理面板为雏形的简化版：

- 列出全部已变更文件（M 修改 / U 未跟踪 / D 删除），文件名按状态着色（复用 `GIT_STATUS_COLORS`：天蓝/绿/红），**已删除文件红色 + 删除线**
- 每个文件右侧显示增减行数：**绿色 `+N`**、**红色 `-N`**（数据来自 numstat，只有增/减其一则不补零）
- 双击文件 → 中栏查看器打开；已删除文件不可打开，双击时状态栏提示
- **面板可隐藏/展开**：① 视图菜单勾选项；② 面板头部栏「−」按钮（两入口汇入单一显隐函数，完全对齐终端面板既有模式）
- 空态：无变更或非 git 仓库时显示空提示行（面板本体不自动隐藏，显隐完全由用户控制）

**不做**：提交/暂存等写操作、右键"还原"、行粒度 diff、面板显隐状态持久化（同终端面板，启动始终显示）。

## 二、现状摸底（计划前提）

| 依赖 | 现状 | 复用方式 |
|---|---|---|
| 变更文件清单 | [`core/git/service.py`](core/git/service.py) `_status` 映射（含 ignored，需过滤） | 新增聚合查询方法 |
| 增减行数 | `_numstat` 映射（`git diff --numstat HEAD`） | 同上 join |
| 未跟踪文件行数 | numstat 不含（未进 index） | 数据层补：文本文件数行数，1MB 守卫 |
| 状态色/增减色 | [`gui/theme.py`](gui/theme.py) `GIT_STATUS_COLORS`（明暗两族） | 直接查表；`+` 用 untracked 绿、`-` 用 deleted 红 |
| 刷新机制 | 主窗口 `_refresh_git_status()` 三事件源 + 300ms 去抖 | 面板挂入该函数 |
| 显隐模式 | 终端面板：视图菜单勾选 + 头部「−」→ `_set_terminal_visible()` 单一入口；`MIN_HEIGHT` + `setCollapsible` 防折叠 | 照搬同构实现 |
| 面板样式 | `PanelCard` 圆角卡片 + `SidePanel` 灰底 + `PanelTitle` 标题（qss 统一） | 照搬 |

**布局决策**：右栏由"单个 FileExplorer"改为垂直 QSplitter（上：文件树，下：变更面板），主窗口 `_splitter_main` 第三格装入该垂直拆分器；变更面板设 `MIN_HEIGHT` 并 `setCollapsible(1, False)`（与终端面板同手法）。
