## 1. 需求背景

为 IDE 增加"变更后对比"功能：同一窗口展示文件改动，**红色 = 删除，绿色 = 新增**。选型已拍板：

- 展示模式：**Unified Diff**（行级，单窗口，`-` 红 / `+` 绿）
- 实现方案：**difflib（标准库）+ Qt 原生渲染**，零新增依赖
- 对比基准：**上游分支（`@{upstream}`，即"已推送状态"）**——未提交的改动与已提交未推送的改动都要能看到差异；仓库未配置上游时回退到 HEAD

明确不做：词/字符级行内高亮（Inline）、并排对比（Side-by-Side）、三方合并。

## 2. 现状盘点

### 2.1 可直接复用的既有能力

| 既有能力 | 位置 | 复用方式 |
|:---|:---|:---|
| git 命令执行层 `run_git(repo_dir, *args)`（2s 超时、失败静默 None） | `src/core/git/runner.py` | 新增 `git show @{upstream}:<rel>` 调用取基准内容（无上游回退 `HEAD:<rel>`） |
| 变更面板 `ChangesPanel.apply_changes` + 双击打开文件 | `src/gui/panels/changes/panel.py`、`src/gui/controllers.py` | 双击接线点：已修改文件改开 diff 视图 |
| 对话框范式 `GitGraphDialog`（非模态单例、QStackedWidget 降级页、`apply_theme`/`refresh_font` 主题链） | `src/gui/git_graph_dialog.py` | 新对话框直接仿写 |
| diff 红绿色键 `diff_add_fg`/`diff_del_fg`（亮暗双套） | `src/gui/theme.py` `chat` 包 | 直接复用；如需行背景色则新增键（亮暗同步） |
| hunk 三色渲染先例（`DiffCard` 的 `BodyHtml` QTextBrowser） | `src/gui/panels/chat/cards.py` | 渲染思路对齐 |

### 2.2 缺口

- `src/core/git/` 目前只有状态/统计缓存，**没有任何取文件内容（含 HEAD 内容）的函数**
- `ChangesPanel` 双击只会 `open_file`，无 diff 预览入口
- 无 difflib 差异行生成的独立模块

## 3. 方案

**D1：core 层新增纯函数差异模块 `src/core/diff_view.py`（不依赖 Qt、不依赖 git）。**
`unified_rows(old_text: str, new_text: str, context: int = 3) -> list[DiffRow]`，`DiffRow = (kind, text)`，`kind ∈ {"del", "add", "ctx", "hunk"}`；内部用 `difflib.unified_diff`，跳过 `---`/`+++` 文件头。纯函数可脱离 Qt 直接单测。另加 `MAX_DIFF_LINES` 常量（暂定 20000）：任一文本超行数则返回空并交由 UI 提示"文件过大"，不做分块。

**D2：git 数据层补内容读取。**
`src/core/git/` 新增 `content.py`：`fetch_base_content(repo_root, rel_path) -> str | None`——优先走 `run_git(repo_root, "show", f"@{{upstream}}:{rel_path}")` 取上游分支版本（已推送状态）；返回 None 时回退 `HEAD:{rel_path}`（未配置上游的仓库）。工作区内容用 `Path.read_text`（读取失败静默 None）。二进制/解码失败一律返回 None，UI 降级提示。

**D3：UI 层新增 `src/gui/diff_view_dialog.py`，仿 `GitGraphDialog` 范式。**
- `QDialog` 非模态，构造注入 `GitStatusService`（只读 `is_enabled`/`repo_root`）；`showEvent` 时按当前文件重拉内容
- 主视图：只读 `QTextBrowser`，等宽字体 `QFont(get_mono_family())`，按 `DiffRow.kind` 逐行 HTML 着色——del 红 / add 绿（前景色复用 `chat` 包 `diff_add_fg`/`diff_del_fg`，行背景色在 `chat` 包新增 `diff_add_bg`/`diff_del_bg` 键，亮暗双套同步并登记 TypedDict）；hunk 头（`@@`）灰、上下文行默认色
- `QStackedWidget` 降级页：非 git 仓库 / 文件未跟踪（基准侧无内容）/ 文件过大 / 读取失败，各给一行占位文案
- 保留 `apply_theme(theme)` 公共接口并挂 `MainWindow._apply_font_size` 字体链
- 未跟踪文件（`U`）在基准侧不存在，双击仍走原 `open_file` 逻辑，不开 diff 视图

**D4：触发接线。**
`src/gui/controllers.py` `GitStatusController`：变更面板双击分发——状态为已修改（M）→ 打开 `DiffViewDialog`；其余状态维持 `file_opened → viewer.open_file` 不变。文件树右键菜单入口本期不加，保持最小范围。

**改动清单**：

1. `src/core/diff_view.py`：新增 `DiffRow`/`unified_rows`/`MAX_DIFF_LINES`。
2. `src/core/git/content.py`：新增 `fetch_base_content`（上游优先、HEAD 兜底）。
3. `src/gui/diff_view_dialog.py`：新增 `DiffViewDialog`。
4. `src/gui/theme.py`：`chat` 包亮暗双套新增 `diff_add_bg`/`diff_del_bg`（若实测仅前景色可读性已够，则不加，实施时定）。
5. `src/gui/controllers.py`：双击分发接线。

7. **不动**：`GitStatusService` 缓存与刷新链路、`ChangesPanel` 其余行为、ACP/DiffCard 相关代码。

## 5. 影响面评估

- ✅ 零新增依赖：difflib 为标准库，`.venv` 与打包脚本零改动
- ✅ git 数据层只增不改：`runner.py`/`service.py` 现有函数签名不变
- ✅ 变更面板行为可控回退：仅双击分发多一个分支，U/D 等状态路径逐字节不变
- ⚠️ 大文件：difflib 纯 Python，万行以上偏慢——由 `MAX_DIFF_LINES` 上限 + 降级文案兜底，不做分块优化
- ⚠️ 无上游仓库：回退 HEAD 对比，已提交未推送的改动在此类仓库不可见（本地仓库本身无"推送"概念，语义可接受）
- ⚠️ 外部并发改动：diff 视图打开期间文件被改动不会自动刷新，需用户重开（与 `GitGraphDialog` 的 showEvent 重拉策略一致，可接受）
