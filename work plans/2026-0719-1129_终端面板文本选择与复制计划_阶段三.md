# 终端面板文本选择与复制计划（阶段三）

## 1. 背景

终端当前无法复制任何文本。根因（已查证，未改代码）：

| 环节 | 现状 |
|:---|:---|
| 鼠标选区 | [`TerminalWidget`](gui/panels/terminal/widget.py) 未实现 `mousePressEvent` / `mouseMoveEvent` / `mouseReleaseEvent`，拖动不创建选区，绘制层无选区高亮 |
| 复制快捷键 | `key_to_bytes()` 将 Ctrl+C 转为 `\x03`（SIGINT）发 shell——符合真实终端语义，但 Linux 惯例的 Ctrl+Shift+C 未实现 |
| 右键菜单 | [`_on_context_menu`](gui/panels/terminal/panel.py) 仅清屏 / 重开 / 终止 / 关闭此终端，无复制项 |
| 剪贴板 | 终端模块无任何 `QClipboard` 调用 |

终端为完全自绘 QWidget（非 QTextEdit 等原生控件），选择/复制链路须整体自建。

## 2. 目标

对齐主流桌面终端（Konsole / GNOME Terminal / WezTerm）的核心体验：

1. 鼠标左键拖选文本，选区实时高亮
2. Ctrl+Shift+C 复制选区；右键菜单提供"复制"
3. Ctrl+Shift+V 粘贴剪贴板文本进 shell；右键菜单提供"粘贴"
4. 双击选词、三击选行（增强项，见 §6）

非目标（本期不做）：OSC 52 剪贴板序列、bracketed paste 模式、X11 PRIMARY 选中即复制、矩形块选。

## 3. 设计决策

### 3.1 选区坐标系

- 选区锚点/端点以**可视快照行坐标**存储：`(y, x)`，`y ∈ [0, rows)` 对应当前 `snapshot(self._scroll_offset)` 的行序，`x ∈ [0, cols)` 为列序
- 提取文本时直接索引快照，与 [`_update_search`](gui/panels/terminal/panel.py) 的查找提取模式一致，无需缓冲区绝对行映射
- ⚠️ 已知取舍：选区**不锚定**缓冲区绝对行。屏幕内容滚动（滚轮回滚、新输出推屏、输入回底、切换 tab）会使选区指向的内容漂移，故采用**滚动即清除选区**策略（Konsole 之外的简化做法，代价是复制前不能翻看历史，可接受）

### 3.2 选区生命周期

| 时机 | 动作 |
|:---|:---|
| 左键按下 | 记录锚点，清除旧选区 |
| 拖拽移动 | 更新活动端点，走既有 30ms 节流重绘（复用 `_refresh_timer` 或直接 `update()`） |
| 左键释放 | 锚点 == 端点（退化为点击）→ 清除选区；否则定稿 |
| 滚轮滚动 / 键盘输入 / 新数据推屏 / 切换 tab / 清屏 | 清除选区 |
| 复制成功后 | 保留选区（主流终端行为，便于二次确认） |

### 3.3 层间职责（维持单向依赖）

- **widget**（碰 Qt 的唯一层）：选区状态、鼠标事件、选区绘制、像素→网格换算、`selected_text() -> str` 提取、Ctrl+Shift+C/V 拦截并直接执行（写剪贴板无副作用；粘贴经 `self._session.write()` 与键盘输入同路径）
- **panel**（决策层）：右键菜单增"复制 / 粘贴"项（复制调 `terminal.selected_text()` 写剪贴板；粘贴调 widget 粘贴方法），`_switch_tab` 清选区（与 `_clear_search` 同位置）

### 3.4 文本提取规则

- 选区归一化：起止按阅读序（上到下、同行左到右）排序
- 跨行拼接：行间插 `\n`；**行尾 `rstrip()`**（网格行按列数补齐空白，直接拼接会带大量尾随空格）
- 单行选区为半开区间 `[x0, x1)`
- 宽字符（CJK）：pyte 缓冲中宽字符数据占一格、伴生一格空白，拼接天然正确；高亮按格染色即可，无需特殊处理（与现有绘制行为一致）

### 3.5 快捷键拦截位置

Ctrl+Shift+C / Ctrl+Shift+V 在 `keyPressEvent` 中拦截，位置与 Ctrl+F 相同——**先于** `key_to_bytes()` 的 VT100 转换。注意现有 Ctrl 字母规则只匹配 `ControlModifier`，Shift+Ctrl 组合天然不会误入 SIGINT 路径。

### 3.6 像素→网格换算

```python
# gui/panels/terminal/widget.py
col = clamp(event.pos().x() // self._cell_w, 0, cols - 1)
row = clamp(event.pos().y() // self._cell_h, 0, rows - 1)
```

`cols` 须与 [`grid_size()`](gui/panels/terminal/widget.py) 口径一致（已扣滚动条宽度），防止拖入滚动条区域取到越界列。

## 5. 验收检查点

- [ ] 拖选单行片段 → 高亮正确 → Ctrl+Shift+C → 可粘贴到编辑器，内容一致且无尾随空格
- [ ] 拖选跨多行 → 复制后换行位置正确
- [ ] 拖选含中文/宽字符行 → 复制内容无错位、无丢字
- [ ] 单击（不拖动）→ 无选区残留
- [ ] 复制后按 Ctrl+C → shell 仍收到 SIGINT（中断语义不被破坏）
- [ ] Ctrl+Shift+V → 剪贴板文本进入 shell 可执行
- [ ] 右键菜单"复制"在有选区时启用、无选区时禁用；"粘贴"在进程退出后禁用
- [ ] 拖选后滚动滚轮 / 输入字符 / 切换 tab → 选区清除
- [ ] 拖入右侧滚动条区域 → 不越界、不崩溃
- [ ] 查找浮层高亮与选区高亮同屏共存时层次正确（选区不盖住光标）

## 6. 后续增强（另立计划，本期不实施）

- 双击选词（按空白/标点切分）、三击选行
- 拖拽至视口上下边缘时自动滚动回滚区（需选区锚定策略升级为缓冲区绝对行）

## 7. 风险与备注

| 项 | 说明 |
|:---|:---|
| ⚠️ 粘贴安全 | 多行文本粘贴进 shell 会逐行执行，属真实终端通用风险；bracketed paste 留待后续增强 |
| ⚠️ 选区漂移 | 已用"滚动即清除"规避（§3.1）；若用户反馈需要"翻看历史后复制"，再升级为绝对行锚定 |
| 刷新节流 | 拖拽重绘频率受鼠标事件驱动，必要时复用 `_refresh_timer` 聚合，避免高 dpi 下过度重绘 |
