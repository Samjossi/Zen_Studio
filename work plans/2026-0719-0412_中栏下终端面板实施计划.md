## 1. 目标

## 2. 模块设计（OOP 分层）

### 2.1 包布局与依赖方向

```
gui/panels/terminal/
├── __init__.py     # 导出 TerminalPanel
├── palette.py      # AnsiPalette     —— 纯数据：ANSI 16 色 × 明暗双主题
├── screen.py       # TerminalScreen  —— 语义层：字节流 → 屏幕状态（pyte 封装，不碰 Qt 绘制）
├── session.py      # PtySession      —— I/O 层：PTY 子进程生命周期（纯字节管道，不懂终端语义）
├── widget.py       # TerminalWidget  —— Qt 层：自绘网格 + 键盘输入 + 滚动条
└── panel.py        # TerminalPanel   —— 装配层：标题行 + 接线 + 生命周期
```

**依赖方向（单向，无环）**：

```
TerminalPanel ──► TerminalWidget ──► TerminalScreen ──► (pyte)
     │                 │
     │                 └──► AnsiPalette（颜色名 → QColor，仅渲染层消费）
     └──► PtySession ──► (ptyprocess)

session 与 screen 互不依赖：字节流由 panel 接线（信号驱动），层间单向可见。
```

分层要义：**session 是纯字节管道**（换个非终端消费者也能用）；**screen 是纯语义模型**（未来"终端内容喂 AI"直接读它）；**widget 是唯一碰 Qt 绘制/键盘的层**。

### 2.2 类职责

| 类 | 文件 | 职责 | 关键成员/接口 |
|:---|:---|:---|:---|
| `AnsiPalette` | `palette.py` | ANSI 颜色名 → `QColor` 映射表（默认前后景 + 16 色 + 粗体高亮变体），明暗双主题 | `PALETTES: dict[str, dict]`；`palette_for(theme) -> dict` |
| `CellStyle` | `screen.py` | 单元格样式值对象（dataclass，颜色用**名字**不用 QColor——语义层不依赖 QtGui） | `fg: str、bg: str、bold: bool、reverse: bool、underline: bool` |
| `TerminalScreen` | `screen.py` | pyte 封装：字节流喂入、屏幕状态查询、尺寸重设、回滚区 | `feed(data: bytes)`；`snapshot() -> list[list[tuple[str, CellStyle]]]`（可视区）；`scrollback_lines() -> int`；`resize(lines, columns)` |
| `PtySession(QObject)` | `session.py` | PTY 子进程 I/O：spawn（cwd=项目根、`TERM=xterm-256color`）、读线程、写、resize、终止 | 信号 `data_received = Signal(bytes)`、`process_exited = Signal(int)`；方法 `start()`、`write(bytes)`、`resize(rows, cols)`、`terminate()`（幂等）、`is_alive` |
| `TerminalWidget(QWidget)` | `widget.py` | 自绘 + 输入：`paintEvent` 画字符网格与光标；`keyPressEvent` → VT100 序列；`resizeEvent` → 行列数换算；`QScrollBar` 映回滚区；滚轮 | `set_screen(screen)`；`set_session(session)`；`apply_palette(palette)`；`key_to_bytes(event) -> bytes`（静态映射表） |
| `TerminalPanel(QWidget)` | `panel.py` | 装配：标题行（shell 名 + 状态 + 重开按钮）+ widget + session 生命周期 | `apply_theme(theme)`；`_start_session()`；`_on_exited(rc)` |

### 2.3 线程模型（pyte 非线程安全，这是硬约束）

```
[reader 线程]  ptyprocess.read() 阻塞读字节
      │  data_received.emit(bytes)        ← Qt 信号跨线程自动排队
      ▼
[GUI 线程]    panel._on_data → screen.feed(bytes) → widget.update()
              （pyte/所有 Qt 对象只在 GUI 线程触碰，零锁）
```

- 读循环带短超时（`read(timeout=0.5)`）以便检测子进程退出 → `process_exited.emit(rc)` 后线程自然结束（daemon 线程兜底）
- 防刷屏节流：`update()` 经 30ms `QTimer` 聚合（大量输出时帧率封顶 ~33fps，后续可换 dirty-region 优化，备案）

### 2.4 关键实现细节

| 点 | 设计 |
|:---|:---|
| 屏幕快照 | pyte `Screen.buffer`（`{(y,x): Char}`）逐行转 `[(char, CellStyle)]`；`Char.{fg,bg,bold,reverse,underscore}` → `CellStyle`；widget 遍历快照绘制（先 `fillRect` 背景块，再 `drawText` 字符，光标位反显） |
| 格度量 | `fontMetrics().horizontalAdvance("M")` 为格宽、`height()` 为行高；`cols = width//格宽`、`rows = height//行高`（下限 1） |
| 按键映射 | 静态表：可打印字符 → `event.text().encode()`；`Return→\r`、`Backspace→\x7f`、`Delete→\x1b[3~`、`方向键→\x1b[A/B/C/D`、`Home/End→\x1b[H/F`、`PgUp/PgDn→\x1b[5~/6~`、`Tab→\t`、`Esc→\x1b`、`Ctrl+A..Z→0x01..0x1A` |
| resize 联动 | `resizeEvent` → 换算 rows/cols → `screen.resize()` + `session.resize()`（`setwinsize`） |
| 回滚 | pyte `HistoryScreen`（或 `Screen`+`History`）；`QScrollBar` range = 回滚行数；滚动时 widget 改画回滚区段 |
| 主题 | `apply_theme` → palette 换新 → widget 全量重绘（屏幕模型不含颜色值，只含颜色名，天然免重算） |
| 进程退出 | `process_exited` → 状态行显示 `[进程已退出 code N]` + 标题行"重开"按钮可用；应用退出经 `atexit` 幂等 terminate（与 ACP 后端同款纪律） |

## 5. 验证标准

| 项 | 标准 |
|:---|:---|

| 生命周期 | `exit` 后状态行显示退出码且可重开；关闭应用无残留 shell 进程（`ps` 检查） |
| 主题 | 切换暗色：终端配色即时切换无残色 |
| 走查 | 离屏截图确认浅色/暗色渲染 |

## 6. 风险与对策

| 风险 | 等级 | 对策 |
|:---|:---:|:---|
| 大量输出时自绘刷屏卡顿 | 🟡 | 30ms 刷新聚合（帧率封顶）；备案 dirty-region 优化 |
| pyte 对生僻转义序列行为差异 | 🟢 | pyte 对未知序列容错忽略；走查覆盖 vim/top/ls 主流场景 |
| CJK/emoji 宽度对齐异常 | 🟡 | pyte 内置 wcwidth；验证标准含 CJK 对齐走查 |
| 读线程泄漏（进程死而线程悬挂） | 🟡 | 读循环超时检测 + daemon 线程 + `terminate()` 幂等 + atexit |
| 按键映射遗漏（生僻组合键） | 🟢 | 静态表覆盖主流键；缺失键表现为无响应，可增量补表 |
