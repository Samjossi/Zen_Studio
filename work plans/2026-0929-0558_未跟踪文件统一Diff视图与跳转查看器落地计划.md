## 1. 需求背景

用户实测后拍板两点：

1. **未跟踪文件双击统一进 Diff 视图**：现状未跟踪新文件（`??`）双击走 `file_opened` 进文件查看面板，已暂存新文件（`A`）双击走 `diff_opened` 进变更对比弹窗——同为新建文件两种去向，交互不一致。统一为：未跟踪文件双击也进 Diff 视图（空基准全绿路径已由 0413 计划就绪）。
2. **Diff 视图加「跳转到文件查看面板」能力**：对所有可对比文件（M/A/??）生效，从 diff 一键/一点跳到查看器对应位置，方便用户快速查看已变更的地方（看全上下文）。

现状关键事实（已实地确认）：

- 双击分派：`src/gui/panels/changes/panel.py` `_on_double_clicked`——DELETED → 状态栏提示；MODIFIED → `diff_opened`；其余（UNTRACKED/IGNORED/CONFLICT）→ `file_opened` → `controllers.py` 接 `viewer.open_file`；
- 查看器行定位能力**现成**：`ViewerPanel.open_file(path, line)` 支持 1 起始行号定位（`findBlockByNumber` + `centerCursor`，1836 计划 L2-5，对话区文件路径链接先例），非文本分流页自动忽略行号；
- 变更面板**无既有测试文件**，双击分派逻辑当前零测试覆盖；
- 弹窗是主窗口子窗（非模态单例）：子窗恒在父窗之上，跳转到查看器时若不处理会遮挡目标区域。

## 2. 方案

**D1：未跟踪文件双击改派 `diff_opened`（`src/gui/panels/changes/panel.py`）。**
`_on_double_clicked` 的 UNTRACKED 从 else 分支上提到 `diff_opened` 分支；else 分支剩 IGNORED（忽略条目）与 CONFLICT（冲突态），维持 `file_opened` 不变。模块头 docstring 双击语义行与 `src/gui/README.md` 变更面板信号说明同步更新。

**D2：Diff 视图加「查看文件」按钮 + 跳转信号（`src/gui/diff_view_dialog.py` + `src/gui/controllers.py`）。**
- 顶行右侧、刷新按钮旁新增「查看文件(&V)」按钮；
- 新信号 `viewer_jump_requested = Signal(str, object)`（载荷：绝对路径, 行号|None——对齐对话区 `file_open_requested` 载荷范式）；
- 行号目标：纯函数 `_first_change_line(rows)`——首个 add/del 变更行的新侧行号（add 行取自身 `new_no`；del 行无新侧号，取其后首个新侧行号；全删无新侧行号返回 None）。新文件自然落到第 1 行；
- 启用规则：工作区文件在盘才启用（已删除场景跳无可跳，禁用）；占位页（读取失败/过大/无差异）也可用，此时无行序列，`line=None` 从文件头打开；
- 接线：`controllers._open_diff_view` 惰性创建对话框时 connect 一次 → `viewer.open_file` + 主窗口 `raise_()`/`activateWindow()`；
- **跳转后关闭对话框**：子窗恒在父窗之上，不关闭会遮挡查看器目标行；对话框为非模态单例，重开成本仅一次双击。

**D3：行级精确定位（diff 行号列可点击）。**
`_render` 把行号单元格渲染为锚点 `<a href="diffjump:N">`：add/ctx 行 N=自身新侧行号；del 行 N=其后首个新侧行号（文件尾全删取最后新侧行号）；hunk 行不做锚点。`QTextBrowser` 置 `setOpenLinks(False)` 并接 `anchorClicked` 拦截解析 `diffjump:N`，复用 D2 信号发射（不触发 `setSource` 导航覆盖 diff 内容）。锚点内联 `color` 覆盖 Qt 默认链接色，保持行号染色观感。

**改动清单**：

1. `src/gui/panels/changes/panel.py`：D1 分派 + docstring。
2. `src/gui/diff_view_dialog.py`：D2 按钮/信号/`_first_change_line`/跳转后关闭 + D3 锚点渲染与拦截。
3. `src/gui/controllers.py`：跳转信号接线（查看器 + 主窗口置前）。
4. `src/gui/README.md`：变更面板信号说明、对话框职责描述同步。
5. `tests/test_changes_panel.py`：**新建**（双击分派四分支）。
6. `tests/test_diff_view.py`：`_first_change_line` 纯函数用例、按钮/锚点跳转信号用例、启用规则用例。
7. **不动**：`src/core/`、`ViewerPanel`（行定位能力现成）、主题包。

**明确不做**：CONFLICT 状态双击语义（维持 `file_opened`，冲突态 diff 另行评估）；查看器 → Diff 反向入口（1950 计划否决弹窗配套时一并搁置，本期不复活）；忽略条目（IGNORED）双击语义。

**实施微调说明（2026-09-29）**：

- 锚点范围收敛为 **del/add 行**（计划稿含 ctx 行）：ctx 行本身不是
  「已变更的地方」，不锚更符合跳转意图，也规避 ctx 默认色在类选择器
  里的取色问题；按钮落点（首个变更行）逻辑不变；
- Qt 富文本序列化实证：`a.del`/`a.add` 类选择器生效后，`toHtml` 会把
  色值内联为 `<span style=" color:...">`（`class` 属性不落盘）——
  染色断言按内联 span 形态书写；
- 锚点内不再内嵌 `<font color>`（色由默认样式表类选择器承担），
  避免双重着色冲突。
