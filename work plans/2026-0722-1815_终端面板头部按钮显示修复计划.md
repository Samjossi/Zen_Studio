## 1. 现状诊断

### 1.1 症状 A 🔴 「+」按钮字形裁切（横线只剩一截）

**根因链**（`gui/panels/terminal/panel.py:86-92`）：

```python
self._btn_new = QPushButton("+", self)
self._btn_new.setFixedSize(28, 22)   # ← 宽度锁死 28px
font = QFont(self.font()); font.setBold(True)
font.setPointSizeF(font.pointSizeF() + 3)  # ← 字形再放大的自定义字体
self._btn_new.setFont(font)
```

全局 QPushButton qss（base.qss）含 `padding: 3px 11px` + 1px 描边：
**内容盒宽 = 28 − 11×2 − 1×2 ≈ 4px**。Bold +3pt 的「+」字形宽约 14~16px，
塞进 4px 内容盒 → Qt 水平裁切 → 用户看到的就是中间残存的一小段横线。
垂直方向同理：内容盒高 = 22 − 3×2 − 1×2 = 14px，放大字形上下亦被裁。

### 1.2 症状 B 🔴 「清屏」文字顶部截断、贴右缘

**根因链**（`gui/panels/terminal/panel.py:98-99, 392-396`）：

- `_btn_clear.setFixedHeight(22)`：内容盒高 = 22 − 6(padding) − 2(描边)
  = **14px**，思源黑体中文字形（用户可调字号，默认即 ≥10pt）上伸笔画
  放不下 → 「清」「屏」顶部被裁（截图实证）
- `_lock_header_height()` 取 `_btn_clear.sizeHint().height()` 锁头部栏高，
  但 sizeHint 被 setFixedHeight 污染恒为 22 → 头部栏整体锁矮 26px，
  无任何自愈余量（字号调大时截断只会更严重）
- 贴右缘观感：头部行 margins `(4, 2, 4, 2)` 右端仅 4px，按钮被截后
  视觉重心进一步右塌

### 1.3 对照：聊天侧「+」为何正常（需求方指定的参考实现）

| 维度 | 终端「+」（异常） | 聊天「+」（正常，`tabs.py:63-66`） |
|:--|:--|:--|
| 控件类型 | QPushButton | **QToolButton**（走全局 QToolButton qss，padding `2px 8px`） |
| 固定尺寸 | `setFixedSize(28, 22)` → 内容盒 4×14px | **无**，sizeHint 随字形自适应 |
| 自定义字体 | Bold +3pt（进一步放大字形加剧裁切） | **无**，继承全局字体 |
| 结果 | 字形双侧+上下被裁 | 完整居中，实体化描边圆角正常 |

**修复方向由此明确：终端「+」复刻聊天侧接线（QToolButton + 零固定尺寸
+ 零自定字体），而非在 QPushButton 上打补丁。**

### 1.4 缺口性质

1725 走查 F4 补 QToolButton 全局规则时记录「终端头部『+』」为波及面，
实施时核实其为 QPushButton 而放过——但它是 QToolButton 规则缺位年代的
**绕行 hack**（用 QPushButton + 固定尺寸 + 自定字体硬造小按钮），
如今 QToolButton 范式已立，该 hack 应退役归位。

## 2. 修复方案

### P1 🔴 终端「+」改 QToolButton（复刻聊天侧）

`panel.py::_build_header`：

- `QPushButton("+")` → `QToolButton(self)` + `setText("+")`（对齐 `tabs.py:63-66`）
- 删除 `setFixedSize(28, 22)` 与整段自定义字体代码（4 行）
- tooltip「新建终端」、`clicked → _spawn` 接线不变
- 样式零新增：自动落全局 QToolButton 段（实底 + 描边 + 6px 圆角 + hover 微染）

### P2 🔴 「清屏」解除固定高度，高度交还内容驱动

- 删除 `_btn_clear.setFixedHeight(22)`
- base.qss 增头部作用域收敛（保持头部栏紧凑感，替代固定高度的原始意图）：

```css
#TerminalHeader QPushButton {
    padding: 2px 8px;
}
```

- `_lock_header_height()` **机制保留**（防「标题行膨胀」教训不改）：
  sizeHint 不再被固定高度污染后，锁高公式自动算出「真实内容高 +
  padding + 上下边距」，字号调大时同步伸长、永不截顶
- 头部行 margins `(4, 2, 4, 2)` → `(4, 2, 6, 2)`：右端对齐面板 6px
  外边距体系（《规范》§6.3），解「贴右缘」观感

### P3 🟢 一致性收尾

- 头部栏内 `_status`（#PanelHint）与 tab 条高度随按钮变高后视觉复核
- 《1725 走查》§6 实施记录补一行：F4 波及面的终端「+」hack 退役归位
