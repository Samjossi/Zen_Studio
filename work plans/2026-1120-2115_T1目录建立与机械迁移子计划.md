### 6.4 经验沉淀

1. **包与旧模块同名时先建包再删文件**：`acp.py` 与 `acp/` 并存期间 Python 会优先包，但仍应尽快删除旧文件并用实际 import 验证；只做静态编译无法发现 `map_session_update` 从根出口消失这类运行时错误。
2. **过渡模块不要从稳定 `__init__` 再导出**：否则 T2 拆 mapper 时 GUI/脚本会继续依赖旧公共入口，最后被迫保留 shim。让厂商 provider 直接引用 `acp.updates`，把过渡面缩到可枚举的 import 点。
3. **机械迁移也要锁启动合同**：`AcpConnection` 从 `bin_path` 改为 `argv` 是 T1 唯一的运行语义改动，必须用测试锁定 argv/initialize/session 参数，不能只靠「测试全绿」推断。
4. **AST 对比比逐行 diff 更适合大文件拆分**：按顶层定义比较函数体，可快速证明「只搬不改」；本次因此发现并安全删除了一个无引用常量。
