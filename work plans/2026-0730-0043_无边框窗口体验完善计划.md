# 无边框窗口体验完善计划（标题栏配色 + 边缘缩放 + 增强项）

## 1. 目标

修复 `FramelessWindowHint` 无边框化后暴露的两个基本功能缺陷，并规划后续增强：

1. **标题栏配色割裂**：当前硬编码深色（`#252526`/`#cccccc`），与四个亮色主题视觉
   断裂 → 收编主题令牌体系，随主题切换联动。
2. **窗口边缘无法缩放**：无边框后原生缩放热区消失，鼠标移到边缘显示文本输入符
   （I-beam），用户无法拉大拉小窗口 → 自绘八向边缘缩放热区。
3. 其余增强项（窗口阴影、贴边吸附、标题栏右键系统菜单等）按优先级排入阶段三，
   本计划只做设计定案与排期，不阻塞阶段一/二交付。

**零回归**：拖拽移动、双击最大化、三按钮、菜单栏定高截断、窗口几何持久化行为不变。

## 3. 方案选型

### 3.1 标题栏配色收编（决策点 D1）

| 方案 | 结论 |
|:---|:---|
| A. 复用现有令牌：底色 `sidebar_bg`、文字 `text`、hover `button_hover_bg`、关闭 hover 沿用 `#c75450` | ✅ 采纳（暂定）：零新增令牌，四主题即时生效；关闭按钮红为跨主题通用警示色，保留 |
| B. 每主题新增 `title_bar` 令牌包（bg/text/hover/close_hover 四键） | 备选：若 A 目测某主题观感不佳（如 `sidebar_bg` 与内容区无区分度），升级为 B，调色板加键即切换 |
| C. 保持深色不变 | ❌ 否决：用户明确反馈割裂 |

**实施要点**：`TITLE_BAR_QSS` 从模块级常量改为按调色板生成的函数；`TitleBar.apply_theme(theme)`
挂入 `MainWindow.apply_theme` 转发链（先例：`viewer_panel/terminal_panel/...` 同款签名）。

### 3.2 边缘缩放热区（核心决策）

| 方案 | 结论 |
|:---|:---|
| A. `QSizeGrip` 塞状态栏角落 | ❌ 否决：仅右下角单向，且与状态栏定高体系冲突 |
| B. 窗口级事件过滤器 + 八向热区判定，`startSystemResize(edges)` 优先 | ✅ 采纳：全边全角可用，WM 接管流畅，与拖拽移动（`startSystemMove`）技术路线对称 |
| C. 第三方库（如 FramelessWindow 移植） | ❌ 否决：引入重依赖，与现有 TitleBar 架构不匹配 |

**热区设计**：

- 热区厚度 `RESIZE_MARGIN = 6px`（窗口内缩判定；不向外扩——无边框窗口外扩需透明
  像素边距，侵入布局边距体系，本期不做）。
- 八向判定：`左/右/上/下` + 四角，映射 `Qt.Edge` 标志位组合；光标对应
  `SizeHorCursor / SizeVerCursor / SizeFDiagCursor / SizeBDiagCursor`。
- 事件路径：`MainWindow` 开 `WA_MouseTracking`，`QApplication` 级 `eventFilter`
  （或递归给子控件装过滤器——决策点 D2，实施时以「光标不被子控件 I-beam 覆盖」
  为验收标准择简者）拦截 `MouseMove/MouseButtonPress`：
  - 光标进入热区（未按下）→ `setCursor` 对应缩放光标；离开 → `unsetCursor`。
  - 热区内左键按下 → `windowHandle().startSystemResize(edges)`，返回 False 时
    记录起始几何与全局坐标，手动 `setGeometry` 兜底（MouseMove 驱动，释放结束）。
- 守卫：`isMaximized()` 或 `isFullScreen()` 时热区整体禁用；`minimumSize`
  建议设为三栏最小可布局值（实测后定，初估 900×500——决策点 D3）。
