## 1. 结论

**需求方观察属实，且比观察更严重**：聊天标签页（QTabWidget）在 base.qss 中
**零规则**，整体回落平台原生样式渲染，是当前主界面唯一未纳入主题体系的
显眼组件；同窗口内与终端面板标签（`#TerminalTabs`，合规）形成肉眼可见的
风格割裂。间距问题同样属实：ChatTabs 是全库唯一 0 外边距、0 间距的面板容器。

## 2. 发现清单

### F1 🔴 聊天标签页零 qss 规则，平台原生渲染

| 项 | 内容 |
|:---|:---|
| 证据（代码） | base.qss 全文 grep `QTabWidget`/`QTabBar` 零命中（`#TerminalTabs` 为终端面板专用 ID 规则，不覆盖 QTabWidget）；tabs.py 未给 `_tabs` 设 objectName、无任何内联样式 |
| 证据（截图） | 「会话 1/2/3」为原生灰底方块标签：直角、无圆角层级、无 accent 激活指示、选中态仅靠原生明暗区分 |
| 违反 | 《规范》§1 圆角层级（8/6/3~4 全局统一）；§3 objectName 接线纪律（未复用也未登记新 ID）；§4 控件风格表（QTabWidget 整行缺失） |
| 对比 | 同窗口终端面板「终端1」标签：`#TerminalTabs` 透明底 + 激活 2px accent 下划线（Multi_Cli 范式），完全合规——两组件同屏风格断裂 |

### F2 🟡 模型行与标签条间距过窄（需求方主诉）

| 项 | 内容 |
|:---|:---|
| 证据（代码） | `ChatTabs.__init__`：`layout.setContentsMargins(0, 0, 0, 0)` + `setSpacing(0)`；`ModelBar` 自身 margins `(4, 2, 4, 2)` → 下拉框底缘距标签条仅约 2px |
| 证据（截图） | 左栏局部图：模型行与标签条几乎相贴，无呼吸感 |
| 违反 | 《规范》§6.3 外边距/间距职责（面板级 6px）：viewer/terminal/chat panel 容器均为 6px 外边距，**ChatTabs 是全库唯一 0 边距 0 间距的面板容器** |

### F3 🟡 标签条与内容卡片视觉脱节

| 项 | 内容 |
|:---|:---|
| 证据 | QTabWidget `documentMode` 去框后，原生标签条悬于 ChatPanel 的 `#PanelCard` 卡片之外：标签底缘与卡片顶缘各自为政、无视觉连续；原生灰底标签贴在侧栏 `sidebar_bg` 上显得突兀 |
| 违反 | 《规范》§1「描边层次优于色块分区」的整体感；对照 `#TerminalTabs`「tab 条透明融入头部栏」范式 |

### F4 🟡 QToolButton 全局无规则，波及三处

| 项 | 内容 |
|:---|:---|
| 证据（代码） | base.qss 未定义任何 `QToolButton` 规则 |
| 波及 | ① ChatTabs「+」新建角按钮（原生渲染，截图可见方形灰钮）；② 设置中心黑名单折叠钮（1510 计划刚落地，同走原生样式）；③ 终端面板头部「+」新建终端钮 |
| 违反 | 《规范》§4 按钮实体化（实底 + 描边 + 6px 圆角 + hover 微染） |

### F5 🟢 标签关闭按钮原生样式

| 项 | 内容 |
|:---|:---|
| 证据 | `QTabBar::close-button` 无 qss：原生 ✕，选中标签的关闭钮呈原生色块（截图「会话 3」为灰橙方块），无 hover 微染体系 |
| 说明 | 随 F1 一并解决（定义 QTabBar 段时补 close-button 子控件规则） |

### F6 🟢 ModelBar 本体合规，边距微瑕

下拉框走全局 QComboBox 规则（透明底 + 描边 + 6px 圆角）合规；
margins `(4, 2, 4, 2)` 与面板 6px 体系不一致（随 F2 一并对齐）。

## 3. 缺口性质判定

| 缺口 | 性质 |
|:---|:---|
| QTabWidget/QTabBar 无规则 | **多标签改造（2026-0722-0756 计划 P3）引入新组件时未同步样式**——《规范》§7 自查清单第 2/6 项（四主题截图复核、objectName 复用）当时未执行 |
| ChatTabs 0 边距 | 多标签改造前单聊天面板时代遗留（原 ChatPanel 直接充左栏，自身带 6px；抽出一层 ChatTabs 容器后边距未重新分配） |
| QToolButton 无规则 | 历史缺口（此前 QToolButton 用量少未暴露；1510 黑名单折叠钮 + 终端/聊天「+」钮使其显性化） |

## 4. 修复方向建议（供立项参考，非实施）

1. **base.qss 增聊天标签样式段**：对齐 `#TerminalTabs` 范式——tab 透明底 +
   `muted_text`，激活态 `text` + 2px `accent` 下划线（或卡片化标签，二选一立项
   时选型）；圆角与 hover 微染按《规范》§1/§4；补 `::close-button` 子控件规则
2. **ChatTabs 容器边距对齐 6px 面板体系**：container margins 与 spacing 重分配
   （ModelBar 行、标签条、卡片三者呼吸感）；ModelBar margins 并入统一
3. **base.qss 补 QToolButton 全局实体化段**（实底 + 描边 + 6px 圆角 + hover
   微染），一次惠及「+」角按钮、设置中心折叠钮、终端头部钮三处
4. **《规范》§4 控件表补 QTabWidget/QToolButton 两行**（规则落地后回填，
   保持文档与 base.qss 同步）
5. **验证纪律**：四主题 offscreen 截图 + **真实平台走查**（1510 教训：offscreen
   Fusion 样式会弱化原生观感差异，本报告 F1 在真实平台比截图更刺眼——
   需求方实机观察先于截图发现即为例证）
