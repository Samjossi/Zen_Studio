## 2. 设计方案

### 2.1 骨架重排（P0）

```text
┌────────────────────────────────────────────────────┐
│ 设置中心                                            │
├──────────┬─────────────────────────────────────────┤
│ 导航      │ 页标题（粗体大字）                        │
│ （图标+   │ ───────────────（分隔线）                │
│  文字，   │                                         │
│  160px，  │ 页面内容区（统一外边距/间距常量）          │
│  分隔线） │                                         │
│          │                                         │
├──────────┴─────────────────────────────────────────┤
│                                          [关闭]    │
└────────────────────────────────────────────────────┘
```

- **页标题区**：`_PAGE_REGISTRY` 扩为四元组 `(导航名, 页标题/副标题, build, reload)`——
  副标题即现行页顶灰色 hint 上移，标题粗体 14pt、副标题 muted_text，
  `currentRowChanged` 时骨架统一刷新；各页 `_build_*_page` 不再自带页顶说明（D4/D8）
- **导航栏**：140 → 160px 且改 `setMinimumWidth`（不再 Fixed），项高 32px、
  左内边距 12px；右缘 1px `border` 令牌分隔线；图标列入裁剪（§4），本轮纯文字（D1/D10）
- **底部按钮**：弃用 `QDialogButtonBox`（其本地化依赖 QTranslator，未装载故英文），
  改普通 `QPushButton("关闭")` + `clicked.connect(self.reject)`，无图标（D3）
- **尺寸纪律**：`setMinimumSize(600, 420)`，初始 `resize(680, 500)`；
  内容区统一 `setContentsMargins(16, 12, 16, 12)` + `setSpacing(8)`（D9）

### 2.2 样式令牌化（P0）

- `_STYLE_HINT` 由 `color: gray` 改引主题 `muted_text` 令牌：settings_dialog 新增
  模块级 `_apply_dialog_palette(theme_tokens)` 挂入 `switch_theme` 收敛点链
  （同 ModelBar/面板换肤先例），或简化为控件 `QPalette` 取 `placeholderText`
  角色色——选型在实施时取改动面更小者，本计划裁决：**用 QPalette 角色色**，
  零 qss 模板改动、天然随主题（D6）
- radio 粗体、页标题字号等内联 style 集中到模块级 `_STYLE_*` 常量（AFCP 3.4），
  不再散落构建函数（D11）
- 描述缩进 24px 魔法数提取常量 `_DESC_INDENT = 20`（radio 指示器宽 16 + 间距 4），
  按指示器实际度量对齐（D5）

### 2.3 权限页细化（P1）

- 黑名单入口改「`QToolButton` + `▶/▼` 箭头 + 左对齐自适应宽度」，checkable 态
  翻转箭头；不再拉满整行（D2）
- 黑名单只读区 `setFixedHeight(160)` + 等宽字体（`QFontDatabase.systemFont(
  FixedFont)`），条目每行 `编号. 说明` 不变（D13）
- `auto_all` 档警示红色保留（WARNING_COLOR 单一来源不动）

### 2.4 各页布局统一（P1）

五页统一模板：**说明段落 → 控件区 → 补充 hint**，控件区枚举/单选用 VBox、
键值对用 FormLayout 的现行格局保留（两类场景本就不同），但：
- hint 一律走 `_make_hint` + `setWordWrap(True)`，禁止再出现不换行 hint（D8）
- 终端页、高级页控件过少：高级页「打开配置文件 / 恢复默认设置」改水平排列
  + `addStretch(1)` 沉底，视觉重心上移（D9）
- 所有 `_on_*` 槽补 `statusBar().showMessage` 反馈（模型/外观/终端页对齐权限页
  先例），文案统一格式：`{页名}：{项} → {值}`（D12）

### 2.5 明确不做

- 不改 `_PAGE_REGISTRY` 机制本身（仅扩元组字段，注册语义不变）
- 不改任何设置键、默认值、持久化格式
- 不动 MainWindow 应用槽签名与 `_sync_settings_dialog` 链路
- 不动 qss 模板与各主题调色板文件
