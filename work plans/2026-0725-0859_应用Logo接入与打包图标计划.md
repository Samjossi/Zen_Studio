# 应用 Logo 接入与打包图标计划

> **平台约束**：Zen Studio 仅在 **Linux** 上使用，Windows / macOS 一概不考虑。全计划只覆盖 Linux 图标体系（窗口图标 + 任务栏 / Dock + `.desktop` 入口），不产出 `.ico` / `.icns`。

## 1. 背景与目标

从 `assets/logo候选池/B_禅圈.svg` 定版 Zen Studio 官方 Logo，完成两条链路：

1. **运行时图标**：窗口标题栏图标 + 任务栏 / Dock 图标 + 「关于」对话框 Logo。
2. **打包产物图标**：PyInstaller 打包（Linux onedir）后的运行图标与 `.desktop` 桌面入口图标（PNG）。

定版资产**复制出候选池**为 `assets/logo.svg`，候选池原文件保留不动（后续换标只改正式文件，不动候选池）。

### 1.1 关于「标题栏中间显示 Logo」的约束说明 ⚠️

当前标题栏是 **Qt 原生标题栏**（`gui/main_window.py` 中 `setWindowTitle` 设置文字，由操作系统绘制）。Linux 下原生标题栏的 Logo 能力 = **窗口图标**（`setWindowIcon`），显示位置：

| 场景 | 图标来源 | 位置 |
|:---|:---|:---|
| 窗口标题栏 | `setWindowIcon` | 标题**最左侧**（文字左边；视桌面环境，部分 DE 不显示） |
| 任务栏 / Dock（X11） | `setWindowIcon` | 任务管理器、Alt-Tab |
| 任务栏 / Dock（Wayland） | `.desktop` 文件的 `Icon=`（经 `StartupWMClass` / `setDesktopFileName` 关联） | 任务管理器、Alt-Tab |

原生标题栏**不支持**在居中标题文字旁嵌入图标。若确需「标题正中 + Logo」的视觉效果，须改自绘无边框窗口（`FramelessWindowHint` + 自绘标题栏），工程量大且涉及拖拽 / 缩放 / 系统按钮重实现，**列为本计划非目标**（见 §7），待运行时图标落地后再评估。

## 3. 定版资产方案

| 文件 | 用途 | 来源 |
|:---|:---|:---|
| `assets/logo.svg` | 矢量母版（换标唯一改动点） | 复制自 `assets/logo候选池/B_禅圈.svg` |
| `assets/logo_256.png` | 运行时窗口图标 + 「关于」对话框 + `.desktop` 的 `Icon=` | 由母版渲染 |
| `assets/logo_512.png` | 高分屏 / 大图标场景（部分 DE 任务栏放大取图） | 由母版渲染 |

Linux 图标体系以 PNG 为准（freedesktop 规范），**不产出 `.ico`**。窗口图标用 256px PNG 即可——Qt 按场景自动缩放；SVG 直接喂 `QIcon` 依赖 QtSvg 插件在打包态的随行，反而多一个风险点，故运行时统一走 PNG。

栅格化脚本 `scripts/render_logo.py`：用 PySide6 `QSvgRenderer` + `QImage` 渲染 16–512 各尺寸到 `.tmp/logo_preview/`（供 T3 目检），正式产出仅落 `logo_256.png` 与 `logo_512.png` 两件。**零新增第三方依赖**。脚本入库留存，换标时改母版重跑即可。

## 6. 风险与注意事项

| 符号 | 项 | 说明 |
|:--:|:---|:---|
| ⚠️ | 深色 Logo 辨识度 | 母版主体 `#1B1B22`，深色主题任务栏上 16px 尺寸可能糊成一团，T3 目检兜底 |
| ⚠️ | Wayland 任务栏图标 | Wayland 下任务栏图标取自 `.desktop` 而非 `setWindowIcon`——T5 的 `setDesktopFileName` 与 T10 的 `StartupWMClass` 必须同名（`zen-studio`），缺一环则任务栏显示默认齿轮图标 |
| ⚠️ | `PROJECT_ROOT` 语义漂移 | T4 改路径推导后，`config/`（设置、最近项目）在打包态的写入位置仍是「解包目录」——用户数据应写用户目录而非安装目录，属**打包配置专题**，本计划只保证资源读取正确，写入路径另立计划处理 |
| 🟡 | `.tmp/` 约定 | 按 `AGENTS.md`，渲染预览组放项目内 `.tmp/logo_preview/`，不碰系统临时目录 |
