## 1. 问题现象

用户反馈：AI 改动文件（重命名、新增、删除、目录结构调整）后，文件树**偶尔一直显示旧的文件名与旧结构**，界面没有任何途径可刷新。

## 2. 根因诊断

### 2.1 文件树实现现状

文件树位于主窗口**右栏**（`gui/main_window.py` 实例化 `FileExplorer`），实现于 `gui/panels/file_explorer/explorer.py`：

- 基于 Qt 原生 `QFileSystemModel` + `QTreeView` 懒加载，结构变化监听完全依赖 `QFileSystemModel` 内建的 inotify watcher，项目中没有自建 watcher。
- watcher 溢出（inotify 上限、大批量外部改动）时事件会漏，模型内部节点缓存滞留旧结构——这正是「偶尔一直显示旧的」的根因。

### 2.2 刷新能力其实已存在，只是入口太隐蔽

`FileExplorer.refresh()` 已实现完整的强制重建逻辑：收集展开/选中状态 → `setRootPath("")` 脱根 → `setRootPath(root_dir)` 重挂强制全量重读 → `directoryLoaded` 异步接力回填展开/选中状态。

但该入口**只藏在视图菜单**「刷新文件树（&F)」（`gui/menus/view_menu.py`，action `view.file_tree_refresh`），无快捷键、无按钮，用户发现不了。

## 3. 方案

在文件树面板**右下角加一个悬浮圆形刷新按钮**，点击直接调 `FileExplorer.refresh()`。样式 1:1 复刻对话栏「回到底部」按钮（`gui/panels/chat/transcript.py` 的 `BackToBottomButton`）：

| 要素 | 复刻来源（transcript.py） | 本按钮 |
|:---|:---|:---|
| 控件 | `QToolButton`，`setFixedSize(32, 32)` | 同 |
| 图标 | Unicode 字符当文本（⏷ U+23F7），非图片非自绘 | `⟳` U+27F3（需截图验证字形，见 T3） |
| 外形 | qss `border-radius: 16px`（半径=直径一半成圆），背景/边框/hover 吃全局 `QToolButton` 规则 | 同，objectName `FileTreeRefreshButton` |
| 低调/hover | `QGraphicsOpacityEffect` 常态 0.5，`eventFilter` Enter→1.0 / Leave→0.5 | 同，照抄该模式 |
| 定位 | 手动 `move` 到右下角 + `resizeEvent` 重定位 + `raise_()` | 同，parent 挂 `FileExplorer` 自身（它是普通 QWidget，无 viewport；树填满布局，按钮浮于其上） |

**与「回到底部」的差异**（有意为之，非遗漏）：

- 图标字符不同（⟳ vs ⏷）。
- **常显**：不绑定跟随锁那套显隐状态机，任何时候都可见可用——因为「树滞留旧结构」正是用户不知道该刷新的场景。

**改动清单**：

1. `gui/panels/file_explorer/explorer.py`
   - 顶部常量区加 `_REFRESH_BTN_SIZE = 32`、`_REFRESH_BTN_MARGIN = 16`、`_REFRESH_BTN_OPACITY = 0.5`（数值与注释风格对齐 transcript.py 同名常量）。
   - `__init__` 末尾造按钮：parent `self`、objectName `FileTreeRefreshButton`、`ToolButtonTextOnly`、`setText("⟳")`、`clicked.connect(self.refresh)`、装 `QGraphicsOpacityEffect` + `installEventFilter`。
   - 新增 `_place_refresh_button()`（右下角定位 + `raise_()`）与 `resizeEvent` 重定位；新增 `eventFilter` 处理 Enter/Leave 透明度。
   - 边距说明：FileExplorer 布局自身有 6px 外边距，按钮坐标系为面板坐标，`_REFRESH_BTN_MARGIN = 16` 已大于 6，视觉上与「回到底部」一致，不额外叠加。
2. `assets/themes/base.qss`
   - 追加 `#FileTreeRefreshButton { padding: 0; border-radius: 16px; font-size: 22px; }`（font-size 按字形实看微调）；背景/hover 变色自动继承全局 `QToolButton` 规则，四主题通吃。
3. **不动**：`refresh()` 本身、视图菜单入口、Git 状态代理模型——全部复用。

## 5. 影响面评估

- ✅ `refresh()` 为既有方法，按钮只是新增一个调用入口，刷新行为本身与视图菜单完全一致。
- ✅ qss 只新增一条 objectName 规则，全局 `QToolButton` 规则不动，其余按钮观感零影响。
- ✅ 树懒加载与 Git 状态着色（`GitStatusProxyModel`）不受影响；`resizeEvent`/`eventFilter` 为 FileExplorer 新增方法，无覆盖冲突。
- ⚠️ 按钮会遮挡树右下角一小块区域——与「回到底部」同样取舍，可接受；常态 0.5 透明度降低存在感。
- ⚠️ ⟳ 字形依赖当前字体渲染，T3 若字形不佳，备选字符 `↻`（U+21BB）或退回自绘/主题图标方案再议。
