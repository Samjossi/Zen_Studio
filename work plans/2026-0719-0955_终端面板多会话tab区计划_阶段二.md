# 终端面板多会话 tab 区计划（阶段二）

## 1. 目标

头部栏左侧进化为 **tab 区**，承载多 PTY 会话；操作组保持同行固定（Theia"工具栏独立于滚动区"原则）；查找等低频功能浮层化；清屏/终止/重开收进终端内容右键菜单（Theia 功能分层）。

目标形态：

```
┌────────────────────────────────────────────┐
│ [bash ×] [zsh ×] [＋]           [清屏][−]  │ ← 单行：tab 区（可滚动）+ 固定操作组
├────────────────────────────────────────────┤
│ $ █                        ┌───────────┐   │
│                            │ 查找浮层   │   │ ← Ctrl+F 调出，右上角悬浮不占布局
│                            └───────────┘   │
└────────────────────────────────────────────┘
```

## 2. 依赖关系与检查点

| 依赖 | 说明 |
|:---|:---|
| 🔴 阶段一完成 | 头部栏单行结构、操作组、高度锁定就位，本阶段在其左侧插入 tab 区 |
| 现有五层单向依赖结构 | 每会话一套 `PtySession + TerminalScreen`，`TerminalWidget` 经 `set_screen`/`set_session` 重绑定——切换机制天然支持，无需改层间契约 |

**检查点**：① tab 区骨架（新建/关闭/切换）→ ② 会话生命周期（进程回收）→ ③ 右键菜单 → ④ 查找浮层（可裁剪）。

## 3. 设计

### 3.1 会话栈模型（panel.py 改造）

```
TerminalPanel
├── _sessions: list[_Session]          # 会话栈（dataclass：session/screen/title）
├── _active: int                        # 活动索引
├── tab_bar: QTabBar                    # tab 区（头部栏左侧）
└── terminal: TerminalWidget            # 绑定 _sessions[_active] 的 screen/session
```

- `_Session` 值对象：`session: PtySession`、`screen: TerminalScreen`、`title: str`（tab 文本，默认 shell 名）。
- **切换**：`tab_bar.currentChanged` → `terminal.set_screen(s.screen)` + `terminal.set_session(s.session)` + 滚动条复位 + 全量重绘。
- **新建**：`＋` 按钮 → 以当前 `grid_size()` spawn（无阶段一前的 1 行屏幕问题，彼时控件尺寸已稳定）→ 入栈 + `addTab` + 切为新 tab。
- **关闭**：tab 行内 ×（`QTabBar.setTabsClosable(True)`）→ `session.terminate()`（幂等，已有）→ 出栈 + `removeTab`；关到最后一 tab 时**保留面板**，终端区显示空状态提示（"没有终端，点击 ＋ 创建"，对齐 Multi_Cli_Studio 的 overlay 范式）。
- **后台会话数据**：非活动会话的 reader 线程照常发信号 → 各自 `_on_data` → 各自 screen 喂入（信号槽在 GUI 线程串行执行，pyte 无线程安全问题）；切回时 `set_screen` 触发全量重绘，天然同步。

### 3.2 头部栏布局（阶段一结构上演进）

```
QHBoxLayout
├── tab_bar QTabBar（stretch=1，expanding=false，usesScrollButtons=true）  ← tab 区
├── btn_new  QPushButton("＋")   ← 固定于 tab 尾后（对齐 C：工具栏独立于滚动区）
├── _status  QLabel
├── btn_clear / btn_hide（阶段一按钮组，重开迁入右键菜单）
└── （btn_clear 保留至右键菜单就位后再评估去留）
```

- tab 文本：初始为 shell 名；**动态标题**跟进——pyte `Screen` 接收 OSC 0/2 序列后更新 `title`，panel 轮询/挂钩同步到 tab 文本（对齐 Theia 的 `onTitleChange` 行为）。
- tab 溢出：`usesScrollButtons` 滚动箭头兜底；"打开的 tab 下拉"裁剪不做（tab 数量有限）。

### 3.3 右键菜单（终端内容区，对齐 Theia 分层）

`TerminalWidget.contextMenuEvent` → 菜单：清屏 / 重开 / 终止（kill）/ 关闭此终端。动作经信号转发给 panel 执行（widget 不碰会话生命周期，保持单向依赖）。

### 3.4 查找浮层（可裁剪，优先级低）

- `Ctrl+F`（widget `keyPressEvent` 拦截）→ 头部栏下方/终端右上角浮层：`QLineEdit` + 上一个/下一个 + 关闭。
- 搜索域：活动会话 `TerminalScreen` 当前屏 + 回滚区文本；命中行高亮（widget 绘制叠加层）。
- 本期可实现最小版：仅当前屏搜索 + 跳转高亮；回滚搜索备案。

## 5. 验证标准

| 项 | 标准 |
|:---|:---|
| 新建 | 连开 3 个会话：各自独立提示符、`pwd`/`echo` 互不串屏 |
| 切换 | A 会话 `seq 1 100`，切 B 再切回：A 屏幕与回滚完整、光标位置正确 |
| 后台数据 | B 会话后台跑 `for i in {1..50}; do echo $i; sleep 0.1; done`，切回后输出完整无丢失 |
| 关闭 | × 关闭后 `ps` 无残留 shell；关闭活动 tab 自动切邻 tab；关到最后一个显示空状态提示且可新建 |
| 动态标题 | `echo -ne "\033]0;自定义标题\007"` 后 tab 文本更新 |
| resize | 拖动 splitter：仅活动会话 `stty size` 变化；切回后台会话时其尺寸同步为新值 |
| 右键菜单 | 各动作行为正确；「终止」后 tab 状态显示退出提示 |
| 查找 | Ctrl+F 浮层开合、当前屏命中高亮、Enter 跳下一个 |
| 主题 | 五主题下 tab 条/浮层/菜单样式跟随（qss） |

## 6. 风险与对策

| 风险 | 等级 | 对策 |
|:---|:---:|:---|
| 多 reader 线程信号错绑（A 会话数据进 B 屏幕） | 🟡 | 每会话信号连接各自闭包（`functools.partial`/lambda 捕获 `_Session`），连接在入栈时一次性建立 |
| tab 关闭瞬间后台信号到达已弃 screen | 🟢 | `PtySession._closing` 守卫已有；出栈前 `terminate()` + 断信号 |
| `QTabBar` 样式与主题 qss 体系磨合（关闭按钮/激活态） | 🟡 | 新增 `QTabBar` 主题规则（五个 qss 同构补充）；激活态对齐 Multi_Cli 下划线范式 |
| resize 竞态放大（N 会话各自 winsize） | 🟢 | resize 仅发活动会话；切换时按当前 grid 补同步 |
| OSC 标题注入恶意/超长文本 | 🟢 | tab 文本截断（如 32 字符）+ 去除控制字符 |

## 7. 备案（本阶段不做）

1. 会话拆分（split，同屏并列两终端）——选型 C 工具栏第二颗，待面板高度策略另行设计
2. 回滚区搜索与"打开的 tab"下拉
3. 终端内容喂 AI（`TerminalScreen.plain_text` 一键发聊天，ACP terminal RPC 接通前的过渡形态）
4. 会话持久化（重启恢复 tab 列表；shell 状态本身不可恢复，仅恢复结构）
