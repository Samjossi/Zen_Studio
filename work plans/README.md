# work plans

本目录用于存放项目的 **Work Plans（工作计划）**。

计划文档用于将章程拆分为可执行、可追踪的任务清单，通常包含：
- 阶段划分
- 任务列表与优先级
- 预计起止时间
- 负责人
- 检查点与依赖关系

文件命名遵循 `文档编写规范.md`（v3.0）：
- 文件：`YYYY-MMDD-HHMM_计划标题.md`
- 中文优先，英文名后置
