# 时间线色块条与用量徽章上移输入区上方实施计划

> 按选型定夺的方案 F：将**会话活动时间线色块条**（现位于聊天卡片最底部、
> 输入对话框之下）与**上下文用量徽章**（现位于输入区底行、模型下拉与发送
> 按钮之间）合并为**一行状态条**，上移到**输出区与输入区之间**——左条
> 右徽，徽章独立右侧恒宽。每标签一套实例，语义零迁移。

## 1. 目标布局（已与用户图形化确认）

```
├─ 输出区（splitter 上段）───────────┤
│                                    │
├─ 状态行 ───────────────────────────┤  ← 新位置
│ ▓▓▓▓▓▓░░▓▓▓░░（时间线条）  [~42%]  │     左条右徽，徽章恒宽右对齐
├─ 输入区（splitter 下段）───────────┤
│ ┌─ 输入框 ────────────────────┐    │
│ └─────────────────────────────┘    │
│ [模型▾][版本▾]          [ 发送 ]   │  ← 底行移除徽章，纯操作行
└────────────────────────────────────┘
     （卡片最底部不再有时间线条）
```

## 2. 现状盘点（实证，2026-07-31）

`gui/panels/chat/panel.py`：

- `_build_layout()`：`card_layout.addWidget(self._splitter, 1)` 后
  `card_layout.addWidget(self.timeline)`——时间线条挂卡片底部常驻
  （1824 计划 D2，不进 splitter 因子件会被拖拽均分）。
- `_build_input_box()`：`button_row` 内 `model_bar → _usage_label →
  stretch → _send_button`；`_usage_label` 恒宽（`~100%` + 8px）、
  AlignCenter、空文本占位——显隐不改 sizeHint 的左栏宽度病根纪律
  （2026-0724-2305 教训）。
- splitter 垂直双向：output / input_box 比例可拖拽、状态持久化
  （DEFAULT_SPLITTER_SIZES）。

## 3. 设计要点

### 3.1 状态行挂载点（关键决策）

状态行**不进 splitter**（子件会被拖拽均分，1824 计划 D2 已实证此约束），
也**不再挂卡片底部**。落点为 **input_box 容器内、输入框上方**——
`_build_input_box()` 的 box_layout 首行：

```
box_layout: [状态行(定高)] → [输入框(stretch 1)] → [button_row]
```

效果等价「输出区与输入区之间」：状态行随 splitter 拖拽与输入区整体移动，
视觉恒在输出区下缘、输入框上缘之间；定高不参与拉伸。

### 3.2 同行装配

- 顺序：**左时间线条（stretch 1）→ 右用量徽章（恒宽）**。
- 行高由时间线条决定（约 30px，MAX_H 26 + 上下各 2，1824 已定）；
  徽章垂直方向随 Qt 布局默认居中。
- 徽章**独立右侧**，不嵌入条尾——保留 `~100%` 恒宽占位与 AlignCenter
  语义不变，时间线条可用宽度不受徽章影响。

### 3.3 不变项（明确冻结）

- 时间线条数据源、清条点（异后端切换新会话）、主题三键、`set_colors`
  注入——1824 计划已落地，本计划零改动。
- 徽章簿记、usage_update 路由、tooltip 明细、热态变色、清零点
  （`reset_session` 语义）——1412/1454 计划已落地，本计划零改动。
- 底行其余元素（ModelBar 双下拉、stretch、发送/停止双态按钮）顺序不变。
- 主题键零新增、间距复用卡片现有 spacing 体系。

## 4. 决策表

| # | 决策点 | 定夺 | 依据 |

| D1 | 状态行挂载点 | **input_box 内、输入框上方** | splitter 子件均分约束（1824 D2 实证）；随输入区拖拽移动，视觉恒在输出/输入分界 |

| D5 | 生命周期 | 不变（每标签实例，随会话清条/清零） | 方案 F 语义零迁移承诺 |
| D6 | 主题/样式 | 零新增键；badge 在状态行的视觉与底行一致（qss 选择器 #chatUsageLabel 按 objectName 命中，与父容器无关） | 最小改动面 |
