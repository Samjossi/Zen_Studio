## 2. 漏网根因诊断

### 2.1 标准右键菜单：Qt 内部创建，绕过全部修复点

第一轮修复覆盖的是**项目代码显式创建的 QMenu**（菜单栏装配器批量处理 + 终端面板 + 文件树两处）。但下列控件右键时弹出的**标准编辑菜单**（撤销/重做/剪切/复制/粘贴/全选）由 Qt 在 `contextMenuEvent` 默认实现内部即时 `new QMenu`，完全不经过 `gui/popups.py`：

| 控件 | 文件 | 说明 |
|:---|:---|:---|
| `ChatInput(QTextEdit)` | [`gui/panels/chat/input.py`](gui/panels/chat/input.py) | 聊天输入框 |
| `ChatOutput(QTextBrowser)` | [`gui/panels/chat/output.py`](gui/panels/chat/output.py) | 聊天输出区 |
| `CodeViewer(QPlainTextEdit)` | [`gui/panels/viewer/code_viewer.py`](gui/panels/viewer/code_viewer.py) | 代码查看器 |
| 查找框 `QLineEdit` × 2 | [`gui/panels/terminal/panel.py`](gui/panels/terminal/panel.py)、[`gui/panels/viewer/panel.py`](gui/panels/viewer/panel.py) | 终端/查看器查找浮层输入框 |
| 详情 `QPlainTextEdit` | [`gui/panels/chat/permission_dialog.py`](gui/panels/chat/permission_dialog.py) | 权限对话框只读详情 |

这些 QMenu 命中主题 qss 的 `QMenu { border-radius: 8px }` 圆角规则，但窗口本身不透明 → 与第一轮 §2.1 相同的"矩形窗口底 + 圆角内容"双框。

### 2.2 下拉框：第一轮根因归因不完整，修复未产生视觉效果

第一轮 §2.2 认定"容器 StyledPanel 面板"为矩形来源并施以 `NoFrame` + 透明背景，但离屏截图（`.tmp/shot_combo.py`，真实 cloud 主题 qss）显示：

- 修复组与未修复对照组截图**视觉无差异**
- 四角像素均为不透明灰 `rgba(153,153,154,255)`（修复组 PNG 虽有 alpha 通道，但角落 alpha=255）

→ 容器矩形底的**真正绘制来源尚未找对**，`NoFrame` 不是充分条件。候选方向（实施时逐项实验排除）：

1. 容器顶层窗口缺 `Qt.FramelessWindowHint` 导致透明属性不生效（已知 Qt 弹层圆角的常见搭配）
2. 容器自身 `autoFillBackground` / palette 填充路径（与样式引擎面板无关）
3. 内部 view 的 qss 背景被矩形化（`QComboBox QAbstractItemView` 的 `border` 与 `QListView` 的 `border-radius` 规则叠加冲突）
4. offscreen 平台 grab 合成方式与真实 X11 显示差异（须以像素 alpha 为判定标准，排除截图假象）

## 3. 修复方案

### 3.1 标准右键菜单（确定性修复）

在 [`gui/popups.py`](gui/popups.py) 新增统一入口：

```python
def exec_standard_context_menu(widget, event) -> None:
    """标准编辑菜单透明化弹出：替代控件默认 contextMenuEvent。

    menu = widget.createStandardContextMenu(event.pos()) 经
    make_translucent_popup() 处理后 exec(event.globalPos())。
    """
```

各控件接入方式：

| 控件 | 接入 |
|:---|:---|
| `ChatInput` / `ChatOutput` / `CodeViewer` | 各自重写 `contextMenuEvent`，一行调用上述入口 |
| 查找框 `QLineEdit` × 2 | 同思路重写（两处 panel 内建私有子类或事件过滤器，实施时择简） |
| 权限对话框详情 `QPlainTextEdit` | 同思路重写（只读菜单仅复制/全选，同机制） |

### 3.2 下拉框（实验驱动修复）

**判定标准先行**：以离屏截图 + 角落像素分析为准——四角 `alpha == 0`（或视觉上圆角外无填充）才算修复；禁止再以"属性断言通过"作为结论。

步骤：

1. 基线截图：当前代码 + 真实 cloud qss，确认双框像素特征（已有 `.tmp/fix_check_cloud_popup.png`）
2. 按 §2.2 候选方向逐项实验，每项截图 + 角落像素对比：
   - 实验 A：容器追加 `Qt.FramelessWindowHint`
   - 实验 B：容器 `setAutoFillBackground(False)` + palette Window 透明化
   - 实验 C：view 侧 qss 调整（`QComboBox QAbstractItemView` 显式 `border-radius`，隔离全局 QListView 规则冲突）
   - 实验 D：A+B 组合及余下组合
3. 命中后收敛为 `make_translucent_combo_popup()` 的正式实现，五主题逐一截图回归（`.tmp/verify_combo_round2_<主题>.png`）
4. 暗色主题重点复核：深底浮层的圆角抗锯齿边缘不得有亮边残留
