# 弹出浮层圆角双框（矩形套圆角矩形）清理计划

## 1. 事件背景

2026-07-20 用户报告：点击菜单栏任意一项、以及选择模型/版本下拉任意一项时，弹出浮层呈现**"一个矩形里面包着一个圆角矩形"**的双框观感，疑似两个容器重叠或两层边框。本计划记录两轮清理的完整诊断与修复，并登记后续清理项。

## 2. 根因归因

浮层圆角双框由**两层各自独立的"矩形来源"**叠加而成，均非容器重复创建：

### 2.1 第一层：顶级弹出窗口的不透明矩形底（菜单 + 下拉共有）

主题 qss 给浮层设了圆角：

- `QMenu { border-radius: 8px }`（五套主题同构，如 [`config/themes/cloud.qss`](config/themes/cloud.qss) 178-184 行）
- 下拉弹出列表内部的 view 是 QListView，命中全局规则 `QTreeView, QListView { border-radius: 6px }`

但 Linux 上顶级弹出窗口（`Qt.Popup`）是**不透明矩形窗口**——`border-radius` 只作用于控件绘制层，无法改变窗口外形，圆角外的四个直角仍被窗口背景填满。视觉上即"矩形窗口底 + 圆角内容"。

### 2.2 第二层：QComboBox 弹出容器自绘的矩形面板（下拉独有）

离屏检测（项目 `.venv` + PySide6，offscreen 平台）确认：QComboBox 的下拉弹出容器是 QFrame 子类（`QComboBoxPrivateContainer`），**`frameShape` 默认为 `StyledPanel`**——样式引擎会为它主动绘制一个矩形面板。`WA_TranslucentBackground` 只能让"未绘制"的区域透明，对这层**主动绘制**的面板无效。这是第一轮修复后下拉框仍残留双框的原因；菜单没有这层面板，第一轮即修复正常。

## 3. 修复方案与实施记录

统一封装于新增模块 [`gui/popups.py`](gui/popups.py)：

```python
# 第一轮：通用浮层透明化（菜单修复）
make_translucent_popup(widget)      # WA_TranslucentBackground + NoDropShadowWindowHint

# 第二轮：下拉专用（追加去容器面板）
make_translucent_combo_popup(combo) # 上述 + 容器 frameShape = NoFrame
```

- `WA_TranslucentBackground`：圆角外区域真正透明，消除矩形窗口底（§2.1）
- `NoDropShadowWindowHint`：去掉窗口管理器按矩形外框绘制的投影（否则透明后残留矩形阴影）
- `frameShape = NoFrame`：去掉 QComboBox 弹出容器的 StyledPanel 矩形面板（§2.2）；背景/描边/圆角本由内部 view 的 qss 完整提供，去框无视觉损失
