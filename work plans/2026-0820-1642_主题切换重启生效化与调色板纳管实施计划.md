# 主题切换重启生效化与调色板纳管实施计划

## 1. 目标

1. **切换主题改为重启生效**：`switch_theme` 只做持久化 + 菜单勾选 + 重启提示，不再热重渲染、不再走八方转发链。
2. **QPalette 纳管**：`apply_theme` 内按当前主题令牌刷新 app 级调色板，根治「文本控件落到 palette Text 角色恒黑」的系统性根因（含 1424 计划明确未修的 QLabel/QMenuBar 黑字）。
3. **文档与注释订正**：1424 计划状态行订正为「代码已回滚未入库，路线被本计划取代」；三处"挂 switch_theme 链"docstring 同步订正，消除死链误导。

**非目标**：不做存量卡片重刷机制（B 类整个取消——重启后卡片新建自然正确）；不恢复热切换；不引入第三方主题库；不动 `assets/themes/base.qss` 模板；不做逐像素探针验证矩阵；不做「立即重启」按钮。

## 2. 背景与根因分工

1424 计划调查已实证（结论沿用，不重复验证）：

- **A 类（文字恒黑）**：QSS 的 `color` 不沿控件树继承，未显式命中的文本控件落到 palette Text 角色恒黑。**与热切换无关**——冷启动进深色主题同样黑字，重启治不了，必须纳管 palette。1424 原路线是 base.qss 逐类补 `color`（3 行），但覆盖不全且治不好 QLabel/菜单栏（其 §2 订正自认计划外残留）；palette 路线一处代码全覆盖，故选之。
- **B 类（存量卡切换不重刷）**：卡片颜色构造期冻结进内联 HTML/QSS 字符串，热刷需逐卡类补原始数据簿记 + `refresh_colors()`（约 20 处 label、四五个卡类）。**纯热切换问题**——改重启生效后整个消失，这是本计划砍掉的工作量大头，也是 1424 实施期 token 消耗的主要来源（连同其逐像素 × 六主题验证矩阵）。

**为什么 palette 路线现在可行而 1424 没选**：1424 的目标含「热切换下存量块同步换色」，palette 帮不上 B 类，故其围绕 QSS + 重刷机制设计。本计划砍掉 B 类后，palette 成为 A 类最优解。

## 4. 目标状态设计

### 4.1 QPalette 纳管（`gui/theme.py`）

新增私有函数，`apply_theme` 在 `setStyleSheet` 之后调用：

```python
# gui/theme.py
def _apply_palette(app: QApplication, palette: dict) -> None:
    """按当前主题令牌刷新 app 级 QPalette（QSS 够不到的角色兜底）。

    根因：QSS 的 color 不沿控件树继承（1424 计划探针实证），未显式命中的
    文本控件（QLabel/QMenuBar/文本编辑类等）落到 palette Text 角色恒黑。
    QSS 已显式覆盖的控件以 QSS 为准（Qt 优先级天然如此），本函数只填兜底。
    """
    pal = app.palette()  # 基于现行调色板改，未触及角色保留平台默认
    pal.setColor(QPalette.ColorRole.Window, QColor(palette["window_bg"]))
    pal.setColor(QPalette.ColorRole.WindowText, QColor(palette["text"]))
    pal.setColor(QPalette.ColorRole.Base, QColor(palette["input_bg"]))
    pal.setColor(QPalette.ColorRole.Text, QColor(palette["text"]))
    pal.setColor(QPalette.ColorRole.Button, QColor(palette["card_bg"]))
    pal.setColor(QPalette.ColorRole.ButtonText, QColor(palette["text"]))
    pal.setColor(QPalette.ColorRole.ToolTipBase, QColor(palette["tooltip_bg"]))
    pal.setColor(QPalette.ColorRole.ToolTipText, QColor(palette["tooltip_text"]))
    pal.setColor(QPalette.ColorRole.Highlight, QColor(palette["accent"]))
    pal.setColor(QPalette.ColorRole.HighlightedText, QColor("#ffffff"))
    pal.setColor(QPalette.ColorRole.Link, QColor(palette["accent"]))
    pal.setColor(QPalette.ColorRole.PlaceholderText, QColor(palette["muted_text"]))
    disabled = QColor(palette["button_disabled_text"])
    pal.setColor(QPalette.ColorGroup.Disabled, QPalette.ColorRole.Text, disabled)
    pal.setColor(QPalette.ColorGroup.Disabled, QPalette.ColorRole.WindowText, disabled)
    pal.setColor(QPalette.ColorGroup.Disabled, QPalette.ColorRole.ButtonText, disabled)
    app.setPalette(pal)
```

`apply_theme` 改动（在 `setStyleSheet` 之后、字体注册之前插入一行）：

```python
# gui/theme.py
app.setStyleSheet(render_theme(settings[KEY_THEME]))
_apply_palette(app, get_theme_palette(settings[KEY_THEME]))   # 新增
```

角色映射取舍说明：

| 角色 | 令牌来源 | 理由 |
|:---|:---|:---|
| Window / WindowText | `window_bg` / `text` | 窗口底与兜底文字色（QLabel/QMenuBar 黑字根治点） |
| Base / Text | `input_bg` / `text` | 文本编辑类控件兜底（QTextEdit/QLineEdit 等黑字根治点） |
| Button / ButtonText | `card_bg` / `text` | 按钮类兜底（QSS 已覆盖，palette 值仅作无样式回退） |
| ToolTipBase / ToolTipText | `tooltip_bg` / `tooltip_text` | 与 base.qss QToolTip 规则同源，防漂移 |
| Highlight / HighlightedText | `accent` / 白 | 选区角色；白字与 base.qss `selection-color: #ffffff` 既有硬编码一致；`gui/selection_band.py` 等四处选区带派生自 QPalette.Highlight，天然同源 |
| Link | `accent` | 富文本链接兜底 |
| PlaceholderText | `muted_text` | 输入框占位提示（Qt6 角色，不设则恒灰） |
| Disabled 组 Text/WindowText/ButtonText | `button_disabled_text` | 禁用态文字兜底，与令牌同源 |

**不设的角色及理由**：AlternateBase（交替行底色，本应用视图未启用交替行）、BrightText/LinkVisited（无消费方）、Light/Midlight/Dark/Mid/Shadow（3D 斜面角色，仅基础风格绘制使用，base.qss 已全量接管描边体系）。

**调用时机安全性**：改动后 `apply_theme` 仅剩 `main.py` 启动路径调用（窗口创建之前），`setPalette` 向已存在控件的传播问题不存在。

### 4.2 switch_theme 瘦身（`gui/main_window.py`）

```python
# gui/main_window.py
def switch_theme(self, theme: str) -> None:
    """切换主题：持久化 + 提示重启后生效（热切换已移除，见 2026-0820-1642 计划）。

    热链（apply_theme 八方转发）随本计划停用：存量卡片色构造期冻结进
    内联 HTML/QSS，热刷需逐卡簿记（1424 计划，已回滚）；重启后全部
    新建自然正确。各面板 apply_theme 方法保留（公共接口），仅本函数
    不再调用。菜单勾选语义 = 已保存的选择（非当前生效主题）。
    """
    unchanged = theme == load_settings()[KEY_THEME]   # D1：未变更不弹窗
    save_theme(theme)
    if action := self.menus.get(theme_action_key(theme)):
        action.setChecked(True)
    self._sync_settings_dialog()
    if not unchanged:
        QMessageBox.information(
            self, "主题已保存",
            f"已选择{get_label(theme)}主题，重启后生效。")
```

- **决策点 D1（未变更不弹窗）**：恢复默认设置批路径中主题未变时不打扰；连点当前主题不刷屏。
- **删除项**：`apply_theme(app)` 调用、七面板/对话框转发、状态栏「已切换为××主题」提示（与重启语义矛盾）。
- **保留项**：持久化、菜单勾选、`_sync_settings_dialog`（设置中心下拉即时反映已存选择）。
