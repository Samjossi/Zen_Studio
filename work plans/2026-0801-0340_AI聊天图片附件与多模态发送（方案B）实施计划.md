## 3. 设计要点

### 3.1 附件数据与组件（新文件 `gui/panels/chat/attachments.py`）

```python
class ImageAttachment(TypedDict):
    """单条图片附件（4c 混合载体：path 即全部事实，发送时才读盘）。"""
    path: str        # 粘贴型=落盘 PNG 路径；文件型=原文件路径（不复制）
    mime_type: str   # 由后缀映射（png/jpg/jpeg/gif/webp/bmp）
    pasted: bool     # True=IDE 落盘产物（删除×时连文件删）；False=用户文件（绝不删）
```

- `AttachmentStrip(QWidget)`：横向 chip 行；chip(QFrame) = 缩略图 QLabel
  （48×48 等比裁中）+ 文件名（省略中间）+ × 按钮；行高恒定（~64px），
  无附件 `hide()`、有附件 `show()`——垂直方向显隐，左栏宽度零影响
  （守 2305 病根教训：附件行不设 stretch，宽度随父）。
- 点击 chip（非 ×区）→ `ImagePreviewDialog`（同文件内）：QDialog +
  QPixmap 等比缩放（上限为屏幕可用区 80%），Esc / 点击关闭。
- × 删除：`pasted=True` 连同落盘文件删除；`False` 仅移出列表。
- 上限：单次 ≤5 张、单张 ≤10MB（对齐 Multi_Cli_Studio）；超限拒绝并
  在输出区发系统提示（附件行无文字区，不新增控件）。

### 3.3 三层结构放开

**数据层**（`llm/base.py`）：

```python
class Message(TypedDict, total=False):
    role: ...          # 以下两行现状不变
    content: str
    images: list[ImageAttachment]  # 新增可选键：仅 user 消息携带；agent
                                   # 会话自管历史，永不回传历史图片
```

（`total=False` 化或 `NotRequired` 均可，实施时取与现有用法兼容最小 diff；
ImageAttachment 定义于 base.py 供三层共享，attachments.py re-export。）

**provider 层**（`llm/providers/acp.py` 公共助手 + 四家各两行接入）：

```python
def build_prompt_blocks(message: Message) -> list[dict]:
    """最后一条 user 消息 → ACP prompt 块数组：text 块 + 每图 image 块。
    image 块在读盘失败（文件被删/无权限）时跳过并续发其余块（尽力而为）。"""
    blocks = [{"type": "text", "text": message["content"]}]
    for img in message.get("images", []):
        try:
            data = base64.b64encode(Path(img["path"]).read_bytes()).decode()
        except OSError:
            continue
        blocks.append({"type": "image", "data": data, "mimeType": img["mime_type"]})
    return blocks
```

四家 `chat()` 的 `begin_turn` 调用点由
`"prompt": [{"type": "text", "text": prompt}]` 改为
`"prompt": build_prompt_blocks(last_user)`（取消息逻辑同步从取 content
改为取整条消息）。base64 读盘发生在 worker 线程（provider.chat 由
ChatWorker 驱动）——GUI 零阻塞，无需额外线程设计。

**输出层**（`output.py`）：`append_user_message(content, images=None)`——
气泡卡文本后追加每图 `<img src="file://路径" width="200">`
（Qt 富文本本地文件直渲，宽度限 200 防撑破气泡）。
