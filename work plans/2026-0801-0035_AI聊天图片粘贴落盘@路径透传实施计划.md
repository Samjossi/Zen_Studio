# AI 聊天图片粘贴落盘 @路径透传实施计划（方案 D）

> 按选型定夺的方案 D（最小可用版）：输入框粘贴的图片**落盘成 PNG 文件**，
> 在光标处插入 `@路径 ` 纯文本引用——完全复用现有拖放文件的 @路径 透传链路，
> 由后端 agent CLI 自行读图。`Message` / provider / 输出区三层数据结构**零改动**。
>
> 本计划刻意**不含**缩略图行与大图预览（方案 B 的表现层），后续如需升级，
> 本计划的落盘与入口代码全部复用（见 §8 演进路径）。

## 1. 目标行为

| 场景 | 现状 | 目标 |
|---|---|---|
| 截图工具截图后 Ctrl+V | 无任何反应（图片数据被 Qt 默认丢弃） | 图片落盘 PNG，光标处插入 `@路径 ` |
| 浏览器/看图软件复制图片后 Ctrl+V | 无反应或仅粘出 URL 文本 | 同上（有图片数据即走图片分支） |
| 文件管理器复制图片**文件**后 Ctrl+V | 无反应 | 不复制文件，直接插入该文件 `@路径 `（与拖放行为一致） |
| 普通文本 Ctrl+V | 正常粘贴 | **不变** |
| 拖入图片文件 | 插入 `@路径 `（已有） | **不变**（拖放链路本方案零改动） |

发送侧无任何变化：`@路径 ` 随文本走既有 `send_requested` →
`session/prompt` 纯文本链路，由 agent CLI 解析读图。

## 3. 设计要点

### 3.1 唯一新分支：`insertFromMimeData` 重写

在 `ChatInput` 中重写 `insertFromMimeData(source)`，三分支：

```
source.hasImage()          → 图片分支：落盘 PNG → insertPlainText(_mention_text(落盘路径))
                             （workspace_root 未注入或落盘失败 → 退化默认粘贴，不报错不弹窗）
source.hasUrls() 且含本地文件 → 复用拖放语义：逐个 insertPlainText(_mention_text(本地路径))
其余                        → super().insertFromMimeData(source)（文本等默认行为原样保留）
```

- **图片数据形态**：`source.imageData()` 返回 `QImage` 或 `QPixmap`
  （来源不同形态不同），两者均有 `.save(path, "PNG")`，统一直接 save，
  不做格式判别。
- **统一转 PNG**：无论来源原格式（BMP 截图、JPEG 复制等）一律落 PNG——
  无损、单格式、agent 端兼容性最好；不做压缩/缩放（选型已定，四参考项目
  均未压缩）。
- **文件 URL 分支与拖放对齐**：文件管理器复制的图片文件**不再复制一份**，
  直接引用原路径（拖放现状即如此，行为一致、零磁盘浪费）；非图片文件
  同样受益（复制任意文件粘贴 = 拖放等价物）。

### 3.2 落盘位置与命名（决策 D2）

跟随截图功能双态先例（`main.py:24-26`）：

- 开发态：`<PROJECT_ROOT>/.tmp/pasted/`
- 打包态：`<USER_CONFIG_DIR>/pasted/`

命名：`pasted-YYYYMMDD-HHMMSS.png`，同秒冲突追加 `-2`、`-3` 序号
（时间戳精度到秒，连贴同秒图必然撞名，序号兜底）。

**@路径形态自然分叉**：工作区 = Zen Studio 项目本身时（本用户主场景），
`.tmp/pasted/` 在工作区内，`_mention_text` 产出**相对路径**（如
`@.tmp/pasted/pasted-20260801-003500.png `）；打开其他工作区时产出
**绝对路径**。两种形态 `_mention_text` 现成支持，代码零分支。

### 3.3 不变项（明确冻结）

- `Message.content: str`、四 provider `session/prompt` text 单块、
  `ChatPanel._on_send`、输出区渲染——**零改动**（方案 D 核心承诺）。
- 拖放三个事件（dragEnter/dragMove/drop）——零改动。
- `trigger_send` / Enter 发送 / 选区带自绘 / 右键菜单——零改动。
- 主题键、qss、布局——零新增零改动。
- 落盘文件**不自动清理**：发送后保留（会话期间 agent 可能复读该图；
  `.tmp/` 已 gitignore，手动清或随 `.tmp/` 惯例处理）。
