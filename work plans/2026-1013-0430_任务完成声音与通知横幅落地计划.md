# 任务完成声音提醒 + 顶部通知横幅落地计划

## 需求

AI 执行完任务时：
1. 播放提示音（声音提醒）
2. 弹出顶部通知横幅（Notification Banner）
3. 两者各有独立开关，收纳进设置中心，用户可开关
4. 提示音资产从 `参考代码/` 复制，存入 `assets/sounds/`，内分「备选池」与「正在使用」两个子目录，复制进来的先放备选池

## 关键探查结论（已核实）

- **钩子点**：`src/gui/panels/chat/panel.py:1075` `_on_finished(error)`（成功+失败统一收尾）与 `:1105` `_on_stopped()`（用户手动中断，第三态）。注意 `_on_finished` 中存在待发接续（`:1102` `_fire_pending_send()` 返回 True 时 busy 不间断、紧接着下一轮）——**接续轮中途不提醒，等真正闲下来才提醒**。
- **转发层**：`src/gui/panels/chat/tabs.py:87` `turn_finished` 已有转发先例；`src/gui/main_window.py:360` 已有 `turn_finished → git_controller.schedule_refresh` 挂载先例，照此接线。
- **设置中心**：`src/gui/settings_dialog.py` 页面注册表驱动（`:117`），新增设置项标准流程写在文件头 docstring（`:25-32`）。现有复选框三件套可照抄（`:460` 构建 / `:479` 槽 / `:547` 回读）。
- **持久化**：`src/gui/settings.py` 加 `KEY_*` 常量 + `AppSettings`/`AppSettingsPatch` + `DEFAULT_SETTINGS`，读写走 flock + 原子写，已定型。
- **声音播放**：PySide6>=6.11.1，`PySide6.QtMultimedia.QSoundEffect` 已验证可用（`.venv` 实测导入 OK）。兜底参考 `参考代码/kilocode-main/packages/kilo-vscode/src/services/attention/sound.ts`（Linux 依次尝试 aplay/paplay/play）。
- **音频资产**：`参考代码/kilocode-main/packages/kilo-vscode/audio-wav/` 共 52 个 wav，按语义分五族（alert / bip-bop / staplebops / nope / yup）；kilocode-main 为 MIT 许可（`参考代码/kilocode-main/LICENSE`），可复制。kilocode 官方语义映射：`done → bip-bop-01`、`error → nope-03`。
- **横幅**：本仓无 toast/banner 先例（只有状态栏 `statusBar().showMessage`），需新写；布局参考 `参考代码/kilocode-main/packages/opencode/src/kilocode/components/notification-banner.tsx` 的两行式（标题+正文）。
- **资产目录纪律**（`assets/README.md`）：一族一目录；打包资产须登记 `building/zen-studio.spec` 的 `datas`；运行时访问须走 `src/core/paths.py` 常量（现有 `ASSETS_DIR`/`LOGO_DIR`/`THEMES_ASSETS_DIR`，`paths.py:35-42`）。

## 默认行为决策

- **触发时机**：正常收尾即提醒（成功与失败都提醒，失败用不同音效与横幅文案）；用户手动中断**不**提醒（中断是用户自己的操作）。
- **开关默认**：两个开关默认都开启。
- **窗口状态**：不区分窗口是否聚焦，一律提醒（保持简单，后续可按需加"仅后台时提醒"）。

## 实施步骤

### 1. 资产目录与提示音拷贝（已完成）

- 新建 `assets/sounds/备选池/` 与 `assets/sounds/正在使用/`。
- 从 `参考代码/kilocode-main/packages/kilo-vscode/audio-wav/` 挑选 8 个拷入 `备选池/`（覆盖五族便于后续挑选）：
  `bip-bop-01.wav`、`bip-bop-02.wav`、`bip-bop-03.wav`、`yup-01.wav`、`alert-01.wav`、`staplebops-06.wav`、`nope-01.wav`、`nope-03.wav`
- 默认启用音拷入 `正在使用/` 并语义化命名：`bip-bop-01.wav → done.wav`、`nope-03.wav → error.wav`。

### 2. 资产登记

- `src/core/paths.py` 加常量：`SOUNDS_DIR = ASSETS_DIR / "sounds"`、`SOUNDS_ACTIVE_DIR = SOUNDS_DIR / "正在使用"`（仿 `:38-42` 注释风格）。
- `building/zen-studio.spec` 的 `datas` 补一条 `assets/sounds/正在使用` 收编记录（备选池不打包）。
- 更新 `assets/README.md`：登记 `sounds/` 一族（备选池不打包 / 正在使用打包）。

### 3. 设置项（`src/gui/settings.py`）

- 新增：
  - `KEY_NOTIFY_SOUND_ENABLED = "notify_sound_enabled"`，默认 `True`
  - `KEY_NOTIFY_BANNER_ENABLED = "notify_banner_enabled"`，默认 `True`
- `AppSettings` 与 `AppSettingsPatch` 各加一行（bool），`DEFAULT_SETTINGS` 加默认值。

### 4. 设置中心新页「通知」（`src/gui/settings_dialog.py`）

- `_PAGE_REGISTRY` 在「终端」与「高级」之间插入一行（破坏性操作「高级」沉底的排入纪律不变）：
  `("通知", "AI 任务完成时的声音提醒与通知横幅开关。", "_build_notify_page", "_reload_notify")`
- `_build_notify_page`：两个 `QCheckBox`（「任务完成时播放提示音」「任务完成时弹出顶部通知横幅」）+ 一个「试听提示音」`QPushButton`；`toggled` → `update_settings({KEY_*: checked})` 即时持久化（本页无 MainWindow 应用槽需求，直接调 `update_settings`，同 docstring 标准流程第 2 条）。
- `_reload_notify(settings)`：回读两个复选框状态。

### 5. 声音播放模块 `src/gui/sound_player.py`（新建）

- 函数 `play_completion_sound(success: bool)`：
  - 选 `SOUNDS_ACTIVE_DIR / ("done.wav" if success else "error.wav")`，文件缺失则静默跳过。
  - 主路径 `QSoundEffect`（已验证可用）异步播放；模块级单例持有防 GC 中断。
  - 兜底：QSoundEffect 源加载失败（无声卡环境/AppImage 缺插件）时降级 `aplay`/`paplay` 子进程（shutil.which 探测，参考 kilocode sound.ts:117-123）。
  - 防抖：1 秒内重复触发合并为一次（多标签同时收尾不叠音）。

### 6. 通知横幅组件 `src/gui/notification_banner.py`（新建）

- `NotificationBanner(QFrame)`：父为 `MainWindow`，悬浮于窗口顶部居中（非模态、不抢焦点）。
- 布局：两行式——首行标题（「任务完成」/「任务失败」，成功/失败不同强调色，用 `gui/theme.py` 调色板令牌），次行摘要正文；右侧关闭按钮。参考 kilocode notification-banner.tsx 结构。
- 行为：显示 4 秒后自动淡出隐藏（`QTimer` + `QGraphicsOpacityEffect` 或简单 hide）；新通知到来时替换旧内容并重置计时（单横幅，不做队列）。
- 主题化：内联样式部分挂 `apply_theme(theme)` 收敛点（仿 `settings_dialog.py` 的 hint/分隔线重刷先例）。

### 7. 触发接线

- `src/gui/panels/chat/panel.py`：新增信号 `turn_completed = Signal(bool)`（True=成功，False=失败）。在 `_on_finished` 中：
  - 失败分支（`:1095-1101`）：`_set_busy(False)` 后 `turn_completed.emit(False)`
  - 成功且无待发接续分支（`:1102-1103`）：`_set_busy(False)` 后 `turn_completed.emit(True)`
  - `_on_stopped` 不发（手动中断不提醒）
- `src/gui/panels/chat/tabs.py`：转发 `turn_completed`（仿 `turn_finished` 转发，`tabs.py:232/237` 接线点）。
- `src/gui/main_window.py`：`chat_tabs.turn_completed.connect(self._on_turn_completed)`；槽函数读 `load_settings()`：
  - `KEY_NOTIFY_SOUND_ENABLED` 开 → `sound_player.play_completion_sound(success)`
  - `KEY_NOTIFY_BANNER_ENABLED` 开 → `self._notify_banner.show_completion(success, ...)`（横幅实例懒创建，持有于 MainWindow）
