# Markdown阅览行内代码灰底带偏下自绘修复落地计划

> **状态**：已拍板待实施（2026-11-20 用户确认：方案 A + 行内代码字族借机换库内 Sarasa Term SC）
> **范围**：`src/ide/gui/panels/viewer/markdown_view.py`、`tests/`
> **时间**：2026-11-20 08:03（设计）(UTC+8)
> **优先级**：中

---

## 1. 需求背景（用户反馈）

MD 文档中以重点符号（反引号）包裹的行内代码，在阅览模式（MarkdownView）下渲染为
灰色高亮底带，该带相对文字上下不居中（偏下），与 2026-10-13 修复过的选区高亮偏下
（`2026-1013-1105_卡片轨选区高亮偏下修复落地计划.md`）观感同类。用户真机截图确认。

行内代码底带来自 `_build_stylesheet` 的 `code, pre { background-color: code_bg }`
（`src/ide/gui/panels/viewer/markdown_view.py`），由 Qt 富文本引擎绘制，项目代码不掌控
其几何——与当年选区原生带的处境相同，故同样走「抑制原生 + 自绘对称带」的路线。

## 2. 现状诊断（offscreen 探针实测，2026-11-20）

探针：`.temp/probe_inline_code_band.py`（基线量测 + 候选 CSS 方案筛除）。
环境对齐真机：`theme.apply_theme(app)` 注册库内思源黑体 + 用户字号 13 + 全量 QSS。

**基线量测（现状）**：

| 指标 | 数值 |
|:---|:---|
| 灰底带高 | 28px（= 整行高，含 leading） |
| 文字墨盒高 | 18px |
| 带心 vs 墨心偏差 | **-3.00px（带偏下）**，与用户截图观感一致 |

**根因**：同 2055/1013 计划——思源黑体把额外行距打包为 leading，Qt 排版将 leading
全部垫在行框底部；且 Qt 富文本对行内元素的 `background-color` 一律按**整行高**绘制
（行内带高 28px = 行高），故带必然包住文字并向下溢出。

**纯 CSS 路径全部实测无效**（数值逐字节不变，即被 Qt 忽略）：

- `code { vertical-align: middle / -1px }` —— 无效；
- `p { line-height: 100% }` —— 无效（百分比不被文档 CSS 接受）；
- `span` 替代 `code` 标签 —— 带仍 26px 整行高，无效。

**结论**：Qt 文档 CSS 无 knob 可调，必须自绘。

## 3. 方案选型

### 方案 A（已拍板）：哨兵定位 + 先绘带后重绘文字 + 字族换库内 Sarasa

三段式，全部在 `MarkdownView` 内闭环：

1. **哨兵注入**：覆写 markdown-it 渲染规则 `code_inline`（`md.renderer.rules`），
   输出 `<code>\u200b内容\u200b</code>`（内容转义复用内建规则逻辑）。
   U+200B 零宽空格：零占位、无字形、不破坏排版。探针实证（`.temp/probe_inline_code_sentinel.py`）：
   `setHtml` 后完整保留于 `toPlainText()`，`QTextDocument.find` 可顺序命中定位。
2. **抑制原生带**：`_build_stylesheet` 中摘除 `code` 的背景声明（`pre` 代码块背景
   保留——块级背景整段铺无偏下问题；表格 `th` 背景同理不动）。
3. **字族换库内**：`code` 声明 `font-family: "Sarasa Term SC"`（`theme.get_mono_family()`
   取值，未注册时回退泛型 monospace——防御路径与终端/代码查看器同规约）。动机：消除
   系统 monospace 跨机不一致（现况为 Qt 泛型回退，渲染结果随 fontconfig 漂移），
   与本计划「几何可控」同一目标；顺带使带内墨盒度量跨机确定，自绘带观感可复现。
3. **自绘带**：缓存哨兵对定位的字符区间（`contentsChanged` 时重扫，paintEvent 不重复
   `toPlainText`）；`paintEvent` 中基类绘制后：填 `code_bg` 实色带（几何 = 行
   ascent+descent ± `SELECTION_PAD_Y`，逐行一段、折行分段，**直接复用
   `src/ide/gui/selection_band.py` 的 `selection_rects` 几何**——把核心重构成接受
   `(start, end)` 区间的形式，选区带调用方零改动）→ 带区域内 `document().drawContents`
   以文档坐标重绘文字（带为实色浅灰，文字必须后画；实测 drawContents 局部重绘
   字形清晰无残影）。

**PoC 实测**（`.temp/probe_inline_code_poc.py`）：偏差 **-3.00px → +1.00px**，
带高 19px 与正文选区带同高，观感对齐。残余 +1px 为等宽拉丁墨盒相对 CJK 行 metrics
的非对称性（下划线/升部空间），与选区带同量级，可接受。

### 方案 B（备选）：monospace 片段扫描，无哨兵

利用 Qt 默认文档样式表给 `<code>` 挂 `font-family: monospace` 的特性（探针实证），
遍历文档 fragment，按字族名定位区间。免哨兵、无剪贴板污染，但：字族名耦合 Qt 内部
默认样式行为；`<pre>` 内片段同族需额外区分（其内联带与块底叠加观感噪声）；
用户 md 内嵌 HTML 写 `font-family: monospace` 会误判。维护脆弱性高于方案 A 的
一次性代价，不推荐。

### 方案 C（已证伪）：CSS/行高压缩

vertical-align、line-height 百分比均被 Qt 忽略（§2 实测）；px 行高即使生效也改全文
排版，弃。

## 4. 实施任务

- **T1 渲染规则**：`_build_renderer` 覆写 `code_inline` 规则注入哨兵对；转义逻辑
  复用 markdown-it 内建实现，不手写。
- **T2 样式表摘除与字族切换**：`code, pre` 背景规则拆分为 `pre` 保留、`code`
  移除；`code` 增挂库内等宽字族（`get_mono_family()`，回退 monospace）。
  哨兵字符无色无形，无需隐藏处理。
- **T3 自绘带落地**：`selection_rects` 重构出接受区间的核心（选区路径行为不变）；
  `MarkdownView` 增加区间缓存（`contentsChanged` 重扫，成对取区间、落单忽略防御）、
  `paintEvent` 改为：基类绘制 → code 带（填色 + drawContents 重绘）→ 选区带
  （既有 `paint_selection_band` 半透明叠绘，顺序保持在最后）。
- **T4 offscreen 探针回归**：改造 PoC 为断言式用例——带心/墨心偏差 ≤ ±1.0px
  （PoC 以系统 monospace 实测 +1.00；换 Sarasa 后度量以实测为准，验收线 ±1.0px
  并注明字体度量来源）、带高 = 行墨盒 ± 1px、折行 span 两段带、无哨兵落单崩溃、
  code 片段字族为 Sarasa Term SC。
- **T5 单测**：新增 `tests/test_viewer_inline_code_band.py`：渲染 HTML 含哨兵对、
  CSS 无 code 背景声明且挂库内等宽字族、区间定位正确、pre 代码块背景声明保留。
- **T6 真机视觉验证闭环**：用户真机打开含行内代码的 README，截图像素扫描确认
  带居中；顺带肉眼核对：选区叠在代码带上文字仍可读、pre 代码块无变化。

## 6. 风险与对策

| 风险 | 等级 | 对策 |
|:---|:---:|:---|
| 复制带走哨兵（U+200B 混入剪贴板，粘贴进聊天发给 AI） | 🟡 | 只读查看器复制出口仅 Ctrl+C 与右键菜单：统一改走自定义槽（取 `selectedText()` 去 `\u200b` 后 `clipboard().setText()`），两入口一处实现；接受丢富文本格式（该场景本为纯文本） |
| 用户 md 自带 U+200B 致哨兵配对错位 | 🟢 | 成对扫描 + 落单忽略；本项目文档无此用法，错位仅致带位置画错，不崩溃 |
| 选区跨代码带：带内文字被 drawContents 重绘为非选中色 | 🟢 | 选区带半透明叠绘在最后，整体仍显选中；带区 tint 略有差异，观感可接受（T6 肉眼核对项） |
| 大文件（1MB）每帧 `toPlainText` 开销 | 🟢 | 区间缓存 + `contentsChanged` 失效，paintEvent 零字符串扫描 |
| `selection_rects` 重构波及其余三处挂载点（旧轨聊天输出/输入、本文件选区带） | 🟡 | 重构仅抽参数不改变算法；T5 跑全部选区带相关用例回归 |
