## 1. 问题现象

左栏 AI 会话栏的可视外框（消息区、输入框、模型/发送按钮行外侧的 1px 圆角描边卡片）存在两处边缘错位：

1. **右缘**：外框右边线比标签行右上角「＋」新建按钮的右边缘**靠左约 6px**，未形成一条齐平垂线，右侧多出一截空隙。
2. **底缘**（2026-09-08 截图补充）：外框下边框比中栏终端卡片、右栏「已变更」卡片的下边框**高约 6px**——终端与已变更两栏底线互相对齐，唯独聊天栏底线抬高一截，左中右三栏底线不齐。

期望：外框右缘右移与「＋」按钮右缘齐平；外框底缘下移与终端/已变更卡片底缘齐平（三栏底线一条线）。

## 2. 根因诊断

### 2.1 相关结构

```text
MainWindow._splitter_main
├─ ChatTabs（#SidePanel 灰底）
│  │  layout 边距 (6,6,6,6)                    ← 第 1 层 6px
│  └─ QTabWidget（#ChatTabs，pane 去框、透明）
│     ├─ 角控件「＋」QToolButton（TopRightCorner）  ← 只经第 1 层边距
│     └─ 标签页 = ChatPanel（#SidePanel）
│        │  layout 边距 (6,6,6,6)                ← 第 2 层 6px
│        └─ QFrame #PanelCard（1px 描边 + 8px 圆角）← 用户看到的「外框」，
│           └─ QSplitter（输出区 / 输入区）          经两层边距叠加
├─ TerminalPanel：layout 边距 (6,2,6,6)，#PanelCard 只经 1 层边距
└─ ChangesPanel（已变更）：卡片同样只经 1 层边距
```

### 2.2 根因：6px 边距双层叠加（右缘与底缘同一根因）

- 「＋」按钮是 `QTabWidget` 的右上角控件（`gui/panels/chat/tabs.py` 的 `setCornerWidget`），其右边缘 ≈ ChatTabs 右缘 − 6px（仅第 1 层边距）。
- 外框 `#PanelCard` 建在每个标签页 `ChatPanel` **内部**（`gui/panels/chat/panel.py` 的 `_build_layout`），右缘 = ChatTabs 右缘 − 6px − 6px = **右缘 − 12px**，底缘同理 = **底缘 − 12px**。
- 终端/已变更面板的卡片只经各自面板一层 6px 边距，底缘 = 面板底缘 − 6px。
- 因此聊天卡片右缘差「＋」6px、底缘差终端卡片 6px——两处错位都是 ChatPanel 自身那层 6px 外边距叠加所致。
- 另注：`gui/panels/chat/panel.py` 现行注释称「下边距 6px + 状态栏定高 26px = 底部总间距 32px（一体化设计）」，实际因双层叠加是 12 + 26 = 38px，本修复同时把底部间距拉回设计值。

### 2.3 与终端面板对照（结构差异佐证）

终端面板（`gui/panels/terminal/panel.py`）的头部栏（含「＋」新建终端钮）与终端区**同在** `#PanelCard` 卡片内部，按钮与卡片只经同一层边距，天然对齐；而聊天面板的标签行由 `QTabWidget` 托管、位于卡片**之外**，因此唯独聊天栏出现右缘/底缘错位。属结构性根因，非 qss 问题。

## 3. 修复方案

### 方案 A（推荐，最小改动）：卡片右缘右移 6px、底缘下移 6px

`gui/panels/chat/panel.py` `_build_layout` 中，ChatPanel 面板级布局右、下外边距 6 → 0：

```python
# gui/panels/chat/panel.py
layout.setContentsMargins(6, 6, 0, 0)  # 原 (6, 6, 6, 6)
```

效果：卡片右缘 = 标签页右缘 = QTabWidget 右缘，与「＋」按钮右缘齐平；卡片底缘 = ChatTabs 底缘 − 6px，与终端/已变更卡片底缘齐平（三栏底线一条线，底部总间距回到设计值 32px）。左、上边距不动，其余观感零变化。

⚠️ 已知取舍：左缘维持现状（卡片左缘在 ChatTabs 左缘 +12px，「会话 N」标签左缘约 +6px，镜像方向同样差 6px）。用户本次只报右缘与底缘问题，方案 A 不动左缘。

### 方案 B（可选扩展）：左右同时对齐终端面板几何

```python
# gui/panels/chat/panel.py
layout.setContentsMargins(0, 6, 0, 0)
```

在方案 A 基础上，卡片左缘也与「会话 N」标签左缘齐平，卡片左右缘位置与终端面板卡片完全一致（均距侧栏缘 6px）。代价：卡片整体左移 6px，改动超出本次报告范围。

**建议**：先落方案 A；若审阅时认为左缘也应齐平，再升级方案 B。

> **结论**：实际实施的是**方案 A**（卡片右缘右移 6px、底缘下移 6px，左缘维持现状）。方案 B 未采用，仅作备选记录。
