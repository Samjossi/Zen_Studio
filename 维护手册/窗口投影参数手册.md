# 窗口投影参数手册

> **创建日期**：2026-10-23
> **最后更新**：2026-10-23
> **版本**：v1.0
> **用途**：汇总 GNOME / GTK / Qt 官方实现的窗口投影权威参数，按编号归档。调整 Zen Studio 主窗口投影（`src/gui/window_shadow.py`）时直接说「用 N 号参数」即可，无需重新查证。

---

## 1. 口径说明

- CSS `box-shadow` 四元组语义：`水平偏移 垂直偏移 模糊半径 扩散半径 + 颜色`。总外扩 ≈ 模糊半径 + 扩散半径；零偏移即四边对称投影。
- 本项目实现为九宫格离屏图元拼贴（`src/gui/window_shadow.py`），可调旋钮：
  - `SHADOW_MARGIN`：阴影环厚度（px）≈ CSS 总外扩；
  - `_WIDE_ALPHA` / `_TIGHT_ALPHA` / `_TIGHT_THICK`：宽软层峰值、贴身层峰值与厚度（0-255 ≈ CSS 颜色 alpha 通道 255 进制），两层按 over 叠乘合成（双层骨架对标 1 号；单层方案即贴身层置零的退化）；
  - `_profile(t)`：一维衰减剖面（现行 `cos(πt/2)²`，两层共用）。
- 共同规律：三家官方实现都带 **1px 收边线/描边**——阴影负责「浮起感」，发丝线负责「精确边界」，职责分开。

## 2. 编号参数集

### 1 号 · GNOME libadwaita 原生（目标环境同款，最权威对标）

GNOME 46+ / libadwaita 应用窗口的现行投影，`window.csd` 三层叠加：

```css
box-shadow: 0 0 14px 5px RGB(0 0 0 / 15%),   /* 宽软层：模糊14 + 扩散5 */
            0 0 5px 2px  RGB(0 0 0 / 10%),   /* 贴身层：模糊5 + 扩散2 */
            0 0 0 1px    RGB(0 0 0 / 5%);    /* 1px 发丝线收边 */
```

| 维度 | 值 |
|:---|:---|
| 总外扩 | ≈ 19px |
| 峰值浓度（边缘处三层叠算） | ≈ 25–28% 黑（64–71/255） |
| 偏移 | 无（四边对称） |
| 收边线 | 1px，5% 黑（13/255） |

落地映射：双环两层（贴身环 ≈7px/26 + 宽软环 ≈19px/38 叠乘）+ 可视壳 1px 收边。本项目现行取其骨架的减淡变体，见 5 号。

### 2 号 · GTK4 Default 兜底主题（非 libadwaita 的 GTK4 应用）

```css
box-shadow: 0 3px 9px 1px rgba(0,0,0,0.5),   /* 偏移3 / 模糊9 / 扩散1，50% */
            0 0 0 1px   rgba(0,0,0,0.23);    /* 1px 描边 */
/* 失焦（backdrop）降级为：0 2px 6px 2px rgba(0,0,0,0.2) + 1px 18% */
```

| 维度 | 值 |
|:---|:---|
| 总外扩 | ≈ 10px |
| 峰值浓度 | 50% 黑（128/255），失焦降 20% |
| 偏移 | 向下 3px（有方向感） |
| 收边线 | 1px，23% 黑（59/255） |

落地映射：窄环 ≈10px、高浓度，附下偏移；风格偏「小而深」，与浅色主题白底反差强。

### 3 号 · Qt 官方 Adwaita Wayland 装饰插件

Qt 6 自带 `qwaylandadwaitadecoration` 的常量（阴影为预制位图，非渐变参数）：

| 常量 | 值 |
|:---|:---|
| `ceShadowsWidth`（阴影宽） | 10px |
| `ceCornerRadius`（窗口圆角） | 12px |
| `ceWindowBorderWidth`（描边） | 1px，亮色 `#dbdbdb` / 深色 `#3b3b3b` |
| 最大化/平铺 | 阴影、圆角、描边全部收起 |

落地映射：窄阴影 + 描边路线，近似本仓库已归档的描边方案（锚点 `4e8a76e`）。

### 4 号 · 本项目历史定制（2026-10-23 真机调参定稿，后被 5 号方案替换）

| 维度 | 值 |
|:---|:---|
| 环厚 `SHADOW_MARGIN` | 18px |
| 峰值 `_SHADOW_ALPHA` | 34/255（≈13% 黑） |
| 剖面 `_profile(t)` | `cos(πt/2)²`（t=0 零斜率软着陆，尾部收紧） |
| 角部 | 剖面乘积 `f(dx)×f(dy)`（消径向渐变深结） |
| 收边线 | 无 |
| 最大化/全屏 | 投影收起，边距归零 |

特点：单层渐变、比 1 号更淡更收敛；无描边，边界全靠投影。

### 5 号 · 本项目现行定制（2026-10-23 真机调参定稿：1 号骨架减淡变体）

取 1 号双环骨架，略去收边线，浓度整体减半、宽软层收窄（原生峰值在浅色主题白底下偏浓）。

| 维度 | 值 |
|:---|:---|
| 环厚 `SHADOW_MARGIN` | 15px |
| 贴身层 `_TIGHT_ALPHA` / 厚 `_TIGHT_THICK` | 13/255，7px |
| 宽软层 `_WIDE_ALPHA` | 19/255，铺满全环 |
| 贴边峰值（两层 over 合成） | ≈31/255（≈12% 黑） |
| 剖面 `_profile(t)` | `cos(πt/2)²`（两层共用，逐层衰减后叠乘） |
| 角部 | 逐层剖面乘积后再 over 合成 |
| 收边线 | 无 |
| 最大化/全屏 | 投影收起，边距归零 |

特点：双层叠乘、贴边略浓外缘柔和的 GNOME 骨架，但比 1 号淡一半、更收敛；无描边，边界全靠投影。

## 3. 速查与选择建议

| 编号 | 一句话特征 | 适用 |
|:---:|:---|:---|
| 1 | GNOME 原生观感，三层叠加 + 收边线 | 与 GNOME 桌面完全同化 |
| 2 | 小而深，带下偏移 | 强反差、偏 macOS 方向感 |
| 3 | 窄阴影 + 描边（Qt 官方路线） | 实现最省事，观感偏方正 |
| 4 | 历史定制：单层、淡、无描边 | 已被 5 号方案替换 |
| 5 | 1 号骨架减半减淡：双层 15px、无收边线 | **现行**，默认无需改动 |
